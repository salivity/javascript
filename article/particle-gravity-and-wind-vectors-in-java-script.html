Particle Gravity and Wind Vectors in JavaScript

In JavaScript game programming, physics-driven particle systems rely on vector mathematics to simulate natural motion. Movement is primarily governed by three vectors: position, velocity, and acceleration. External environmental influences, such as gravity and wind, act as directional force vectors that alter a particle's acceleration at each update tick. By accumulating these forces into a particle's velocity vector and subsequently adding that velocity to its position, developers can produce realistic, dynamic behaviors ranging from drifting smoke to falling debris.

Understanding Movement Vectors

A 2D particle's movement state is represented by three core vectors:

  • Position (\(\vec{P}\)): The particle's current coordinates \((x, y)\) on the canvas.
  • Velocity (\(\vec{V}\)): The rate and direction of position change per frame \((v_x, v_y)\).
  • Acceleration (\(\vec{A}\)): The rate and direction of velocity change per frame \((a_x, a_y)\).

In a basic update loop, motion follows standard Euler integration:

velocity.x += acceleration.x;
velocity.y += acceleration.y;
position.x += velocity.x;
position.y += velocity.y;

// Reset acceleration for the next frame
acceleration.x = 0;
acceleration.y = 0;

Forces are applied by adding them to the particle's acceleration vector. According to Newton's second law (\(F = ma\)), acceleration equals force divided by mass (\(A = F / m\)). If mass is normalized to 1, force directly adds to acceleration.

How Gravity Affects Movement Vectors

Gravity is an attractive force pulling objects toward a surface. In standard 2D screen coordinates, where the Y-axis increases downward:

  • Vector Definition: Gravity is defined as a static vector with no horizontal component and a positive vertical component: gravity = { x: 0, y: 0.2 }.
  • Vector Mutation: Applying gravity adds a constant positive offset to acceleration.y. Over consecutive frames, this steadily increases velocity.y.
  • Visual Result: A particle launched upward (negative \(v_y\)) decelerates until its vertical velocity hits zero, then reverses direction and accelerates downward, tracing a natural parabolic arc.

How Wind Affects Movement Vectors

Unlike gravity, wind is a fluid, multi-directional force that can vary over time and space:

  • Vector Definition: Wind primarily exerts lateral force, defined as a vector like wind = { x: 0.15, y: -0.02 }, though turbulence can alter both axes.
  • Dynamic Variation: Real-world wind gusts are rarely static. In JavaScript, wind vectors are frequently modulated using mathematical functions such as Math.sin() or Perlin noise to fluctuate direction and intensity dynamically.
  • Vector Mutation: Wind adds directly to acceleration.x (and optionally acceleration.y). Light particles with lower mass respond aggressively to wind vectors, drifting horizontally across the screen.

Integrating Multiple Forces in JavaScript

When multiple forces interact, their vectors are combined through vector addition before modifying velocity:

class Particle {
  constructor(x, y, mass = 1) {
    this.position = { x, y };
    this.velocity = { x: (Math.random() - 0.5) * 4, y: -Math.random() * 5 };
    this.acceleration = { x: 0, y: 0 };
    this.mass = mass;
    this.drag = 0.99; // Air resistance dampening
  }

  applyForce(force) {
    // F = ma => a = F / m
    this.acceleration.x += force.x / this.mass;
    this.acceleration.y += force.y / this.mass;
  }

  update() {
    this.velocity.x += this.acceleration.x;
    this.velocity.y += this.acceleration.y;

    // Apply drag to mimic terminal velocity
    this.velocity.x *= this.drag;
    this.velocity.y *= this.drag;

    this.position.x += this.velocity.x;
    this.position.y += this.velocity.y;

    this.acceleration.x = 0;
    this.acceleration.y = 0;
  }
}

// Game Loop Example
const particle = new Particle(400, 300, 1.5);
const gravity = { x: 0, y: 0.3 };
const wind = { x: 0.1, y: 0 };

function step() {
  particle.applyForce(gravity);
  particle.applyForce(wind);
  particle.update();
}

The Role of Drag and Terminal Velocity

Unchecked forces cause particle velocities to increase indefinitely. To counteract compounding force vectors, a drag (air resistance) coefficient is applied to the velocity vector each frame. Drag acts opposite to the direction of motion, scaling downward as a percentage (e.g., velocity.x *= 0.99). This counteracting effect establishes terminal velocity, allowing gravity and wind to produce stable, natural movement rather than runaway acceleration.
