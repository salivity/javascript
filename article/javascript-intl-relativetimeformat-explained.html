JavaScript Intl.RelativeTimeFormat Explained

The Intl.RelativeTimeFormat object is a native JavaScript API that enables language-sensitive relative time formatting without the need for external libraries like Moment.js or date-fns. This article covers what the API is, how to configure its options for localized phrases like "yesterday" or "in 3 hours," how to calculate time differences dynamically, and how to use its core methods effectively in modern web development.

What is Intl.RelativeTimeFormat?

Intl.RelativeTimeFormat is part of the ECMAScript Internationalization API (Intl). It formats a numerical value and a time unit into a human-readable relative string appropriate for a specified locale.

Before this API, developers had to rely on heavy third-party packages or complex switch statements with translation maps to display strings like "5 minutes ago" or "next week." The native API handles the pluralization and localization rules across languages automatically.

Basic Syntax and Usage

To use the API, initialize an instance with a locale and an optional configuration object, then call the format() method.

const rtf = new Intl.RelativeTimeFormat('en', { numeric: 'auto' });

rtf.format(-1, 'day');    // "yesterday"
rtf.format(0, 'day');     // "today"
rtf.format(1, 'day');     // "tomorrow"
rtf.format(-3, 'week');   // "3 weeks ago"
rtf.format(2, 'month');   // "in 2 months"

The first argument of format() is the numerical value (negative for past events, positive for future events), and the second is the unit of time.

Supported Units

The format() method accepts singular or plural variations of the following units:

  • 'year'
  • 'quarter'
  • 'month'
  • 'week'
  • 'day'
  • 'hour'
  • 'minute'
  • 'second'

Configuration Options

When instantiating Intl.RelativeTimeFormat, you can customize the output using the options object:

1. numeric

  • 'always' (default): Formats the output with numbers (e.g., "1 day ago").
  • 'auto': Uses natural language terms where available (e.g., "yesterday", "tomorrow", "today").
const rtfAlways = new Intl.RelativeTimeFormat('en', { numeric: 'always' });
const rtfAuto = new Intl.RelativeTimeFormat('en', { numeric: 'auto' });

console.log(rtfAlways.format(-1, 'day')); // "1 day ago"
console.log(rtfAuto.format(-1, 'day'));   // "yesterday"

2. style

  • 'long' (default): Full words (e.g., "in 1 month", "1 month ago").
  • 'short': Abbreviated forms where supported (e.g., "in 1 mo.", "1 mo. ago").
  • 'narrow': Shortest possible representation (e.g., "in 1mo.", "1mo. ago").
const rtfShort = new Intl.RelativeTimeFormat('en', { style: 'short' });
console.log(rtfShort.format(-5, 'minute')); // "5 min. ago"

3. Localization Support

Changing the locale automatically applies correct translations and grammatical structures:

const rtfSpanish = new Intl.RelativeTimeFormat('es', { numeric: 'auto' });
console.log(rtfSpanish.format(-1, 'day')); // "ayer"
console.log(rtfSpanish.format(3, 'hour')); // "dentro de 3 horas"

const rtfGerman = new Intl.RelativeTimeFormat('de', { numeric: 'auto' });
console.log(rtfGerman.format(-2, 'day'));  // "vorgestern"

Calculating Relative Dates Automatically

Intl.RelativeTimeFormat does not calculate the difference between two Date objects directly; it only formats numbers you pass into it. To format actual dates dynamically, determine the difference between timestamps and select the appropriate unit.

function getRelativeTime(targetDate, baseDate = new Date(), locale = 'en') {
  const diffInSeconds = Math.round((targetDate.getTime() - baseDate.getTime()) / 1000);

  const cutoffs = [
    { limit: 60, unit: 'second', divisor: 1 },
    { limit: 3600, unit: 'minute', divisor: 60 },
    { limit: 86400, unit: 'hour', divisor: 3600 },
    { limit: 604800, unit: 'day', divisor: 86400 },
    { limit: 2592000, unit: 'week', divisor: 604800 },
    { limit: 31536000, unit: 'month', divisor: 2592000 },
    { limit: Infinity, unit: 'year', divisor: 31536000 },
  ];

  const match = cutoffs.find(item => Math.abs(diffInSeconds) < item.limit);
  const value = Math.round(diffInSeconds / match.divisor);

  const rtf = new Intl.RelativeTimeFormat(locale, { numeric: 'auto' });
  return rtf.format(value, match.unit);
}

const pastDate = new Date(Date.now() - 1000 * 60 * 45); // 45 minutes ago
console.log(getRelativeTime(pastDate)); // "45 minutes ago"

Tokenizing Output with formatToParts()

If you need to style the number and text independently with HTML, use formatToParts(). It returns an array of objects detailing the components of the formatted string:

const rtf = new Intl.RelativeTimeFormat('en', { numeric: 'auto' });
const parts = rtf.formatToParts(-10, 'minute');

console.log(parts);
// Output:
// [
//   { type: 'integer', value: '10', unit: 'minute' },
//   { type: 'literal', value: ' minutes ago' }
// ]

This method is useful when applying distinct CSS classes to integers or specific elements of the relative date string.
