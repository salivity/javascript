JavaScript startsWith and endsWith Position Arguments

In JavaScript, String.prototype.startsWith() and String.prototype.endsWith() determine whether a string begins or ends with a specific sequence of characters. Both methods accept an optional second parameter to alter the search boundaries, but they interpret this parameter differently: startsWith() uses it as a start index to move the left boundary forward, whereas endsWith() uses it as an expected string length to shift the right boundary backward. Understanding how these boundaries shift is essential for writing accurate substring checks and avoiding off-by-one errors.

How startsWith() Uses the position Parameter

The syntax for startsWith() is:

str.startsWith(searchString, position)

By default, position is 0. When you provide a custom position, the method shifts the starting point of the search to that zero-based index.

Functionally, this alters the boundary by ignoring everything before position. It evaluates the string as if it were sliced from that index to the end (str.slice(position)):

const text = "JavaScript is versatile";

text.startsWith("Script", 4); // true
text.startsWith("is", 11);    // true
text.startsWith("Java", 4);   // false
  • Index inclusion: The check begins at the specified index.
  • Negative or out-of-range values: If position < 0, it defaults to 0. If position >= str.length, it returns false unless searchString is an empty string "".

How endsWith() Uses the endPosition Parameter

The syntax for endsWith() is:

str.endsWith(searchString, endPosition)

By default, endPosition equals str.length. Unlike startsWith(), the second argument in endsWith() does not represent a start index; it represents the length of the string to consider, effectively serving as an exclusive upper boundary.

When you specify endPosition, the method behaves as if the string were truncated to that length using str.slice(0, endPosition):

const text = "JavaScript is versatile";

text.endsWith("Java", 4);        // true (checks "Java")
text.endsWith("Script", 10);     // true (checks "JavaScript")
text.endsWith("versatile", 10);  // false
  • Length vs. Index: An endPosition of 4 checks up to, but not including, index 4. It evaluates the first 4 characters.
  • Negative or out-of-range values: If endPosition <= 0, it returns false (unless matching an empty string ""). If endPosition > str.length, it defaults to str.length.

Key Difference in Mental Model

The fundamental difference lies in which side of the string boundary is constrained:

  • startsWith(searchString, position) sets the left boundary (inclusive). The search range becomes [position, str.length].
  • endsWith(searchString, endPosition) sets the right boundary (exclusive). The search range becomes [0, endPosition].
