Touch Swipe Velocity for Fast Dodging in JavaScript

Implementing a responsive dodge mechanic in mobile browser games requires measuring both the distance and speed of a player's swipe gesture. By capturing touch coordinates alongside precise timestamps, JavaScript calculates swipe velocity to distinguish an intentional, rapid flick from a slow pan. When this calculated speed exceeds a predefined velocity threshold, the game immediately triggers an evasive dodge maneuver, ensuring snappy, lag-free character movement.

Capturing Touch Coordinates and Time

The mechanic relies on standard DOM touch events: touchstart and touchend. To determine velocity, you must record where the touch started, where it finished, and how many milliseconds elapsed between the two events.

let touchStartX = 0;
let touchStartY = 0;
let touchStartTime = 0;

window.addEventListener('touchstart', (e) => {
    const touch = e.changedTouches[0];
    touchStartX = touch.clientX;
    touchStartY = touch.clientY;
    touchStartTime = performance.now();
}, { passive: true });

Using performance.now() provides sub-millisecond precision, which prevents rounding errors when calculating fast gestures.

Calculating Displacement and Velocity

When the user releases their finger, calculate the change in distance (\(\Delta x\), \(\Delta y\)) and the change in time (\(\Delta t\)). Velocity is defined as distance divided by time.

window.addEventListener('touchend', (e) => {
    const touch = e.changedTouches[0];
    const deltaX = touch.clientX - touchStartX;
    const deltaY = touch.clientY - touchStartY;
    const deltaTime = performance.now() - touchStartTime;

    if (deltaTime === 0) return;

    // Calculate velocity in pixels per millisecond
    const velocityX = Math.abs(deltaX) / deltaTime;
    const velocityY = Math.abs(deltaY) / deltaTime;

    evaluateDodge(deltaX, deltaY, velocityX, velocityY);
}, { passive: true });

Applying Velocity Thresholds

A standard swipe detection implementation only checks if distance exceeds a minimum pixel count. For fast dodging, you must enforce both a minimum distance threshold to prevent micro-jitters and a velocity threshold to separate deliberate dodges from casual dragging.

  • Minimum Distance: Typically between 30 and 50 pixels to ignore minor accidental finger slips.
  • Velocity Threshold: Typically between 0.5 and 1.2 pixels per millisecond (\(px/ms\)). Speeds above this indicate an aggressive flick.
const MIN_DISTANCE = 40; // pixels
const VELOCITY_THRESHOLD = 0.65; // pixels per millisecond

function evaluateDodge(deltaX, deltaY, velocityX, velocityY) {
    const absX = Math.abs(deltaX);
    const absY = Math.abs(deltaY);

    // Determine the dominant axis of movement
    if (absX > absY) {
        if (absX > MIN_DISTANCE && velocityX >= VELOCITY_THRESHOLD) {
            deltaX > 0 ? triggerDodge('right') : triggerDodge('left');
        }
    } else {
        if (absY > MIN_DISTANCE && velocityY >= VELOCITY_THRESHOLD) {
            deltaY > 0 ? triggerDodge('down') : triggerDodge('up');
        }
    }
}

Triggering the Dodge State

Once the threshold condition evaluates to true, the triggerDodge function immediately transitions the player entity into an invulnerable or rapid-movement state within the game loop.

function triggerDodge(direction) {
    if (player.isDodging || player.dodgeCooldown > 0) return;

    player.isDodging = true;
    player.dodgeDirection = direction;
    player.velocityMultiplier = 3.0; // Rapid burst speed
    player.dodgeTimer = 200; // Duration in ms
    player.dodgeCooldown = 500; // Cooldown before next dodge
}

By decoupling directional movement from simple drag offsets and tying it directly to velocity thresholds, JavaScript games can accurately simulate arcade-style evasion mechanics without input latency.
