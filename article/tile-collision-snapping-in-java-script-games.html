Tile Collision Snapping in JavaScript Games

Tile-based collision snapping is a fundamental game development technique used to prevent characters from penetrating solid obstacles by aligning their bounding boxes directly against the grid boundaries. In 2D grid-based engines, character movement often produces fractional pixel positions that overlap solid tiles. By converting continuous pixel coordinates into discrete grid coordinates, detecting overlaps, and mathematically realigning the character’s position to the edge of the colliding tile, developers achieve smooth, responsive, and bug-free movement.

Understanding Grid Coordinates vs. World Coordinates

A 2D tile-based game operates on two distinct coordinate systems:

  1. World Coordinates (Pixels): Floating-point values representing the exact visual position of entities (e.g., player.x = 142.6, player.y = 88.2).
  2. Tile Coordinates (Grid): Integer indices representing the column and row within a 2D array (e.g., col = 4, row = 2).

Converting between these two systems requires the tile size (usually a power of two, such as 16, 32, or 64 pixels).

To convert from world pixels to tile coordinates:

const tileX = Math.floor(pixelX / tileSize);
const tileY = Math.floor(pixelY / tileSize);

The Axis-Separated Movement Strategy

To snap entities cleanly without getting stuck on corners or snagging diagonally, collision detection must be executed separately for each axis:

  1. Update the horizontal position (x += vx).
  2. Check for horizontal collisions and snap to the tile edge if an overlap occurs.
  3. Update the vertical position (y += vy).
  4. Check for vertical collisions and snap to the tile edge if an overlap occurs.

The Snapping Mathematics

When a bounding box penetrates a solid tile, its position is corrected along the axis of movement by resetting the coordinate to the boundary line of the tile minus or plus the player's dimensions.

Horizontal Snapping

  • Moving Right (vx > 0): The right edge of the player (x + width) has entered a solid tile at tileX. The player must snap to the left edge of that tile:

    player.x = tileX * tileSize - player.width;
player.vx = 0;

  • Moving Left (vx < 0): The left edge of the player (x) has entered a solid tile at tileX. The player must snap to the right edge of that tile:

    player.x = (tileX + 1) * tileSize;
player.vx = 0;

Vertical Snapping

  • Moving Down (vy > 0): The bottom edge of the player (y + height) penetrates a solid tile at tileY. The player snaps to the top edge of that tile:

    player.y = tileY * tileSize - player.height;
player.vy = 0;
player.isGrounded = true;

  • Moving Up (vy < 0): The top edge of the player (y) penetrates a solid tile at tileY. The player snaps to the bottom edge of that tile:

    player.y = (tileY + 1) * tileSize;
player.vy = 0;

Implementation Example

The following JavaScript function demonstrates how to check edge points and snap an axis after movement:

function moveAndResolve(entity, map, tileSize) {
    // 1. Horizontal Movement & Collision
    entity.x += entity.vx;

    let startX = Math.floor(entity.x / tileSize);
    let endX = Math.floor((entity.x + entity.width - 1) / tileSize);
    let startY = Math.floor(entity.y / tileSize);
    let endY = Math.floor((entity.y + entity.height - 1) / tileSize);

    if (entity.vx > 0) { // Moving Right
        for (let y = startY; y <= endY; y++) {
            if (map.isSolid(endX, y)) {
                entity.x = endX * tileSize - entity.width;
                entity.vx = 0;
                break;
            }
        }
    } else if (entity.vx < 0) { // Moving Left
        for (let y = startY; y <= endY; y++) {
            if (map.isSolid(startX, y)) {
                entity.x = (startX + 1) * tileSize;
                entity.vx = 0;
                break;
            }
        }
    }

    // 2. Vertical Movement & Collision
    entity.y += entity.vy;

    startX = Math.floor(entity.x / tileSize);
    endX = Math.floor((entity.x + entity.width - 1) / tileSize);
    startY = Math.floor(entity.y / tileSize);
    endY = Math.floor((entity.y + entity.height - 1) / tileSize);

    if (entity.vy > 0) { // Moving Down
        for (let x = startX; x <= endX; x++) {
            if (map.isSolid(x, endY)) {
                entity.y = endY * tileSize - entity.height;
                entity.vy = 0;
                entity.grounded = true;
                break;
            }
        }
    } else if (entity.vy < 0) { // Moving Up
        for (let x = startX; x <= endX; x++) {
            if (map.isSolid(x, startY)) {
                entity.y = (startY + 1) * tileSize;
                entity.vy = 0;
                break;
            }
        }
    }
}

By subtracting 1 from the bounding box extents (x + width - 1), this algorithm prevents false positive collisions when an entity is resting flush against an adjacent tile boundary. The resulting snapping eliminates visual jitter and ensures deterministic physics across varying frame rates.
