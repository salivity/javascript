AVL Tree Implementation and Balancing in JavaScript

This article covers the fundamental structure and self-balancing mechanics of an AVL tree, followed by a concrete JavaScript implementation. You will learn how node heights and balance factors are calculated, how the four primary rotation algorithms (Left, Right, Left-Right, and Right-Left) restore tree equilibrium, and how to combine these operations into a functional insertion routine.

AVL Tree Structure

An AVL tree is a self-balancing binary search tree (BST). In an AVL tree, the heights of the two child subtrees of any node differ by at most one. If at any time they differ by more than one, rebalancing is performed to restore this property.

Each node in an AVL tree maintains standard BST references (left and right), a key (or value), and an explicit height property:

class AVLNode {
  constructor(key) {
    this.key = key;
    this.left = null;
    this.right = null;
    this.height = 1; // New nodes are added at leaf level with height 1
  }
}

The tree's primary structural metrics are calculated as follows:

  • Height: The length of the longest path from a node to a leaf. A null child has a height of 0.
  • Balance Factor (\(BF\)): Calculated as height(left subtree) - height(right subtree). A node is balanced when \(BF \in \{-1, 0, 1\}\).

The Balancing Algorithm

When a node insertion causes the balance factor of an ancestor to become greater than 1 or less than -1, the tree must be restructured using rotations. There are four imbalance scenarios:

  1. Left-Left (LL) Case (\(BF > 1\) and key < left child key): Fixed with a single Right Rotation.
  2. Right-Right (RR) Case (\(BF < -1\) and key > right child key): Fixed with a single Left Rotation.
  3. Left-Right (LR) Case (\(BF > 1\) and key > left child key): Fixed with a Left Rotation on the left child, followed by a Right Rotation on the current node.
  4. Right-Left (RL) Case (\(BF < -1\) and key < right child key): Fixed with a Right Rotation on the right child, followed by a Left Rotation on the current node.

Rotation Mechanics

A Right Rotation around node \(y\) with left child \(x\):

  • \(x\)'s right child becomes \(y\)'s left child.
  • \(y\) becomes \(x\)'s right child.
  • Heights of \(y\) and \(x\) are recalculated.

A Left Rotation around node \(x\) with right child \(y\):

  • \(y\)'s left child becomes \(x\)'s right child.
  • \(x\) becomes \(y\)'s left child.
  • Heights of \(x\) and \(y\) are recalculated.

JavaScript Implementation

Below is the complete implementation of the AVL tree structure, helper functions, rotations, and recursive insertion algorithm:

class AVLTree {
  constructor() {
    this.root = null;
  }

  // Get height of a node (0 if null)
  getHeight(node) {
    return node ? node.height : 0;
  }

  // Calculate balance factor
  getBalanceFactor(node) {
    return node ? this.getHeight(node.left) - this.getHeight(node.right) : 0;
  }

  // Update node height based on children
  updateHeight(node) {
    node.height = 1 + Math.max(this.getHeight(node.left), this.getHeight(node.right));
  }

  // Right rotation
  rotateRight(y) {
    const x = y.left;
    const T2 = x.right;

    // Perform rotation
    x.right = y;
    y.left = T2;

    // Update heights
    this.updateHeight(y);
    this.updateHeight(x);

    return x; // New root
  }

  // Left rotation
  rotateLeft(x) {
    const y = x.right;
    const T2 = y.left;

    // Perform rotation
    y.left = x;
    x.right = T2;

    // Update heights
    this.updateHeight(x);
    this.updateHeight(y);

    return y; // New root
  }

  // Insert a key into the tree
  insert(key) {
    this.root = this._insertNode(this.root, key);
  }

  _insertNode(node, key) {
    // 1. Standard BST insertion
    if (!node) {
      return new AVLNode(key);
    }

    if (key < node.key) {
      node.left = this._insertNode(node.left, key);
    } else if (key > node.key) {
      node.right = this._insertNode(node.right, key);
    } else {
      return node; // Duplicate keys not allowed
    }

    // 2. Update height of current node
    this.updateHeight(node);

    // 3. Get the balance factor
    const balance = this.getBalanceFactor(node);

    // 4. Balance the node if required

    // Left-Left (LL)
    if (balance > 1 && key < node.left.key) {
      return this.rotateRight(node);
    }

    // Right-Right (RR)
    if (balance < -1 && key > node.right.key) {
      return this.rotateLeft(node);
    }

    // Left-Right (LR)
    if (balance > 1 && key > node.left.key) {
      node.left = this.rotateLeft(node.left);
      return this.rotateRight(node);
    }

    // Right-Left (RL)
    if (balance < -1 && key < node.right.key) {
      node.right = this.rotateRight(node.right);
      return this.rotateLeft(node);
    }

    return node;
  }
}

Complexity

Because tree height is strictly maintained at \(O(\log n)\), all primary AVL operations—including lookup, insertion, and deletion—guarantee a worst-case time complexity of \(O(\log n)\). Rotations operate solely on reference pointers and execute in \(O(1)\) time.
