A* Pathfinding in JavaScript for Grid Navigation

The A* (A-Star) search algorithm is one of the most effective solutions for finding the shortest path between two points on a grid. This guide breaks down the core mechanics of A*, explains the scoring formula behind its heuristic search, and provides a practical, step-by-step implementation in pure JavaScript designed for 2D grid-based movement.

Core Mechanics of A*

A* evaluates potential paths by balancing the actual distance traveled with an educated guess of the remaining distance. It assigns an \(F\) score to every visited cell using the formula:

\[F = G + H\]

  • \(G\) Cost: The exact cost to move from the starting point to the current cell.
  • \(H\) Cost (Heuristic): The estimated cost from the current cell to the destination. For four-directional grid navigation, the Manhattan distance (\(|x_1 - x_2| + |y_1 - y_2|\)) is the standard metric.
  • \(F\) Cost: The sum of \(G\) and \(H\). The algorithm always evaluates the open node with the lowest \(F\) cost first.

To manage discovery, the algorithm tracks two collections:

  1. Open Set: Nodes identified but not yet fully evaluated.
  2. Closed Set: Nodes that have already been evaluated.

Step-by-Step JavaScript Implementation

1. Defining the Node and Grid

Each cell on the grid requires tracking its coordinates, traversal costs, walkability status, and a reference to its parent node to reconstruct the final path.

class Node {
  constructor(x, y, walkable = true) {
    this.x = x;
    this.y = y;
    this.walkable = walkable;
    this.g = 0;
    this.h = 0;
    this.f = 0;
    this.parent = null;
  }
}

2. The Heuristic Function

The Manhattan distance calculates the absolute grid steps required between two coordinates, ignoring diagonal movement.

function getManhattanDistance(nodeA, nodeB) {
  return Math.abs(nodeA.x - nodeB.x) + Math.abs(nodeA.y - nodeB.y);
}

3. Retrieving Neighbors

This helper identifies valid orthogonal adjacent cells (up, down, left, right) within grid boundaries.

function getNeighbors(grid, node) {
  const neighbors = [];
  const directions = [
    { x: 0, y: -1 }, // Up
    { x: 0, y: 1 },  // Down
    { x: -1, y: 0 }, // Left
    { x: 1, y: 0 }   // Right
  ];

  for (const dir of directions) {
    const checkX = node.x + dir.x;
    const checkY = node.y + dir.y;

    if (
      checkX >= 0 &&
      checkX < grid.length &&
      checkY >= 0 &&
      checkY < grid[0].length
    ) {
      neighbors.push(grid[checkX][checkY]);
    }
  }

  return neighbors;
}

4. The Pathfinding Function

The core loop iterates through the open set, finds the node with the lowest \(F\) cost, inspects its neighbors, and traces back the parent references once the target is reached.

function findPath(grid, startNode, endNode) {
  const openSet = [startNode];
  const closedSet = new Set();

  while (openSet.length > 0) {
    // 1. Find the node with the lowest f cost
    let currentIndex = 0;
    for (let i = 1; i < openSet.length; i++) {
      if (
        openSet[i].f < openSet[currentIndex].f ||
        (openSet[i].f === openSet[currentIndex].f && openSet[i].h < openSet[currentIndex].h)
      ) {
        currentIndex = i;
      }
    }

    const current = openSet.splice(currentIndex, 1)[0];
    closedSet.add(current);

    // 2. Target reached: reconstruct path
    if (current === endNode) {
      const path = [];
      let temp = current;
      while (temp) {
        path.push({ x: temp.x, y: temp.y });
        temp = temp.parent;
      }
      return path.reverse();
    }

    // 3. Process adjacent nodes
    const neighbors = getNeighbors(grid, current);
    for (const neighbor of neighbors) {
      if (!neighbor.walkable || closedSet.has(neighbor)) {
        continue;
      }

      const newMovementCost = current.g + 1;

      if (newMovementCost < neighbor.g || !openSet.includes(neighbor)) {
        neighbor.g = newMovementCost;
        neighbor.h = getManhattanDistance(neighbor, endNode);
        neighbor.f = neighbor.g + neighbor.h;
        neighbor.parent = current;

        if (!openSet.includes(neighbor)) {
          openSet.push(neighbor);
        }
      }
    }
  }

  // Return empty array if no path exists
  return [];
}

Usage Example

To run the implementation, initialize a 2D array of nodes, define unwalkable barriers, and pass the start and end nodes into findPath:

// Initialize a 5x5 grid
const rows = 5;
const cols = 5;
const grid = Array.from({ length: rows }, (_, x) =>
  Array.from({ length: cols }, (_, y) => new Node(x, y))
);

// Add an obstacle
grid[1][1].walkable = false;
grid[2][1].walkable = false;
grid[3][1].walkable = false;

const start = grid[0][1];
const target = grid[4][1];

const path = findPath(grid, start, target);
console.log(path);
// Returns the array of coordinates routing around the obstacle to the target

Performance Optimization Notes

  • Priority Queues: The code uses Array.splice to find the lowest \(F\) cost, which operates in \(O(N)\) time. For larger maps, replace the array with a Min-Heap or Binary Heap to reduce extraction time to \(O(\log N)\).
  • Diagonal Movement: If eight-directional navigation is required, include diagonal offsets in the neighbor checks and switch the heuristic function from Manhattan distance to Chebyshev or Octile distance.
