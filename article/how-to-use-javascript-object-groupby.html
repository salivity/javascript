How to Use JavaScript Object.groupBy

This article explains how the static method Object.groupBy() categorizes elements from an iterable collection into a structured object in modern JavaScript. You will learn the mechanics behind its callback-driven categorization, how keys and arrays are generated, and how it replaces older grouping patterns like Array.prototype.reduce() with cleaner, native code.

The Purpose of Object.groupBy()

Introduced in ECMAScript 2024, Object.groupBy() provides a native, standardized mechanism for partitioning iterable collections—such as arrays—into groups without relying on utility libraries like Lodash or complex custom logic.

The method accepts two arguments:

  1. items: The iterable collection to process.
  2. callbackFn: A function executed for each element to determine which group key it belongs to.

It returns a null-prototype object whose keys are the group names returned by the callback, and whose values are arrays containing the matching items.

Syntax and Basic Mechanics

Object.groupBy(items, callbackFn(element, index))

During execution, Object.groupBy() iterates over the collection sequentially. For each item:

  1. It executes callbackFn(element, index).
  2. The callback returns a value that serves as the group identifier.
  3. The return value is coerced to a string (or Symbol).
  4. If the key does not exist on the target object, JavaScript initializes it with an empty array.
  5. The current element is pushed into the array associated with that key.

Grouping by an Existing Property

The most common use case is grouping an array of objects by a shared property value, such as a category or role.

const inventory = [
  { name: "Apples", type: "fruit", quantity: 10 },
  { name: "Carrots", type: "vegetable", quantity: 5 },
  { name: "Bananas", type: "fruit", quantity: 22 },
  { name: "Broccoli", type: "vegetable", quantity: 8 }
];

const result = Object.groupBy(inventory, item => item.type);

The resulting object structures the items under their respective types:

{
  fruit: [
    { name: "Apples", type: "fruit", quantity: 10 },
    { name: "Bananas", type: "fruit", quantity: 22 }
  ],
  vegetable: [
    { name: "Carrots", type: "vegetable", quantity: 5 },
    { name: "Broccoli", type: "vegetable", quantity: 8 }
  ]
}

Dynamic Conditional Grouping

The callback function is not limited to returning existing properties. It can compute arbitrary strings based on conditional logic.

const scores = [45, 82, 90, 58, 74, 95];

const gradeBuckets = Object.groupBy(scores, score => {
  if (score >= 90) return "excellent";
  if (score >= 60) return "passing";
  return "needsImprovement";
});

Output:

{
  excellent: [90, 95],
  passing: [82, 74],
  needsImprovement: [45, 58]
}

Key Characteristics to Consider

  • Null-Prototype Return: The object returned by Object.groupBy() does not inherit from Object.prototype. This means standard methods like result.hasOwnProperty() are not present on the returned object, which prevents accidental property collisions with user-defined keys.
  • String Coercion: All non-Symbol keys returned by callbackFn are converted to strings. If you need keys to retain non-primitive identities (such as objects), use Map.groupBy() instead.
  • Immutability: The input iterable remains unchanged; a new object is created and populated.
