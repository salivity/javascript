Guide to Canvas createPattern and createLinearGradient

The HTML5 Canvas 2D API enables rich visual styling beyond flat colors through pattern and gradient generators. Both createPattern() and createLinearGradient() return specialized objects—a CanvasPattern and a CanvasGradient respectively—that act as styles when assigned to ctx.fillStyle or ctx.strokeStyle. This article explains how each method computes color values across canvas pixels, how coordinates influence rendering, and how to implement both techniques effectively in JavaScript.

How createLinearGradient Generates Fills

The createLinearGradient(x0, y0, x1, y1) method creates an interpolated color transition along an invisible line segment defined by two points: a start point (x0, y0) and an end point (x1, y1).

Syntax and Color Stops

const gradient = ctx.createLinearGradient(x0, y0, x1, y1);
gradient.addColorStop(offset, color);
  1. Vector Definition: The coordinates determine the angle and length of the gradient vector.
  2. Color Interpolation: Colors are mapped using addColorStop(offset, color), where offset is a float from 0.0 (start) to 1.0 (end). The canvas engine interpolates RGBA values linearly along perpendicular lines relative to this vector.
  3. Out-of-Bounds Behavior: Pixels positioned before (x0, y0) along the vector axis take the color of the first stop (offset 0.0). Pixels past (x1, y1) take the color of the last stop (offset 1.0).

Code Example

const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');

// Create a horizontal gradient from x=20 to x=220
const linearGrad = ctx.createLinearGradient(20, 0, 220, 0);
linearGrad.addColorStop(0, '#ff7e5f');
linearGrad.addColorStop(1, '#feb47b');

// Apply and draw
ctx.fillStyle = linearGrad;
ctx.fillRect(20, 20, 200, 100);

How createPattern Generates Fills

The createPattern(image, repetition) method produces a tiled fill based on a graphical source. The source can be an HTMLImageElement, HTMLCanvasElement, HTMLVideoElement, or ImageBitmap.

Syntax and Repetition Rules

const pattern = ctx.createPattern(imageSource, repetition);

The repetition parameter determines how the image tiles across the space:

  • 'repeat': Tiles horizontally and vertically.
  • 'repeat-x': Tiles horizontally only.
  • 'repeat-y': Tiles vertically only.
  • 'no-repeat': Displays the image once at its origin.

When drawing, the canvas engine samples pixels from the source element based on the target canvas pixel coordinates modulo the source image dimensions (factoring in the repetition rule).

Code Example

const img = new Image();
img.src = 'texture.png';
img.onload = () => {
  const pattern = ctx.createPattern(img, 'repeat');
  
  ctx.fillStyle = pattern;
  ctx.fillRect(0, 0, 500, 500);
};

Coordinate Spaces and Alignment

A critical aspect of both methods is that fills are bound to the canvas coordinate space, not to the individual shape being drawn.

  • Linear Gradients: The coordinates (x0, y0) and (x1, y1) match canvas absolute coordinates. If you draw a rectangle at (300, 300) using a gradient defined between (0, 0) and (100, 0), the rectangle will only display the clamped color of the gradient's final stop unless the coordinates are adjusted or the context is translated using ctx.translate().
  • Patterns: Patterns anchor their top-left origin (0, 0) to the canvas origin by default. To offset, rotate, or scale a pattern independently of the canvas grid, apply an SVGMatrix using pattern.setTransform(matrix).
