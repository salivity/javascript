Canvas 2D globalCompositeOperation Blend Modes

This guide provides a comprehensive overview of the globalCompositeOperation property in the HTML5 Canvas 2D API, explaining how it controls the rendering behavior when drawing new shapes onto existing canvas content. By manipulating this property, developers can create masking effects, clipping paths, and complex visual blends using either Porter-Duff compositing operators or modern color blending modes.

In the Canvas 2D API, the source refers to the new shape or image being drawn, while the destination refers to the pixels already rendered on the canvas. Setting ctx.globalCompositeOperation = mode alters how these two layers interact.

Porter-Duff Compositing Operators

These modes govern shape clipping, masking, and overlapping geometry based on pixel transparency (alpha values).

  • source-over (Default): Draws the source shape on top of the destination canvas.
  • source-in: Draws the source only where it overlaps with the existing destination. Everything else becomes transparent.
  • source-out: Draws the source only where it does not overlap with the destination.
  • source-atop: Draws the source only where it overlaps the destination, preserving the destination's background underneath.
  • destination-over: Draws the source behind the existing canvas content.
  • destination-in: Keeps the destination where it overlaps the source; everything else, including the source itself, becomes transparent.
  • destination-out: Keeps the destination where it does not overlap the source, effectively using the source as an eraser.
  • destination-atop: Retains the destination only where it overlaps the source, with the source drawn underneath.
  • lighter: Adds the color and alpha values of both source and destination pixels, creating an additive lightening effect.
  • copy: Discards all existing canvas content and only draws the new source shape.
  • xor: Renders both source and destination, but clears to transparent anywhere the two overlap.

Color Blending Modes

These modes mix the color channels of the source and destination rather than just their alpha masks, mirroring blend modes commonly found in graphic design software.

  • multiply: Multiplies the color values of the source and destination pixels, resulting in a darker color.
  • screen: Inverts, multiplies, and inverts the colors again, resulting in a brighter image (the opposite of multiply).
  • overlay: Combines multiply and screen. It multiplies dark colors and screens light colors, preserving highlights and shadows.
  • darken: Retains the darkest pixel value from either the source or destination for each color channel.
  • lighten: Retains the lightest pixel value from either the source or destination for each color channel.
  • color-dodge: Divides the destination color by the inverse of the source color, significantly brightening the underlying pixels.
  • color-burn: Inverts the destination color, divides it by the source, and inverts again, producing a high-contrast darkening effect.
  • hard-light: Similar to overlay, but checks the luminance of the source instead of the destination, creating harsh lighting effects.
  • soft-light: A subtler version of hard-light, applying a gentle lightening or darkening effect akin to a diffused spotlight.
  • difference: Subtracts the darker color from the lighter color, producing high-contrast, inverted visuals.
  • exclusion: Similar to difference, but produces lower contrast without harsh extremes.

HSL Component Modes

These modes isolate and apply individual HSL (Hue, Saturation, Lightness) components between the source and destination.

  • hue: Applies the hue of the source to the saturation and luminosity of the destination.
  • saturation: Applies the saturation of the source to the hue and luminosity of the destination.
  • color: Applies both the hue and saturation of the source to the luminosity of the destination, effectively colorizing monochrome layers.
  • luminosity: Applies the luminosity of the source to the hue and saturation of the destination, preserving the destination's colors while altering its brightness.
