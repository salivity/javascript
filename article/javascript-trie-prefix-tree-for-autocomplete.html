JavaScript Trie Prefix Tree for Autocomplete

A Trie, or prefix tree, is an efficient tree-based data structure optimized for storing and retrieving strings over a dynamic dataset. In this article, you will learn how to build a Trie from scratch in JavaScript to power an autocomplete feature. We will cover the design of individual Trie nodes, implementing insertion logic, and using depth-first search to extract all stored words matching a given search prefix.

Understanding the Trie Structure

Unlike a binary search tree, nodes in a Trie do not store their own keys. Instead, a node's position in the tree defines the character it represents. All descendants of a node share a common prefix associated with that node.

To build an autocomplete system, each node requires:

  1. children: A key-value map (or plain object) holding references to child nodes corresponding to characters.
  2. isEndOfWord: A boolean flag indicating whether the node marks the completion of a full word.
class TrieNode {
  constructor() {
    this.children = {};
    this.isEndOfWord = false;
  }
}

Constructing the Trie Class

The Trie class initializes an empty root node and manages operations like inserting words and querying prefixes.

class Trie {
  constructor() {
    this.root = new TrieNode();
  }

  // Insertion logic
  insert(word) {
    let current = this.root;
    const lowerWord = word.toLowerCase();

    for (const char of lowerWord) {
      if (!current.children[char]) {
        current.children[char] = new TrieNode();
      }
      current = current.children[char];
    }

    current.isEndOfWord = true;
  }
}

When inserting a word:

  • Start at this.root.
  • For every character in the string, check if a child node exists for that character.
  • If it does not exist, create a new TrieNode.
  • Move the pointer to that child node.
  • Once all characters are processed, set isEndOfWord = true on the final node.

Implementing Autocomplete Logic

Autocomplete consists of two phases:

  1. Prefix Traversal: Navigate down the tree matching each character of the input prefix. If any character is missing, the prefix does not exist in the Trie, returning an empty array.
  2. Word Collection: Once the end of the prefix is reached, traverse all descendant nodes using Depth-First Search (DFS) to collect every word branching from that point.
class Trie {
  constructor() {
    this.root = new TrieNode();
  }

  insert(word) {
    let current = this.root;
    const lowerWord = word.toLowerCase();

    for (const char of lowerWord) {
      if (!current.children[char]) {
        current.children[char] = new TrieNode();
      }
      current = current.children[char];
    }

    current.isEndOfWord = true;
  }

  autocomplete(prefix) {
    let current = this.root;
    const lowerPrefix = prefix.toLowerCase();

    // 1. Locate the prefix node
    for (const char of lowerPrefix) {
      if (!current.children[char]) {
        return []; // Prefix not found
      }
      current = current.children[char];
    }

    // 2. Collect all words extending from the prefix node
    const results = [];
    this._collectWords(current, lowerPrefix, results);
    return results;
  }

  _collectWords(node, currentWord, results) {
    if (node.isEndOfWord) {
      results.push(currentWord);
    }

    for (const char in node.children) {
      this._collectWords(node.children[char], currentWord + char, results);
    }
  }
}

Usage Example

To see the Trie autocomplete in action:

const searchIndex = new Trie();

// Populate the index
const words = ["apple", "app", "application", "apt", "banana", "band", "bandwidth"];
words.forEach(word => searchIndex.insert(word));

// Query suggestions
console.log(searchIndex.autocomplete("app"));
// Output: ["app", "apple", "application"]

console.log(searchIndex.autocomplete("ban"));
// Output: ["banana", "band", "bandwidth"]

console.log(searchIndex.autocomplete("car"));
// Output: []

Performance Characteristics

  • Insertion Time Complexity: O(L), where L is the length of the string being inserted.
  • Prefix Lookup Time Complexity: O(P), where P is the length of the search prefix to reach the target node.
  • Collection Time Complexity: O(N), where N is the total number of descendant nodes under the target prefix.

Because the prefix lookup depends solely on the length of the search term rather than the total size of your dataset, a Trie provides near-instantaneous responses suitable for real-time input fields.
