ES2021: Numeric Separators and Promise Handling

ECMAScript 2021 (ES12) introduced practical updates to the JavaScript specification, highlighted by numeric separators for enhanced visual clarity and Promise.any() for resilient asynchronous operations. These additions simplified how developers manage large numerical constants and race multiple asynchronous tasks, eliminating common boilerplate patterns and reducing runtime oversights.

Enhancing Numeric Readability with Numeric Separators

Prior to ES2021, reading and verifying large numbers in source code was error-prone, as numbers like 1000000000 required careful counting of digits. ECMAScript 2021 solved this by introducing numeric separators using the underscore (_) character.

Separators act strictly as visual cues for developers and are ignored by the JavaScript engine during parsing and execution:

// Before ES2021
const byteLimit = 1000000000;
const hexMask = 0xFFD700;

// In ES2021
const byteLimit = 1_000_000_000;
const hexMask = 0xFF_D7_00;
const microSecs = 0.000_001;
const largeBigInt = 9_223_372_036_854_775_807n;

Numeric separators work across standard decimal numbers, binary literals (0b), octal literals (0o), hexadecimal literals (0x), and BigInt values. They remove ambiguity without altering variable types or runtime performance.

Smarter Asynchronous Control with Promise.any

ES2021 significantly improved promise management by introducing Promise.any(). While Promise.race() settles as soon as any promise either resolves or rejects, Promise.any() focuses strictly on the first successful operation.

Promise.any() accepts an iterable of promises and fulfills as soon as any single promise in the collection fulfills. If individual promises reject along the way, they are ignored as long as at least one promise resolves:

const primaryEndpoint = fetch("https://primary.example.com/data");
const backupEndpoint = fetch("https://backup.example.com/data");

try {
  // Resolves with whichever endpoint returns data first, even if one fails
  const response = await Promise.any([primaryEndpoint, backupEndpoint]);
  const data = await response.json();
} catch (error) {
  // Triggers only if ALL passed promises reject
  console.error("All endpoints failed:", error.errors);
}

Comprehensive Failure Tracking with AggregateError

To complement Promise.any(), ES2021 introduced the AggregateError object. If every promise passed to Promise.any() fails, the returned promise rejects with an AggregateError. This error wraps all individual rejection reasons inside an errors array property, allowing developers to inspect each failure cause without losing debugging context.

Together, numeric separators and Promise.any() represent ES2021’s focus on developer ergonomics—making source code cleaner to read and asynchronous network patterns easier to implement reliably.
