JavaScript Bullet Hell Circular Spread Patterns

Creating circular projectile spreads in bullet hell (danmaku) games involves calculating equal angular distributions around an origin point and applying standard trigonometry to determine each bullet's trajectory. In JavaScript game programming, this is accomplished by dividing a complete circle—measured in radians—by the total number of projectiles, and using Math.cos() and Math.sin() within an execution loop to assign horizontal and vertical velocities to each newly instantiated projectile.

The Underlying Trigonometry

A standard 2D cartesian coordinate system requires moving an object along the X and Y axes independently. To make a projectile move outward in a specific direction at a constant speed, you convert polar coordinates (an angle \(\theta\) and a speed \(r\)) into Cartesian coordinates (velocities \(v_x\) and \(v_y\)).

A full circular rotation equals \(2\pi\) radians (or approximately 6.28318 radians). If an attack requires \(N\) bullets, the angular step between each adjacent bullet is calculated as:

const angleStep = (Math.PI * 2) / bulletCount;

For each bullet in the sequence, its specific direction is \(angle = index \times angleStep\). The directional velocity components are then calculated as:

  • \(v_x = \text{speed} \times \cos(angle)\)
  • \(v_y = \text{speed} \times \sin(angle)\)

JavaScript Implementation

The following function demonstrates how to generate an array of bullet objects forming an omnidirectional ring from a central coordinate:

function createCircularSpread(originX, originY, count, speed, initialOffset = 0) {
    const bullets = [];
    const angleStep = (Math.PI * 2) / count;

    for (let i = 0; i < count; i++) {
        // Calculate the absolute angle for this projectile
        const angle = i * angleStep + initialOffset;

        // Determine X and Y components of the velocity vector
        const vx = Math.cos(angle) * speed;
        const vy = Math.sin(angle) * speed;

        bullets.push({
            x: originX,
            y: originY,
            vx: vx,
            vy: vy,
            angle: angle
        });
    }

    return bullets;
}

Frame-by-Frame Update Loop

Once spawned, the game's update loop shifts each bullet's position using its calculated velocity vectors on every frame:

function updateBullets(bullets, deltaTime) {
    for (let i = 0; i < bullets.length; i++) {
        const bullet = bullets[i];
        bullet.x += bullet.vx * deltaTime;
        bullet.y += bullet.vy * deltaTime;
    }
}

Because velocity is pre-calculated at the moment of emission, the game engine does not need to recalculate expensive trigonometric functions on every frame for linear trajectories, maintaining optimal 60 FPS performance even with hundreds of active sprites.

Creating Spirals and Complex Variations

To transform a static ring burst into dynamic patterns like spirals or flowers, developers modify the initialOffset parameter over time. Incrementing this offset on each successive ring emission creates a rotating emitter:

let currentRotation = 0;

function gameTick() {
    // Spawns a rotating 12-way spread every interval
    if (shouldShoot) {
        const ring = createCircularSpread(boss.x, boss.y, 12, 200, currentRotation);
        activeBullets.push(...ring);
        currentRotation += 0.1; // Rotates subsequent rings
    }
}

By altering the speed parameter for each bullet based on sine waves, or by applying a continuous angular velocity inside the bullet update function, this foundational circular formula scales into the complex visual geometry typical of bullet hell shooters.
