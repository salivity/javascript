JavaScript Function Length with Default and Rest Parameters

In JavaScript, a function's length property reports its arity—the number of arguments the function expects to receive. However, modern features like default parameter values and rest parameters change how this property behaves. When these features are present, the length property only counts the parameters defined before the first parameter with a default value and entirely excludes any rest parameters.

The Basic Definition of Function.prototype.length

Traditionally, the length property of a function reflects the total count of formal parameters declared in the function signature:

function basic(a, b, c) {}
console.log(basic.length); // 2

This count represents the contract specified by the function definition, regardless of how many arguments are actually passed during execution.

How Default Parameters Affect length

When default parameters are introduced, JavaScript stops counting parameters as soon as it encounters the first default parameter. Any parameters following it—even if they do not have default values—are excluded from the length count.

function withDefaults(a, b = 10, c) {}
console.log(withDefaults.length); // 1

In the example above, a is counted, but b has a default value. Because b is encountered, the count stops immediately, and both b and c are omitted from the total.

If the first parameter in the signature has a default value, the function's length will be 0:

function defaultFirst(a = 1, b, c) {}
console.log(defaultFirst.length); // 0

How Rest Parameters Affect length

Rest parameters (...args) allow a function to accept an indefinite number of arguments as an array. Because a rest parameter does not represent a single formal parameter, the JavaScript specification explicitly excludes it from the length calculation.

function withRest(a, b, ...rest) {}
console.log(withRest.length); // 2

Here, only a and b are counted. The ...rest parameter contributes nothing to the count. If a function contains only a rest parameter, its length is 0:

function onlyRest(...args) {}
console.log(onlyRest.length); // 0

Combining Default and Rest Parameters

When combining regular parameters, default parameters, and rest parameters, the rules apply sequentially:

  1. Parameters are counted from left to right.
  2. The count increments for each regular parameter.
  3. The count terminates as soon as the first default parameter or a rest parameter is reached.
function combined(a, b, c = 5, d, ...rest) {}
console.log(combined.length); // 2

In this case, a and b are regular parameters (count: 2). Parameter c has a default value, terminating the count. Parameter d and the rest parameter ...rest are ignored.

Function.prototype.length vs. arguments.length

It is important to distinguish function.length from arguments.length:

  • function.length is static and describes the number of expected arguments up to the first default or rest parameter.
  • arguments.length is dynamic and reflects the actual number of arguments passed into the function at runtime.

Understanding this distinction is essential when writing higher-order functions, currying utilities, or libraries that rely on function arity to determine behavior dynamically.
