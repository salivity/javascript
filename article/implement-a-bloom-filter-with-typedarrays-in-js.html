Implement a Bloom Filter with TypedArrays in JS

A Bloom filter is a space-efficient, probabilistic data structure designed to test whether an element is a member of a set, allowing for false positives but guaranteeing no false negatives. This article demonstrates how to implement a Bloom filter in JavaScript using Uint8Array to manage bits directly at the byte level. By leveraging TypedArrays and optimal hash distribution, you can drastically reduce memory overhead when checking for the existence of millions of items in client-side or Node.js environments.

Core Mechanics of a Bloom Filter

A Bloom filter consists of two primary components:

  1. A Bit Array: An array of \(m\) bits, all initially set to 0.
  2. \(k\) Independent Hash Functions: Functions that map any input key to one of the \(m\) array positions with a uniform distribution.
  • Adding an item: The item is passed through all \(k\) hash functions to obtain \(k\) array indices. The bits at these indices are set to 1.
  • Querying an item: The item is hashed with the same \(k\) functions. If all corresponding bits are 1, the item might be in the set. If any bit is 0, the item is definitely not in the set.

Bit Manipulation with TypedArrays

JavaScript numbers are 64-bit floats, and standard arrays introduce significant memory overhead. A Uint8Array allows compact storage where each element represents 8 individual bits.

To locate and modify a specific bit index (bitIndex):

  • Byte index: bitIndex >> 3 (equivalent to Math.floor(bitIndex / 8))
  • Bit offset within byte: bitIndex & 7 (equivalent to bitIndex % 8)
  • Set bit: buffer[byteIndex] |= (1 << bitOffset)
  • Test bit: (buffer[byteIndex] & (1 << bitOffset)) !== 0

Hash Function Strategy

Rather than computing \(k\) distinct hash functions, you can use the Kirsch-Mitzenmacher technique. By generating two 32-bit hash values (\(h_1\) and \(h_2\)), you can simulate \(k\) independent hash functions using the formula:

\[g_i(x) = (h_1(x) + i \cdot h_2(x)) \pmod m\]

Below, we use standard 32-bit FNV-1a and a secondary variant to generate the base hashes.

Complete Implementation

class BloomFilter {
  /**
   * @param {number} size - Total number of bits (m)
   * @param {number} hashes - Number of hash functions (k)
   */
  constructor(size = 1024, hashes = 4) {
    this.size = size;
    this.hashes = hashes;
    this.buffer = new Uint8Array(Math.ceil(size / 8));
  }

  /**
   * Calculates optimal size (m) and hashes (k) based on expected items and false positive rate.
   * @param {number} expectedItems - Expected number of elements (n)
   * @param {number} falsePositiveRate - Target false positive probability (p)
   */
  static createOptimal(expectedItems, falsePositiveRate = 0.01) {
    const m = Math.ceil(
      (-expectedItems * Math.log(falsePositiveRate)) / (Math.log(2) ** 2)
    );
    const k = Math.round((m / expectedItems) * Math.log(2));
    return new BloomFilter(m, k);
  }

  // 32-bit FNV-1a Hash
  _hash1(str) {
    let hash = 0x811c9dc5;
    for (let i = 0; i < str.length; i++) {
      hash ^= str.charCodeAt(i);
      hash = Math.imul(hash, 0x01000193);
    }
    return hash >>> 0;
  }

  // Secondary hash using a different seed/multiplier
  _hash2(str) {
    let hash = 0x811c9dc5;
    for (let i = 0; i < str.length; i++) {
      hash = Math.imul(hash ^ str.charCodeAt(i), 0x5bd1e995);
      hash ^= hash >>> 15;
    }
    return hash >>> 0;
  }

  /**
   * Generates bit positions for an item.
   * @param {string} item
   * @returns {number[]}
   */
  _getIndices(item) {
    const str = String(item);
    const h1 = this._hash1(str);
    const h2 = this._hash2(str);
    const indices = [];

    for (let i = 0; i < this.hashes; i++) {
      const combined = (h1 + Math.imul(i, h2)) >>> 0;
      indices.push(combined % this.size);
    }
    return indices;
  }

  /**
   * Adds an item to the filter.
   * @param {string} item
   */
  add(item) {
    const indices = this._getIndices(item);
    for (const bitIndex of indices) {
      const byteIndex = bitIndex >> 3;
      const bitOffset = bitIndex & 7;
      this.buffer[byteIndex] |= 1 << bitOffset;
    }
  }

  /**
   * Checks if an item is possibly in the filter.
   * @param {string} item
   * @returns {boolean}
   */
  has(item) {
    const indices = this._getIndices(item);
    for (const bitIndex of indices) {
      const byteIndex = bitIndex >> 3;
      const bitOffset = bitIndex & 7;
      if ((this.buffer[byteIndex] & (1 << bitOffset)) === 0) {
        return false; // Definitely not in set
      }
    }
    return true; // Possibly in set
  }
}

Usage Example

// Initialize for 10,000 items with a 1% (0.01) false-positive threshold
const filter = BloomFilter.createOptimal(10000, 0.01);

// Add items
filter.add("alice@example.com");
filter.add("bob@example.com");

// Verify presence
console.log(filter.has("alice@example.com")); // true (correct)
console.log(filter.has("charlie@example.com")); // false (correct)

// Inspect memory footprint
console.log(`Buffer size: ${filter.buffer.byteLength} bytes`);
// ~11,982 bytes for 10,000 items at 1% error rate

Performance Considerations

  • Time Complexity: Both add and has operate in \(O(k)\) time, where \(k\) is the number of hash iterations. Because \(k\) is constant relative to input size, operations run in effectively \(O(1)\) time.
  • Memory Footprint: A standard JavaScript Set storing 10,000 strings typically consumes several hundred kilobytes. The Uint8Array Bloom filter manages this state in under 12 KB of raw binary memory.
  • Deletion: Standard Bloom filters do not support item removal because clearing a bit can inadvertently delete other keys that share the same bit index.
