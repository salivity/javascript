Pursuit and Evasion Vector Math in JavaScript Games

In game artificial intelligence, calculating believable pursuit and evasion behaviors requires more than simply moving an entity toward a target's current position. Instead, an AI agent must predict where the target will be in the future and steer toward that predicted intercept point. This article breaks down the mathematical vector calculations behind predictive interception and evasion, demonstrating how to implement these algorithms cleanly using 2D vectors in JavaScript game programming.

Core Vector Concepts

Predictive steering relies on Craig Reynolds’ steering behavior framework, which defines steering force as:

\[\text{Steering Force} = \text{Desired Velocity} - \text{Current Velocity}\]

Direct seeking targets an entity's current coordinates. Pursuit, by contrast, targets a calculated future position based on the target’s velocity. Evasion uses the exact same prediction math as pursuit, but reverses the resulting steering vector to flee from the predicted point.

Calculating the Interception Look-Ahead Time

To determine where a target will be, the pursuer needs to estimate how many frames or seconds into the future it will take to reach the target.

A standard approximation estimates time (\(T\)) by dividing the distance between the pursuer and the target by the pursuer's maximum speed:

\[T = \frac{|\vec{P}_{\text{target}} - \vec{P}_{\text{pursuer}}|}{\text{Speed}_{\text{max}}}\]

Once \(T\) is determined, the target's predicted future position (\(\vec{P}_{\text{future}}\)) is calculated using its current velocity (\(\vec{V}_{\text{target}}\)):

\[\vec{P}_{\text{future}} = \vec{P}_{\text{target}} + (\vec{V}_{\text{target}} \times T)\]

2D Vector Helper in JavaScript

Before implementing pursuit logic, a minimal vector class handles necessary operations:

class Vector2D {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }

  add(v) { return new Vector2D(this.x + v.x, this.y + v.y); }
  subtract(v) { return new Vector2D(this.x - v.x, this.y - v.y); }
  multiply(scalar) { return new Vector2D(this.x * scalar, this.y * scalar); }
  
  magnitude() { 
    return Math.hypot(this.x, this.y); 
  }

  normalize() {
    const mag = this.magnitude();
    return mag > 0 ? new Vector2D(this.x / mag, this.y / mag) : new Vector2D(0, 0);
  }

  truncate(max) {
    return this.magnitude() > max ? this.normalize().multiply(max) : this;
  }
}

Implementing Pursuit

In pursuit, the agent calculates look-ahead time, projects the target position, and applies standard seek behavior toward that point:

function calculatePursuit(pursuer, target, maxPredictionTime = 2.0) {
  const displacement = target.position.subtract(pursuer.position);
  const distance = displacement.magnitude();

  // Dynamic look-ahead time clamped to avoid overshooting at long distances
  let lookAheadTime = distance / pursuer.maxSpeed;
  lookAheadTime = Math.min(lookAheadTime, maxPredictionTime);

  // Predict future position
  const predictedPosition = target.position.add(
    target.velocity.multiply(lookAheadTime)
  );

  // Seek predicted position
  const desiredDirection = predictedPosition.subtract(pursuer.position).normalize();
  const desiredVelocity = desiredDirection.multiply(pursuer.maxSpeed);

  // Calculate steering force
  const steeringForce = desiredVelocity.subtract(pursuer.velocity);
  return steeringForce.truncate(pursuer.maxForce);
}

Implementing Evasion

Evasion uses the same look-ahead prediction as pursuit, but negates the direction vector to steer directly away from the predicted point:

function calculateEvasion(evader, pursuer, maxPredictionTime = 2.0) {
  const displacement = pursuer.position.subtract(evader.position);
  const distance = displacement.magnitude();

  let lookAheadTime = distance / evader.maxSpeed;
  lookAheadTime = Math.min(lookAheadTime, maxPredictionTime);

  // Predict where the pursuer will be
  const predictedPosition = pursuer.position.add(
    pursuer.velocity.multiply(lookAheadTime)
  );

  // Flee from predicted position (direction is reversed: evader - predicted)
  const desiredDirection = evader.position.subtract(predictedPosition).normalize();
  const desiredVelocity = desiredDirection.multiply(evader.maxSpeed);

  const steeringForce = desiredVelocity.subtract(evader.velocity);
  return steeringForce.truncate(evader.maxForce);
}

Managing Edge Cases

  1. Target Ahead and Facing Pursuer: If the target is directly in front of the pursuer and heading toward it, predicting far ahead causes the pursuer to steer behind the target. In this scenario, set look-ahead time to zero and seek directly.
  2. Prediction Clamping: If the target is extremely far away, \(T\) becomes excessively large, resulting in erratic predictions if the target turns. Always clamp look-ahead time with an upper bound (maxPredictionTime).
  3. Updating the Game Loop: The resulting steering vector should be added to the entity’s velocity each frame, scaled by delta time, and clamped to the entity's maximum allowable speed.
