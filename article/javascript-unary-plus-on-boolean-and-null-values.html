JavaScript Unary Plus on Boolean and Null Values

The JavaScript unary plus operator (+) provides a concise mechanism for converting non-numeric data types into numbers. When applied to boolean values and null, the operator triggers implicit type coercion via the ECMAScript abstract ToNumber operation. As a result, applying the unary plus operator converts true to 1, false to 0, and null to 0. This article details how this conversion operates under the hood and outlines the precise behavior of each case with practical examples.

How the Unary Plus Operator Operates

The unary plus operator precedes its operand and attempts to convert it into a numeric primitive. It behaves identically to calling the built-in Number() constructor as a function, but with a more compact syntax.

+x === Number(x)

If the operand cannot be converted into a meaningful number, the operation evaluates to NaN (Not-a-Number). However, both booleans and null have strictly defined numeric conversions in the ECMAScript specification that resolve to concrete integers.

Unary Plus Applied to Boolean Values

Booleans represent binary states: true and false. In numeric contexts within JavaScript, these states map directly to standard binary digits:

  • +true results in 1
  • +false results in 0

Examples:

console.log(+true);  // Output: 1
console.log(+false); // Output: 0

// Equivalent to:
console.log(Number(true));  // Output: 1
console.log(Number(false)); // Output: 0

This conversion is frequently used in quick calculations or flags where boolean values must contribute to a mathematical sum, such as counting completed steps or active toggle states:

const hasSubscription = true;
const hasCoupon = false;

const discountPoints = +hasSubscription + +hasCoupon; // 1 + 0 = 1

Unary Plus Applied to Null

The null primitive represents the intentional absence of any object value. In numeric type coercion, JavaScript treats null as an empty or zero value.

  • +null results in 0

Example:

console.log(+null); // Output: 0

// Equivalent to:
console.log(Number(null)); // Output: 0

It is worth distinguishing null from undefined in this context. While +null evaluates to 0, applying a unary plus to undefined evaluates to NaN. This distinction occurs because null represents a defined state of emptiness (evaluating to base zero), whereas undefined indicates a missing value that cannot be quantified.

console.log(+null);      // Output: 0
console.log(+undefined); // Output: NaN

Summary of Results

Expression Evaluated Result Underlying Conversion
+true 1 ToNumber(true) -> 1
+false 0 ToNumber(false) -> 0
+null 0 ToNumber(null) -> 0

Using the unary plus operator on booleans and null is a safe and predictable operation in JavaScript, consistently producing either 0 or 1 without throwing runtime errors.
