How to Set CSS Important Flag with setProperty

Dynamically applying CSS styles with elevated priority in JavaScript often requires the !important declaration, but standard property assignment fails to register this flag. The CSSStyleDeclaration.setProperty() method provides the native solution by accepting an optional priority flag as its third parameter. This article explains how setProperty() processes priority flags, the correct syntax required to apply them, how to inspect their priority, and common mistakes to avoid.

The Syntax of setProperty()

The setProperty() method accepts three parameters:

style.setProperty(propertyName, value, priority);
  • propertyName: A string representing the CSS property name to modify (kebab-case, e.g., 'background-color').
  • value: A string containing the new property value. If omitted or set to an empty string, the property is removed.
  • priority: An optional string indicating priority. To apply the !important rule, pass the exact string 'important'. If normal priority is desired, pass an empty string "" or omit the argument.

Applying the Important Flag

When working directly with properties via the style object (such as element.style.color = 'red !important'), browsers silently discard the assignment because !important is not a valid CSS value syntax within the CSS Object Model (CSSOM).

To apply !important, use the third parameter of setProperty() without an exclamation mark:

const targetElement = document.querySelector('.my-element');

// Correct usage: pass 'important' as the third argument
targetElement.style.setProperty('color', 'red', 'important');
targetElement.style.setProperty('margin-top', '20px', 'important');

The browser will render this inline as:

<div class="my-element" style="color: red !important; margin-top: 20px !important;"></div>

Checking and Removing Priority

To inspect whether a property has an important priority flag applied, use the getPropertyPriority() method on the CSSStyleDeclaration object:

const priority = targetElement.style.getPropertyPriority('color');
console.log(priority); // Outputs: "important"

If the property has standard priority, getPropertyPriority() returns an empty string "".

To downgrade an existing property to standard priority without changing its value, call setProperty() again with an empty string as the third parameter:

targetElement.style.setProperty('color', 'red', '');
