JavaScript Game Menu Key Repeat Rate Handling

Key repeat rate handling is a technique used in JavaScript game development to control how fast a menu cursor moves when a player holds down a navigation key. Because operating systems and browsers have varying, unpredictable default repeat delays, games must implement custom input timing to ensure menu navigation feels responsive, predictable, and uniform across all devices.

The Problem with Native Browser Key Repeat

When a user holds down a key, the browser fires an initial keydown event, pauses for an operating system-defined delay (usually between 250ms and 500ms), and then fires repeated keydown events at a fixed frequency (typically 30Hz to 60Hz). In JavaScript, these repeated events have their event.repeat property set to true.

Relying on this native behavior in game menus introduces several problems:

  • Inconsistent Experience: A player with aggressive OS repeat settings will scroll through options too quickly, while a player with standard settings may experience an awkward delay before scrolling starts.
  • Menu Overshooting: Rapid native repeats often cause the selection cursor to skip past the intended menu item.
  • Platform Discrepancies: Different browsers and platforms manage keyboard repeating differently, leading to inconsistent gameplay across environments.

How Custom Key Repeat Handling Works

To solve these issues, game developers decouple menu navigation from browser repeat events. Instead of executing actions on every keydown event, the game monitors key states and uses an internal timer within the game loop to trigger navigation steps.

This pattern relies on two primary configuration variables:

  • Initial Delay: The time a player must hold a direction key before continuous scrolling begins (typically 300ms to 400ms). This prevents accidental multiple inputs when the player only intended a single tap.
  • Repeat Rate (Interval): The speed at which the menu cycles through items once continuous scrolling is active (typically 80ms to 150ms per step).

Implementation in JavaScript

The most robust way to manage key repeat rates is by tracking keyboard state and updating the timer inside your game loop's update function.

class MenuController {
  constructor(menuItems) {
    this.items = menuItems;
    this.selectedIndex = 0;

    // Timing configurations (in milliseconds)
    this.initialDelay = 350;
    this.repeatInterval = 100;

    // State tracking
    this.heldKey = null;
    this.keyHoldTimer = 0;
    this.nextRepeatTime = 0;

    this.bindEvents();
  }

  bindEvents() {
    window.addEventListener("keydown", (e) => {
      // Ignore native browser repeat events
      if (e.repeat) return;

      if (e.key === "ArrowUp" || e.key === "ArrowDown") {
        this.heldKey = e.key;
        this.keyHoldTimer = 0;
        this.nextRepeatTime = this.initialDelay;
        
        // Immediate action on the first key press
        this.navigate(e.key === "ArrowDown" ? 1 : -1);
      }
    });

    window.addEventListener("keyup", (e) => {
      if (e.key === this.heldKey) {
        this.heldKey = null;
        this.keyHoldTimer = 0;
      }
    });
  }

  update(deltaTime) {
    if (!this.heldKey) return;

    this.keyHoldTimer += deltaTime;

    // Trigger repeated movement when the threshold is reached
    if (this.keyHoldTimer >= this.nextRepeatTime) {
      this.navigate(this.heldKey === "ArrowDown" ? 1 : -1);
      this.nextRepeatTime += this.repeatInterval;
    }
  }

  navigate(direction) {
    this.selectedIndex = (this.selectedIndex + direction + this.items.length) % this.items.length;
    console.log(`Selected item: ${this.items[this.selectedIndex]}`);
  }
}

Key Considerations

When implementing custom repeat handling, keep these practices in mind:

  • Gamepad and Keyboard Parity: Apply the same repeat logic to directional pad (D-pad) and analog stick inputs to keep gamepad navigation consistent with keyboard navigation.
  • Delta Time Scaling: Always advance repeat timers using frame delta time (deltaTime) rather than fixed frame increments, ensuring navigation speed remains consistent regardless of the monitor's refresh rate.
  • Audio Feedback: Play subtle interface sound effects on both the initial press and each repeated trigger to give players clear feedback that holding the key is performing actions.
