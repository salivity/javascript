JavaScript indexOf Empty String Behavior

In JavaScript, calling String.prototype.indexOf() with an empty string as the search value returns 0 by default, rather than -1. When an optional fromIndex argument is provided, the method returns that index clamped between 0 and the target string's length. This guide explains the exact mechanics behind this behavior, how different position values alter the output, and what the ECMAScript specification dictates for this edge case.

The Default Behavior

When you pass an empty string ("") to indexOf without a second argument, it returns 0:

"hello".indexOf(""); // Returns 0
"".indexOf("");      // Returns 0

Because an empty string contains no characters, it is considered conceptually present at every possible boundary in a string, starting before the first character at index 0. Even when searching an empty string, the result is 0.

How fromIndex Affects the Result

The indexOf() method accepts an optional second parameter: fromIndex. When searching for an empty string, the return value directly reflects fromIndex, bounded by 0 and string.length:

  1. Within string boundaries (0 <= fromIndex <= string.length): The method returns the exact value of fromIndex.
  2. Negative values (fromIndex < 0): The method treats negative numbers as 0 and returns 0.
  3. Values exceeding length (fromIndex > string.length): The method clamps the return value to the string's total length.

Examples

const str = "JavaScript"; // str.length is 10

// Valid boundaries
str.indexOf("", 0);  // Returns 0
str.indexOf("", 4);  // Returns 4
str.indexOf("", 10); // Returns 10

// Negative index (treated as 0)
str.indexOf("", -5); // Returns 0

// Beyond string length (clamped to str.length)
str.indexOf("", 15); // Returns 10

Why JavaScript Behaves This Way

According to the ECMAScript specification, an empty string is a valid substring at every position from index 0 up to string.length.

When searchValue is "", the algorithm does not perform character-matching loops. Instead, it computes min(max(fromIndex, 0), string.length) and immediately returns that position. It will never return -1 when the search string is empty.
