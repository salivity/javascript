Normal Map Specular Highlights in JavaScript WebGL

Normal mapped lighting adds fine surface detail to 3D geometry without increasing polygon counts, while specular highlights simulate the bright reflections of light sources off shiny surfaces. In JavaScript game programming using WebGL or Three.js, calculating specular highlights with normal mapping requires reading per-pixel normal vectors from a texture, converting these vectors into a shared coordinate space, and applying a lighting equation—such as the Blinn-Phong model—in a GLSL fragment shader.

The Role of Normal Maps in Lighting

Standard 3D meshes define vertex normals across polygons, which produce smooth but flat surfaces when interpolated. A normal map stores fine directional surface normals in an RGB texture, where the red, green, and blue color channels correspond to the X, Y, and Z vector components.

Before lighting math can occur, the sampled normal must be converted from texture color space [0.0, 1.0] back to vector direction space [-1.0, 1.0]:

vec3 normal = texture2D(uNormalMap, vUv).rgb * 2.0 - 1.0;

Coordinate Spaces and the TBN Matrix

A normal map's vectors are usually defined in tangent space, a localized coordinate system relative to the surface plane. To calculate reflections accurately, all vectors—the surface normal (\(N\)), the light direction (\(L\)), and the view/camera direction (\(V\))—must exist in the same coordinate space.

JavaScript game engines typically handle this by passing vertex attributes (Tangent, Bitangent, Normal) to create a TBN transformation matrix in the vertex or fragment shader:

  1. Tangent Space Approach: Transform the light direction and view direction into tangent space using the inverse of the TBN matrix.
  2. World/View Space Approach: Transform the sampled normal vector into world or view space by multiplying it directly with the TBN matrix:
vec3 N = normalize(vTBN * normal);

Calculating the Specular Highlight (Blinn-Phong)

Once the perturbed normal (\(N\)), light vector (\(L\)), and view vector (\(V\)) are in the same coordinate space and normalized, the specular reflection is calculated. The Blinn-Phong reflection model is preferred in real-time WebGL engines because it is computationally efficient and avoids costly reflection vector calculations.

  1. Calculate the Halfway Vector (\(H\)): Find the vector halfway between the light direction and the viewer direction. \[H = \text{normalize}(L + V)\]

  2. Calculate the Specular Factor: Compute the dot product of the normal (\(N\)) and the halfway vector (\(H\)). Clamp the result between 0.0 and 1.0 to prevent negative lighting.

  3. Apply Shininess Exponent: Raise the dot product to a power representing the material's shininess (glossiness). Higher exponents produce tighter, sharper highlights.

vec3 L = normalize(uLightPosition - vFragPosition);
vec3 V = normalize(uCameraPosition - vFragPosition);
vec3 H = normalize(L + V);

float specFactor = max(dot(N, H), 0.0);
float specular = pow(specFactor, uShininess);

Complete Fragment Shader Pipeline

In a JavaScript engine, the rendering loop updates uniforms (uLightPosition, uCameraPosition, uNormalMap, uShininess) and issues draw calls. The fragment shader resolves the specular highlight per-pixel:

precision mediump float;

uniform sampler2D uNormalMap;
uniform vec3 uLightColor;
uniform vec3 uLightPosition;
uniform vec3 uCameraPosition;
uniform float uShininess;

varying vec2 vUv;
varying vec3 vFragPosition;
varying mat3 vTBN;

void main() {
    // 1. Unpack normal from map and transform via TBN
    vec3 sampledNormal = texture2D(uNormalMap, vUv).rgb * 2.0 - 1.0;
    vec3 N = normalize(vTBN * sampledNormal);

    // 2. Compute direction vectors
    vec3 L = normalize(uLightPosition - vFragPosition);
    vec3 V = normalize(uCameraPosition - vFragPosition);
    vec3 H = normalize(L + V);

    // 3. Diffuse factor (specular should not show where light does not reach)
    float NdotL = max(dot(N, L), 0.0);

    // 4. Specular calculation
    float NdotH = max(dot(N, H), 0.0);
    float specFactor = pow(NdotH, uShininess);
    vec3 specularColor = uLightColor * specFactor * step(0.0, NdotL);

    gl_FragColor = vec4(specularColor, 1.0);
}

Because the calculation relies on the per-pixel normal \(N\) extracted from the normal map, the specular glints follow every crease, groove, and bump on the textured surface as the light or camera moves.
