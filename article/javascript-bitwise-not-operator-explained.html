JavaScript Bitwise NOT Operator Explained

The bitwise NOT operator (~) in JavaScript is a unary operator that inverts the bits of its operand. When applied to numbers, it converts the value into a 32-bit signed integer, flips every bit (turning 0s into 1s and 1s into 0s), and returns the resulting 32-bit signed integer. In simple arithmetic terms, applying ~x always produces the mathematical result of -(x + 1).

Step-by-Step Execution

When JavaScript encounters the ~ operator on a number, it executes the following steps:

  1. Conversion to 32-Bit Integer: Standard JavaScript numbers are 64-bit floating-point values (IEEE 754). The bitwise NOT operator truncates any fractional parts and converts the number into a 32-bit two's complement signed integer.
  2. Bit Inversion: Every bit in the 32-bit representation is inverted.
  3. Evaluation: The resulting two's complement binary representation is interpreted back as a JavaScript number.

The Mathematical Shortcut

Because modern computers use two's complement format to store signed integers, inverting the bits of any integer x yields:

~x === -(x + 1)

Examples:

  • ~5 evaluates to -(5 + 1) = -6
  • ~(-6) evaluates to -(-6 + 1) = 5
  • ~0 evaluates to -(0 + 1) = -1
  • ~(-1) evaluates to -(-1 + 1) = 0

Handling Decimals and Non-Integers

Because the operator enforces conversion to a 32-bit signed integer, it discards fractional values before performing the inversion:

  • ~5.9 is treated as ~5, producing -6.
  • ~(-3.2) is treated as ~(-3), producing 2.

Values outside the 32-bit signed integer range (-2,147,483,648 to 2,147,483,647) will wrap around according to modular arithmetic.

Handling Non-Finite Numbers

If ~ is used on non-finite numbers such as NaN or Infinity, JavaScript coerces these values to 0 before inverting:

  • ~NaN evaluates to -1
  • ~Infinity evaluates to -1
  • ~(-Infinity) evaluates to -1

Practical Applications

  1. Index Checking (Legacy Pattern): Before methods like Array.prototype.includes() were introduced, developers frequently used ~ with indexOf(). Since indexOf() returns -1 when an item is not found, ~(-1) evaluates to 0 (a falsy value). Any valid index (0 or greater) evaluates to a non-zero truthy number: 
    if (~str.indexOf("query")) {
  // Found
}
  2. Fast Truncation (~~): Applying the bitwise NOT operator twice (~~) inverts the bits back to their original state while retaining the integer truncation step, serving as a shorthand for Math.trunc() for numbers within the 32-bit range: 
    ~~4.9; // 4
~~-4.9; // -4
