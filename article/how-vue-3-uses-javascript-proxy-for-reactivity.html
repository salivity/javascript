How Vue 3 Uses JavaScript Proxy for Reactivity

Vue 3 relies on JavaScript Proxy objects to power its reactivity system, completely replacing the Object.defineProperty mechanism used in Vue 2. By wrapping state objects inside a proxy, Vue intercepts fundamental operations such as reading, writing, and deleting properties through handler functions called traps. This architecture enables seamless dependency tracking and update triggering while overcoming previous limitations with dynamically added properties and array mutations.

The Role of JavaScript Proxy

A Proxy object wraps another target object and intercepts internal operations performed on it. Instead of mutating the original object to attach getters and setters to specific properties, Vue 3 wraps the entire object within a proxy handler.

When you define reactive state using reactive(), Vue passes the target object to a factory function that instantiates a new Proxy with specialized trap handlers:

const reactiveState = new Proxy(target, {
  get(target, key, receiver) { /* trap logic */ },
  set(target, key, value, receiver) { /* trap logic */ },
  deleteProperty(target, key) { /* trap logic */ },
  has(target, key) { /* trap logic */ }
});

The get Trap: Dependency Tracking

The get trap intercepts any operation that reads a property from the proxy. When code reads reactiveState.count, the get trap executes the following steps:

  1. Retrieve the Value: It reads the property using Reflect.get(target, key, receiver), ensuring that this context binds correctly inside custom getters.
  2. Track Dependencies (track): If a reactive effect (such as a component render function, a watchEffect, or a computed property) is currently running, Vue registers that active effect as a subscriber to (target, key).
  3. Lazy Nesting: If the retrieved value is an object, Vue recursively wraps it in a reactive proxy on demand. Unlike Vue 2, which recursively converted deeply nested objects upfront, Vue 3 performs this lazily upon access, substantially improving initialization performance.

The set Trap: Triggering Updates

The set trap intercepts any property assignment, such as reactiveState.count = 2. When a property modification occurs, the set trap coordinates the update:

  1. Compare Values: It checks whether the new value is actually different from the existing value to avoid redundant re-renders.
  2. Identify Operation Type: It determines if the operation adds a brand-new key (ADD) or modifies an existing one (SET).
  3. Apply the Change: It updates the raw target object using Reflect.set(target, key, value, receiver).
  4. Trigger Effects (trigger): It looks up all effects subscribed to (target, key) in Vue's internal dependency registry and schedules them to re-run. If a new property was added, it also triggers effects monitoring array lengths or iteration keys.

Additional Traps: deleteProperty and has

Vue 3 handles operations that were previously impossible to detect reliably in earlier versions:

  • deleteProperty: Intercepts the delete operator (e.g., delete reactiveState.count). Vue updates the target object via Reflect.deleteProperty and invokes trigger to alert effects that rely on the deleted key or object keys enumeration.
  • has: Intercepts the in operator (e.g., 'count' in reactiveState). Vue runs track to record that an effect depends on the existence of that property.

The Dependency Registry Structure

To connect traps to reactive effects, Vue maintains a centralized dependency tree using nested collections:

  • targetMap (WeakMap): Maps raw target objects to property maps. Using a WeakMap ensures that garbage collection is not blocked when targets fall out of scope.
  • depsMap (Map): Maps specific property keys to a set of effects.
  • dep (Set): Stores the distinct effect functions subscribed to that specific key.

When the get trap calls track(), it adds the active effect to the relevant dep Set. When the set or deleteProperty trap calls trigger(), it extracts that dep Set and executes each subscribed effect, synchronizing the user interface with the modified state.
