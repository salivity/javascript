Circle-to-Circle Collision in JavaScript

Circle-to-circle collision detection is a fundamental technique in 2D game development used to determine when two round objects overlap. This guide explains the core mathematical principles behind radial collision detection—specifically the Pythagorean theorem—and demonstrates how to efficiently implement this logic in JavaScript game programming using optimized distance calculations.

The Mathematical Foundation

A circle in a 2D coordinate plane is defined by two properties: a center point \((x, y)\) and a radius \(r\).

When two circles intersect, the distance between their center points is less than or equal to the sum of their radii. Mathematically, the condition for collision between Circle A (\(x_1, y_1, r_1\)) and Circle B (\(x_2, y_2, r_2\)) is:

\[\text{Distance} \le r_1 + r_2\]

To calculate the Euclidean distance between the two center points, use the Pythagorean theorem:

\[\text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]

Combining these gives the complete collision formula:

\[\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} \le r_1 + r_2\]

The Performance Optimization

In game loops running at 60 frames per second or higher, calculating square roots via Math.sqrt() is computationally expensive, especially when checking dozens or hundreds of entities against each other.

To optimize this calculation, eliminate the square root by squaring both sides of the inequality:

\[(x_2 - x_1)^2 + (y_2 - y_1)^2 \le (r_1 + r_2)^2\]

By comparing the squared distance against the squared sum of the radii, you achieve the exact same collision result using only basic arithmetic operations: subtraction, multiplication, and addition.

JavaScript Implementation

Here is the standard, optimized implementation of circle-to-circle collision detection in JavaScript:

function checkCircleCollision(circleA, circleB) {
  // Calculate horizontal and vertical distances
  const dx = circleB.x - circleA.x;
  const dy = circleB.y - circleA.y;

  // Calculate squared distance between centers
  const distanceSquared = dx * dx + dy * dy;

  // Calculate squared sum of both radii
  const radiusSum = circleA.radius + circleB.radius;
  const radiusSumSquared = radiusSum * radiusSum;

  // Returns true if intersecting, false otherwise
  return distanceSquared <= radiusSumSquared;
}

Example Usage

const player = { x: 100, y: 150, radius: 20 };
const enemy = { x: 130, y: 150, radius: 15 };

if (checkCircleCollision(player, enemy)) {
  console.log("Collision detected!");
}

In this example:

  • Horizontal distance (\(dx\)) = \(130 - 100 = 30\)
  • Vertical distance (\(dy\)) = \(150 - 150 = 0\)
  • Squared distance = \(30^2 + 0^2 = 900\)
  • Combined radius = \(20 + 15 = 35\)
  • Squared radius sum = \(35^2 = 1225\)

Since \(900 \le 1225\), the function evaluates to true.

Resolving the Collision

Detecting an overlap is typically followed by collision resolution to prevent objects from passing through each other. To separate two colliding circles, calculate the actual distance using Math.sqrt(distanceSquared) and move each circle away along the collision normal:

function resolveCircleCollision(circleA, circleB) {
  const dx = circleB.x - circleA.x;
  const dy = circleB.y - circleA.y;
  const distance = Math.sqrt(dx * dx + dy * dy);

  // Prevent division by zero if centers are identical
  if (distance === 0) return;

  const overlap = (circleA.radius + circleB.radius) - distance;
  
  // Normalized direction vectors
  const normalX = dx / distance;
  const normalY = dy / distance;

  // Push both objects apart equally
  circleA.x -= normalX * (overlap / 2);
  circleA.y -= normalY * (overlap / 2);
  circleB.x += normalX * (overlap / 2);
  circleB.y += normalY * (overlap / 2);
}

This ensures objects separate smoothly along the axis of collision without visual jittering.
