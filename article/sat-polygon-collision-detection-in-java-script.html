SAT Polygon Collision Detection in JavaScript

This article provides a practical guide to implementing the Separating Axis Theorem (SAT) for convex polygon collision detection in JavaScript game programming. You will learn the underlying mathematical concept of SAT, how to calculate normal projection axes from polygon edges, how to project vertices using vector dot products, and how to write a functional JavaScript collision test that can determine whether two convex shapes intersect.

The Core Concept of SAT

The Separating Axis Theorem states that two convex shapes do not collide if there exists an axis (a 1D line) onto which the projections (shadows) of the two shapes do not overlap. If you can find even one separating axis, the shapes are separated. If the projections overlap across all possible candidate axes, the shapes are colliding.

SAT strictly applies to convex polygons—shapes where all interior angles are 180 degrees or less and no line drawn between two points inside the shape passes outside it. For concave shapes, developers must first decompose the geometry into multiple convex sub-polygons.

Identifying Candidate Axes

In 2D space, you do not need to test an infinite number of axes. The only axes that matter are the perpendicular vectors (normals) to the edges of both polygons.

  1. Loop through each edge of Polygon A and Polygon B.
  2. Calculate the edge vector: (x2 - x1, y2 - y1).
  3. Obtain the perpendicular normal vector: (-dy, dx) or (dy, -dy).
  4. Normalize the normal vector to a unit vector for consistency.

If Polygon A has 4 sides and Polygon B has 3 sides, there are a maximum of 7 candidate axes to test.

Projecting Polygons onto an Axis

To project a 2D shape onto a 1D axis, compute the dot product of each vertex position with the normalized axis vector:

\[\text{projection} = \mathbf{vertex} \cdot \mathbf{axis} = (vertex.x \times axis.x) + (vertex.y \times axis.y)\]

Evaluating the dot product for every vertex in a polygon produces a set of scalar values. The minimum and maximum scalar values represent the bounds of that polygon’s 1D shadow along the given axis.

Overlap Detection

Once you have the minimum and maximum projections for both shapes on a given axis:

  • Polygon A range: [minA, maxA]
  • Polygon B range: [minB, maxB]

You test whether these two intervals overlap:

if (maxA < minB || maxB < minA) {
    // Gap found: an axis separates the shapes
    return false;
}

If a gap is found on any axis, the algorithm immediately exits and returns false—no collision has occurred.

JavaScript Implementation

Below is a complete implementation of SAT collision detection between two 2D convex polygons defined as arrays of points {x, y}.

class SAT {
    // Vector dot product
    static dot(a, b) {
        return a.x * b.x + a.y * b.y;
    }

    // Get the perpendicular normal of an edge
    static getNormal(p1, p2) {
        const dx = p2.x - p1.x;
        const dy = p2.y - p1.y;
        const length = Math.hypot(-dy, dx);
        return { x: -dy / length, y: dx / length };
    }

    // Project all vertices of a polygon onto an axis
    static projectPolygon(axis, vertices) {
        let min = this.dot(axis, vertices[0]);
        let max = min;

        for (let i = 1; i < vertices.length; i++) {
            const projection = this.dot(axis, vertices[i]);
            if (projection < min) min = projection;
            if (projection > max) max = projection;
        }

        return { min, max };
    }

    // Retrieve all edge normals for a polygon
    static getAxes(vertices) {
        const axes = [];
        for (let i = 0; i < vertices.length; i++) {
            const p1 = vertices[i];
            const p2 = vertices[(i + 1) % vertices.length];
            axes.push(this.getNormal(p1, p2));
        }
        return axes;
    }

    // Main collision detection function
    static checkCollision(polyA, polyB) {
        const axes = [...this.getAxes(polyA), ...this.getAxes(polyB)];

        for (const axis of axes) {
            const projA = this.projectPolygon(axis, polyA);
            const projB = this.projectPolygon(axis, polyB);

            // Check for a separating gap
            if (projA.max < projB.min || projB.max < projA.min) {
                return false; // Separating axis found
            }
        }

        return true; // Overlap on all axes
    }
}

Collision Response and MTV

Beyond boolean detection, SAT can calculate the Minimum Translation Vector (MTV) required to resolve collisions. By tracking which tested axis produces the smallest overlap amount along with its direction, you get the shortest displacement vector needed to push the overlapping shapes apart without causing visual clipping or sticking.
