Crowd Simulation Collision Separation in JavaScript

In JavaScript game development, crowd simulation relies on collision separation algorithms to create realistic, autonomous movements for multiple on-screen entities. Without separation logic, entities moving toward a shared target will overlap, condense into a single point, and break immersion. This article explains the mechanics of collision separation, why bunching occurs, and the mathematical techniques and JavaScript implementations developers use to keep agents moving naturally without clumping together.

What Is Collision Separation?

Collision separation is a reactive steering behavior initially formalized by Craig Reynolds in his 1987 "Boids" model. In crowd simulation, it acts as a localized repulsive force. While pathfinding algorithms like A* or flow fields instruct an agent where to go globally, collision separation dictates how an agent behaves locally relative to its immediate neighbors.

Every agent scans its surrounding perimeter within a defined "comfort radius." When another agent enters this radius, a repulsive vector is computed to push the agent away from the encroaching neighbor.

Why Agents Bunch Together

Bunching happens primarily because standard pathfinding evaluates agents individually rather than collectively. If one hundred agents are tasked with chasing a player or navigating through a narrow doorway, their pathfinding algorithms will generate near-identical optimal paths.

Without local avoidance or volume constraints:

  • Agents share identical velocity vectors.
  • Agents occupy the exact same coordinate space simultaneously.
  • Performance drops if complex collision physics engines attempt to resolve dozens of simultaneous interpenetrations at a single coordinate.

Core Techniques to Prevent Bunching

Developers primarily combine two methods to handle multi-agent separation in 2D canvas or WebGL games:

1. Reynolds Separation Steering Force

Separation force prevents bunching before it occurs. The algorithm iterates through neighboring agents, calculates the distance to each, and applies a steering force inversely proportional to that distance. The closer a neighbor is, the stronger the repulsive force applied.

\[\vec{F}_{\text{separation}} = \sum_{i=1}^{n} \frac{\vec{P}_{\text{agent}} - \vec{P}_{\text{neighbor}_i}}{\|\vec{P}_{\text{agent}} - \vec{P}_{\text{neighbor}_i}\|^2}\]

2. Positional Constraint Relaxation (Elastic Separation)

When steering forces fail to prevent an overlap (e.g., inside narrow corridors), positional correction immediately pushes overlapping bounding circles apart so they do not render on top of each other.

If the distance between two agents with radius \(r\) is less than \(2r\), the overlap distance is: \[\text{overlap} = 2r - \text{distance}\]

Both agents are then moved directly away from each other along their collision normal by half of the overlap value: \[\vec{P}_{\text{agent}} += \vec{N} \times (\text{overlap} \times 0.5)\]

Implementing Separation in JavaScript

Below is a standard JavaScript implementation of a separation steering behavior within an update loop:

class Agent {
  constructor(x, y, radius = 12) {
    this.position = { x, y };
    this.velocity = { x: 0, y: 0 };
    this.acceleration = { x: 0, y: 0 };
    this.radius = radius;
    this.maxSpeed = 2.5;
    this.maxForce = 0.1;
    this.desiredSeparation = radius * 2.5;
  }

  separate(neighbors) {
    let steer = { x: 0, y: 0 };
    let count = 0;

    for (let i = 0; i < neighbors.length; i++) {
      const other = neighbors[i];
      const dx = this.position.x - other.position.x;
      const dy = this.position.y - other.position.y;
      const distance = Math.hypot(dx, dy);

      // Check if neighbor is within separation zone and not self
      if (distance > 0 && distance < this.desiredSeparation) {
        // Calculate vector pointing away from neighbor
        let diffX = dx / distance;
        let diffY = dy / distance;

        // Weight inversely by distance (closer = stronger push)
        diffX /= distance;
        diffY /= distance;

        steer.x += diffX;
        steer.y += diffY;
        count++;
      }
    }

    if (count > 0) {
      steer.x /= count;
      steer.y /= count;

      // Scale to max speed
      const steerLength = Math.hypot(steer.x, steer.y);
      if (steerLength > 0) {
        steer.x = (steer.x / steerLength) * this.maxSpeed;
        steer.y = (steer.y / steerLength) * this.maxSpeed;

        // Reynolds steering formula: Steering = Desired - Velocity
        steer.x -= this.velocity.x;
        steer.y -= this.velocity.y;

        // Clamp force to prevent erratic twitching
        const forceLength = Math.hypot(steer.x, steer.y);
        if (forceLength > this.maxForce) {
          steer.x = (steer.x / forceLength) * this.maxForce;
          steer.y = (steer.y / forceLength) * this.maxForce;
        }
      }
    }

    return steer;
  }

  applyForce(force) {
    this.acceleration.x += force.x;
    this.acceleration.y += force.y;
  }

  update() {
    this.velocity.x += this.acceleration.x;
    this.velocity.y += this.acceleration.y;

    // Cap velocity
    const speed = Math.hypot(this.velocity.x, this.velocity.y);
    if (speed > this.maxSpeed) {
      this.velocity.x = (this.velocity.x / speed) * this.maxSpeed;
      this.velocity.y = (this.velocity.y / speed) * this.maxSpeed;
    }

    this.position.x += this.velocity.x;
    this.position.y += this.velocity.y;

    // Reset acceleration for next frame
    this.acceleration.x = 0;
    this.acceleration.y = 0;
  }
}

Optimizing Crowd Separation at Scale

Calculating distances between all agents requires \(O(n^2)\) operations, which quickly degrades JavaScript performance when crowd counts exceed a few hundred.

To maintain 60 frames per second:

  • Spatial Partitioning: Implement a uniform grid or Quadtree. Agents only query neighbors within their current and adjacent grid cells, reducing checks to roughly \(O(n)\).
  • TypedArrays: Store agent coordinates in flat Float32Array structures to leverage cache locality and avoid Garbage Collection pauses.
  • Update Throttling: Run separation checks on alternating agents every other frame rather than processing every entity on every tick.
