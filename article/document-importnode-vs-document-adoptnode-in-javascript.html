document.importNode vs document.adoptNode in JavaScript

Both document.importNode() and document.adoptNode() are DOM methods used to bring a node from an external document—such as an <iframe>, an HTMLTemplateElement, or a newly fetched XML/HTML document—into the current document. The fundamental difference between them lies in whether the original node is copied or moved: importNode() creates a duplicate of the source node, leaving the original intact, whereas adoptNode() moves the original node into the new document, stripping it from its original context.

What is document.importNode()?

document.importNode() creates a clone of an external node so it can be inserted into the current document. The original node remains unchanged in its source document.

Syntax

const importedNode = document.importNode(externalNode, deep);
  • externalNode: The node you want to import.
  • deep: A boolean flag. If true, the node and its entire subtree (including child elements and text) are cloned. If false, only the node itself is copied without children.

Example

const iframe = document.querySelector('iframe');
const externalElement = iframe.contentDocument.querySelector('#target');

// Clone the external node and its children
const clonedNode = document.importNode(externalElement, true);

// Append the clone to the host document
document.body.appendChild(clonedNode);

// The original element still exists inside the iframe
console.log(iframe.contentDocument.querySelector('#target')); // HTMLElement

What is document.adoptNode()?

document.adoptNode() transfers an external node directly into the current document. Instead of creating a copy, it modifies the node’s ownerDocument property to reference the adopting document and removes the node from its source document hierarchy.

Syntax

const adoptedNode = document.adoptNode(externalNode);
  • externalNode: The node you want to adopt.
  • There is no deep parameter because adoptNode() automatically moves the node and all of its descendants.

Example

const iframe = document.querySelector('iframe');
const externalElement = iframe.contentDocument.querySelector('#target');

// Move the node to the current document
const movedNode = document.adoptNode(externalElement);

// Append the node to the host document
document.body.appendChild(movedNode);

// The original element is gone from the source iframe
console.log(iframe.contentDocument.querySelector('#target')); // null

Key Differences

Feature document.importNode() document.adoptNode()
Action Clones (copies) the node. Moves (adopts) the original node.
Source Document Retains the original node. Loses the original node.
Parameters (node, deep) (node)
Children Handling Controlled by the deep boolean flag. Always includes all descendants.
Memory Impact Allocates new memory for the clone. Reuses existing node in memory.

When to Use Which

  • Use document.importNode() when you need to reuse an element multiple times (such as reading from an <template> tag) or when you must leave the source document unaltered.
  • Use document.adoptNode() when you want to migrate elements out of an iframe or another document permanently, avoiding the unnecessary memory overhead of creating duplicate DOM trees.
