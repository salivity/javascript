Aspect Ratio Scaling and Letterboxing in JavaScript Games

Screen scaling and letterboxing are essential techniques in web game development that ensure a game renders correctly across diverse screen resolutions without stretching, clipping, or distorting visuals. This article covers the fundamental mechanics of screen scaling, the role of letterboxing and pillarboxing in preserving a fixed aspect ratio, and the practical mathematical steps required to implement these techniques using JavaScript and the HTML5 Canvas API.

Understanding Screen Scaling

Screen scaling is the process of adjusting the visual output of a game to match the display boundaries of the player's device, whether it is a mobile phone, tablet, or ultrawide desktop monitor. In JavaScript game development, games are typically designed around a fixed internal resolution (for example, 1920x1080 or 800x600).

Because end users resize browser windows or access games on screens with varying physical dimensions, games cannot simply expand to fill 100% of the viewport width and height. Doing so naively results in non-uniform scaling, causing circles to appear as ovals and sprite art to become pixelated or warped.

The Purpose of Letterboxing

Letterboxing solves aspect ratio mismatch by enforcing uniform scaling across both the X and Y axes. When a target viewport does not match the game's native aspect ratio, the rendering engine scales the game uniformly until it touches the edges of the screen in one dimension, and fills the remaining empty space with solid borders (often black).

  • Letterboxing: Black bars placed at the top and bottom of the screen when the display is taller than the game's aspect ratio.
  • Pillarboxing: Black bars placed on the left and right sides of the screen when the display is wider than the game's aspect ratio.

Implementing Letterboxing in JavaScript

To maintain aspect ratios using letterboxing, you must determine the appropriate scaling factor during window initialization and every subsequent resize event.

1. Calculating the Scale Factor

The scale factor determines how much the canvas can grow without exceeding the window dimensions or altering its aspect ratio. It is calculated by finding the minimum ratio between the window dimensions and the native game dimensions:

const nativeWidth = 1920;
const nativeHeight = 1080;

function calculateScale(windowWidth, windowHeight) {
    const scaleX = windowWidth / nativeWidth;
    const scaleY = windowHeight / nativeHeight;
    return Math.min(scaleX, scaleY);
}

2. Sizing and Centering the Canvas

Once the scale factor is obtained, apply it to the canvas display size, not the internal rendering resolution. The internal canvas properties (canvas.width and canvas.height) should remain locked to the native dimensions to preserve crisp rendering. The CSS display size (canvas.style.width and canvas.style.height) adapts to the scale factor:

function resizeGame(canvas) {
    const windowWidth = window.innerWidth;
    const windowHeight = window.innerHeight;
    const scale = calculateScale(windowWidth, windowHeight);

    const scaledWidth = Math.floor(nativeWidth * scale);
    const scaledHeight = Math.floor(nativeHeight * scale);

    canvas.style.width = `${scaledWidth}px`;
    canvas.style.height = `${scaledHeight}px`;
}

Centering the canvas in the viewport creates the letterbox or pillarbox effect. The most performant and reliable approach is using CSS flexbox on the canvas parent container:

body {
    margin: 0;
    background-color: #000000;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    overflow: hidden;
}

Translating Input Coordinates

When a canvas is scaled and letterboxed, mouse and touch event coordinates no longer map 1:1 to game coordinates. To handle inputs accurately, screen-space coordinates must be normalized back to native game dimensions:

function getCanvasMousePosition(event, canvas) {
    const rect = canvas.getBoundingClientRect();
    const clientX = event.clientX - rect.left;
    const clientY = event.clientY - rect.top;

    const gameX = clientX * (canvas.width / rect.width);
    const gameY = clientY * (canvas.height / rect.height);

    return { x: gameX, y: gameY };
}

Using these scaling, styling, and coordinate translation steps guarantees that game assets appear uniformly proportional on any screen size while maintaining accurate collision and UI interactions.
