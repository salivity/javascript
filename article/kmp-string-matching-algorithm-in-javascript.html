KMP String Matching Algorithm in JavaScript

The Knuth-Morris-Pratt (KMP) algorithm is an efficient string searching method that searches for occurrences of a "pattern" within a main "text" in linear \(O(n + m)\) time. Unlike naive search approaches that reset checking to the beginning after a mismatch, KMP preprocesses the pattern to skip redundant comparisons. This guide demonstrates how KMP works and provides a clean, step-by-step implementation in JavaScript using the Longest Proper Prefix which is also a Suffix (LPS) array.

Step 1: Building the LPS Array

The foundation of the KMP algorithm is the LPS (Longest Prefix Suffix) array. For every index i in the pattern, lps[i] stores the length of the longest proper prefix of the subpattern pattern[0...i] that is also a suffix of this subpattern.

When a mismatch occurs, this array informs the search pointer where to jump next without re-evaluating characters that are already known to match.

function computeLPSArray(pattern) {
  const lps = new Array(pattern.length).fill(0);
  let length = 0; // Length of the previous longest prefix suffix
  let i = 1;

  while (i < pattern.length) {
    if (pattern[i] === pattern[length]) {
      length++;
      lps[i] = length;
      i++;
    } else {
      if (length !== 0) {
        // Fall back to the previous prefix length
        length = lps[length - 1];
      } else {
        lps[i] = 0;
        i++;
      }
    }
  }

  return lps;
}

Step 2: Implementing the Search Function

With the LPS array generated, the main search scans the text. Pointer i moves through the text, while pointer j tracks matches in the pattern. If a mismatch occurs after some matches, j is updated to lps[j - 1] instead of resetting to 0, preventing backtracking in the text.

function kmpSearch(text, pattern) {
  if (!pattern || !text || pattern.length > text.length) {
    return [];
  }

  const lps = computeLPSArray(pattern);
  const matches = []; // Stores starting indices of matches

  let i = 0; // Index for text
  let j = 0; // Index for pattern

  while (i < text.length) {
    if (pattern[j] === text[i]) {
      i++;
      j++;
    }

    // Found a complete match
    if (j === pattern.length) {
      matches.push(i - j);
      j = lps[j - 1]; // Reset pattern index using LPS to find next match
    } else if (i < text.length && pattern[j] !== text[i]) {
      if (j !== 0) {
        j = lps[j - 1]; // Shift pattern using LPS
      } else {
        i++; // No match, move forward in text
      }
    }
  }

  return matches;
}

Example Usage

const text = "ABABDABACDABABCABAB";
const pattern = "ABABCABAB";

const result = kmpSearch(text, pattern);

console.log(`Pattern found at indices:`, result);
// Output: Pattern found at indices: [ 10 ]

Complexity Analysis

  • Time Complexity:
    • Preprocessing: \(O(m)\) where \(m\) is the length of the pattern.
    • Matching: \(O(n)\) where \(n\) is the length of the text.
    • Total Time: \(O(n + m)\), significantly faster than the naive \(O(n \times m)\) approach on repetitive text.
  • Space Complexity: \(O(m)\) auxiliary space required to store the LPS array.
