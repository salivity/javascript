JavaScript Math.trunc vs Math.floor for Negative Numbers

While both Math.trunc() and Math.floor() are built-in JavaScript methods used to eliminate the fractional component of a number, they behave fundamentally differently when dealing with negative values. Math.trunc() simply cuts off decimal places, moving the value toward zero, whereas Math.floor() rounds the number down toward negative infinity. Understanding this distinction is essential for avoiding subtle calculation errors in mathematical operations and algorithmic logic.

How Each Method Works

  • Math.trunc() (Truncation): Removes the fractional digits without performing any rounding calculations. For any positive or negative float, it extracts only the integer part, effectively rounding toward zero.
  • Math.floor() (Floor): Returns the largest integer less than or equal to the given number. It always moves downward along the number line toward negative infinity.

Behavior with Positive Numbers

When handling positive numbers, both methods produce the exact same outcome:

Math.trunc(4.7); // Returns 4
Math.floor(4.7); // Returns 4

In this scenario, discarding the fractional part and finding the next lowest integer yield the identical integer 4.

Behavior with Negative Numbers

The divergence occurs strictly with negative values because rounding down moves further away from zero:

Math.trunc(-4.7); // Returns -4
Math.floor(-4.7); // Returns -5

Math.trunc(-0.3); // Returns -0 (treated as 0 in standard comparisons)
Math.floor(-0.3); // Returns -1

With Math.trunc(-4.7), the .7 is discarded, leaving -4. With Math.floor(-4.7), JavaScript looks for the greatest integer that is less than or equal to -4.7. Since -5 is smaller than -4.7, the result is -5.

When to Use Which

  • Use Math.trunc() when your primary goal is to strip the decimal places or extract the raw integer component of a number regardless of sign (e.g., parsing user inputs or parsing integer values from coordinates).
  • Use Math.floor() when you require strict mathematical floor division, grid indexing, or consistent downward rounding across the entire number line (e.g., continuous coordinate mapping, pagination, or calculating lower bounds).
