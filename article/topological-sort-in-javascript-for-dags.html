Topological Sort in JavaScript for DAGs

Topological sorting produces a linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every directed edge from vertex \(u\) to vertex \(v\), vertex \(u\) appears before vertex \(v\). This article explains how to implement topological sorting in JavaScript using Kahn's Algorithm (a Breadth-First Search approach) and explores its step-by-step logic, edge cases such as cycle detection, and computational complexity.

Understanding Kahn's Algorithm

Kahn's Algorithm determines the order of nodes by repeatedly removing vertices that have no incoming dependencies. It relies on the concept of in-degree, which is the total number of incoming edges directed at a specific vertex.

The process follows these steps:

  1. Calculate the in-degree for every vertex in the graph.
  2. Add all vertices with an in-degree of 0 to a queue.
  3. While the queue is not empty:
    • Remove a vertex from the queue and append it to the sorted list.
    • Decrement the in-degree of all adjacent vertices.
    • If an adjacent vertex's in-degree drops to 0, add it to the queue.
  4. If the sorted list contains all vertices, the graph has been successfully sorted. If it contains fewer vertices, the graph contains at least one cycle and cannot be topologically sorted.

JavaScript Implementation

The following implementation uses an adjacency list representation of a directed graph.

function topologicalSort(numCourses, edges) {
  // 1. Build adjacency list and in-degree map
  const adjList = new Map();
  const inDegree = new Array(numCourses).fill(0);

  for (let i = 0; i < numCourses; i++) {
    adjList.set(i, []);
  }

  for (const [src, dest] of edges) {
    adjList.get(src).push(dest);
    inDegree[dest]++;
  }

  // 2. Collect all nodes with 0 in-degree
  const queue = [];
  for (let i = 0; i < numCourses; i++) {
    if (inDegree[i] === 0) {
      queue.push(i);
    }
  }

  const sortedOrder = [];

  // 3. Process the queue
  while (queue.length > 0) {
    const current = queue.shift();
    sortedOrder.push(current);

    const neighbors = adjList.get(current) || [];
    for (const neighbor of neighbors) {
      inDegree[neighbor]--;

      if (inDegree[neighbor] === 0) {
        queue.push(neighbor);
      }
    }
  }

  // 4. Cycle detection
  if (sortedOrder.length !== numCourses) {
    throw new Error("Cycle detected: Topological sort is not possible on graphs with cycles.");
  }

  return sortedOrder;
}

Example Usage

Consider a build pipeline where tasks depend on each other:

  • Task 0 must run before Task 1
  • Task 0 must run before Task 2
  • Task 1 must run before Task 3
  • Task 2 must run before Task 3
const tasks = 4;
const dependencies = [
  [0, 1],
  [0, 2],
  [1, 3],
  [2, 3]
];

try {
  const result = topologicalSort(tasks, dependencies);
  console.log(result); // Output: [0, 1, 2, 3] or [0, 2, 1, 3]
} catch (error) {
  console.error(error.message);
}

Complexity Analysis

  • Time Complexity: \(O(V + E)\), where \(V\) is the number of vertices and \(E\) is the number of directed edges. Initializing the adjacency list takes \(O(E)\), finding the initial zero-degree nodes takes \(O(V)\), and every vertex and edge is processed at most once during traversal.
  • Space Complexity: \(O(V + E)\) to store the adjacency list, in-degree array, and queue structures.
