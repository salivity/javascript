Web Audio ConvolverNode Reverb in JavaScript

The Web Audio API's ConvolverNode provides a powerful way to simulate natural acoustic reverberation directly within web browsers using JavaScript. By utilizing a digital signal processing technique known as convolution, this node processes an incoming dry audio signal against an "impulse response" file—a pre-recorded acoustic profile of a physical space. This article explains the underlying acoustics behind convolution reverb, how the ConvolverNode calculates realistic acoustic reflections, and how to implement it efficiently in your JavaScript applications.

Understanding the Physics: Impulse Responses

To reproduce the acoustic environment of a specific space (such as a cathedral, tunnel, or recording studio), audio engineers capture an Impulse Response (IR).

An impulse is a sudden, transient burst of sound across all audible frequencies, such as a starter pistol, popped balloon, or a calibrated sine sweep. As the sound travels through the room, it reflects off walls, floors, and ceilings. Hard surfaces reflect high frequencies, while soft materials absorb them. The microphone captures both the direct sound and the thousands of subsequent reflections (early reflections and late diffuse decay). This recorded audio file is the impulse response: a complete mathematical fingerprint of how that physical environment alters sound over time.

The Mathematics of Convolution

The ConvolverNode applies a mathematical operation called convolution to merge two distinct signals:

  1. The input signal (\(x[t]\)): The dry audio you want to process (e.g., a synthesized tone or clean vocal).
  2. The impulse response (\(h[t]\)): The acoustic profile of the room.

In discrete time, the output \(y[n]\) is calculated by multiplying each sample of the input audio by every sample of the impulse response, summing the products over time:

\[y[n] = \sum_{k=0}^{M} x[n - k] \cdot h[k]\]

Because calculating this directly in the time domain is computationally expensive for long reverbs, the Web Audio API performs this calculation in the frequency domain using the Fast Fourier Transform (FFT). It multiplies the frequency spectra of the two signals and performs an Inverse FFT to return the audio to the time domain. This drastically reduces CPU load while maintaining low-latency playback.

Implementing ConvolverNode in JavaScript

Using the ConvolverNode involves initializing an AudioContext, fetching an IR audio file, decoding it into an AudioBuffer, and routing the audio graph.

// 1. Initialize AudioContext
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();

// 2. Create the ConvolverNode
const convolver = audioCtx.createConvolver();

// 3. Load the Impulse Response file
async function setupReverb() {
  const response = await fetch('cathedral-impulse.wav');
  const arrayBuffer = await response.arrayBuffer();
  
  // Decode audio data into an AudioBuffer
  const decodedAudio = await audioCtx.decodeAudioData(arrayBuffer);
  
  // Assign the impulse response to the convolver
  convolver.buffer = decodedAudio;
}

// 4. Route the Audio Graph with a Wet/Dry mix
const source = audioCtx.createBufferSource(); // Or createMediaElementSource()

const dryGain = audioCtx.createGain();
const wetGain = audioCtx.createGain();

// Balance the direct sound and the reverb effect
dryGain.gain.value = 0.8;
wetGain.gain.value = 0.4;

// Direct (Dry) path
source.connect(dryGain);
dryGain.connect(audioCtx.destination);

// Effect (Wet) path
source.connect(convolver);
convolver.connect(wetGain);
wetGain.connect(audioCtx.destination);

Why Convolution Outperforms Algorithmic Reverb

Traditional algorithmic reverbs generate artificial reflections using networks of delay lines, feedback loops, and comb or all-pass filters. While flexible and easy to parameterize, algorithmic reverbs often exhibit metallic artifacts or an unnatural sound because they approximate room geometry mathematically.

In contrast, the ConvolverNode:

  • Captures Real-World Imperfections: Natural irregularities in surface geometry, air absorption, and complex multi-point reflections are inherently preserved in the IR sample.
  • Maintains Stereo Imaging: True stereo or multi-channel impulse responses preserve the interaural time differences (ITD) and interaural level differences (ILD) that the human ear uses to localize sound in a 3D space.
  • Is Highly Versatile: Beyond acoustic spaces, convolution can simulate the non-linear frequency resonance of guitar cabinets, vintage microphones, and hardware equalizers.

Performance Considerations

While efficient, ConvolverNode execution demands more memory and processing power than standard audio nodes. Long impulse responses (such as reverbs exceeding five seconds) require larger buffers and longer FFT computations. To ensure smooth performance across mobile and lower-end desktop devices, normalize impulse files, trim unnecessary silence from the end of the IR buffer, and maintain sensible audio sample rates.
