Counting Sort for Non-Negative Integers in JavaScript

Counting sort is an efficient, non-comparison-based sorting algorithm ideal for ordering collections of non-negative integers within a known, relatively small range. Unlike algorithms like QuickSort or MergeSort that rely on comparing elements, counting sort determines the position of each element by counting its occurrences. This article explains how the counting sort algorithm works and provides a direct, easy-to-understand implementation in JavaScript.

How Counting Sort Works

Counting sort operates through three primary phases:

  1. Find the Maximum Value: Identify the largest integer in the input array to determine the size of the auxiliary counting array.
  2. Count Frequencies: Traverse the input array and record the frequency of each integer in a count array, where the index matches the integer value.
  3. Reconstruct the Sorted Array: Iterate through the count array and overwrite the original array (or populate a new one) with each number according to its recorded frequency.

JavaScript Implementation

Here is the straightforward implementation of counting sort for an array of non-negative integers:

function countingSort(arr) {
  if (arr.length <= 1) return arr;

  // Step 1: Find the maximum value
  let max = arr[0];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) {
      max = arr[i];
    }
  }

  // Step 2: Initialize count array with zeros
  const count = new Array(max + 1).fill(0);

  // Step 3: Store the count of each element
  for (let i = 0; i < arr.length; i++) {
    count[arr[i]]++;
  }

  // Step 4: Reconstruct the sorted array
  let sortedIndex = 0;
  for (let i = 0; i <= max; i++) {
    while (count[i] > 0) {
      arr[sortedIndex] = i;
      sortedIndex++;
      count[i]--;
    }
  }

  return arr;
}

// Example usage:
const numbers = [4, 2, 2, 8, 3, 3, 1, 0, 5];
console.log(countingSort(numbers));
// Output: [0, 1, 2, 2, 3, 3, 4, 5, 8]

Complexity and Best Use Cases

  • Time Complexity: \(O(n + k)\), where \(n\) is the number of elements in the input array and \(k\) is the maximum value in the array. If \(k\) is proportional to \(n\), the algorithm runs in linear time.
  • Space Complexity: \(O(k)\) auxiliary space required to store the frequency counts.

Counting sort is most effective when the maximum value (\(k\)) is not significantly larger than the total number of items (\(n\)). If the input contains exceptionally large values relative to the array length, the memory overhead can make this approach inefficient compared to standard comparison-based sorts.
