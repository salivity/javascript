Compare DOM Node Positions with compareDocumentPosition

The Node.compareDocumentPosition() method in JavaScript provides a precise way to determine the relative positional and hierarchical relationship between any two nodes in a document. This article explains how the method works, details the bitmask flags it returns, demonstrates how to interpret combined bitwise values, and provides practical code examples for sorting and inspecting DOM elements.

Syntax and Basic Mechanics

The method is invoked directly on a reference node and takes another node as its argument:

const relationship = node.compareDocumentPosition(otherNode);

The method returns an unsigned 16-bit integer representing a bitmask. Instead of returning a simple string or single status code, it uses individual binary bits to represent different spatial relationships, allowing multiple relationships to be reported simultaneously.

Position Flags and Return Values

The DOM specification defines six standard bitmask constants on the Node interface:

Constant Decimal Value Binary Value Meaning
Node.DOCUMENT_POSITION_DISCONNECTED 1 000001 Both nodes are in different documents or not connected to the DOM.
Node.DOCUMENT_POSITION_PRECEDING 2 000010 otherNode appears before node in document order.
Node.DOCUMENT_POSITION_FOLLOWING 4 000100 otherNode appears after node in document order.
Node.DOCUMENT_POSITION_CONTAINS 8 001000 otherNode is an ancestor of node.
Node.DOCUMENT_POSITION_CONTAINED_BY 16 010000 otherNode is a descendant of node.
Node.DOCUMENT_POSITION_IMPLEMENTATION_SPECIFIC 32 100000 The result relies on browser-specific handling (e.g., comparing attribute nodes or disconnected subtrees).

Understanding Combined Bitmasks

Because nodes can have nested relationships, single comparisons often trigger multiple flags simultaneously:

  • If otherNode is a child of node, otherNode is both contained by node (16) and positioned after the opening tag of node (4). The method returns 20 (16 + 4).
  • If otherNode is an ancestor of node, otherNode contains node (8) and precedes node (2). The method returns 10 (8 + 2).

To test for a specific condition, use JavaScript's bitwise AND operator (&):

const parent = document.querySelector('#parent');
const child = document.querySelector('#child');

const position = parent.compareDocumentPosition(child);

// Check if child is contained by parent
const isContained = Boolean(position & Node.DOCUMENT_POSITION_CONTAINED_BY);
console.log(isContained); // true

Practical Examples

Checking Relative Order

To verify whether one element appears before another on the page:

const itemA = document.querySelector('#item-a');
const itemB = document.querySelector('#item-b');

const comparison = itemA.compareDocumentPosition(itemB);

if (comparison & Node.DOCUMENT_POSITION_FOLLOWING) {
  console.log('Item B appears after Item A');
} else if (comparison & Node.DOCUMENT_POSITION_PRECEDING) {
  console.log('Item B appears before Item A');
}

Sorting Nodes into Document Order

You can pass compareDocumentPosition directly into Array.prototype.sort() to order an arbitrary collection of elements sequentially as they appear in the DOM:

const elements = Array.from(document.querySelectorAll('.highlight, .selected'));

elements.sort((a, b) => {
  if (a === b) return 0;
  const position = a.compareDocumentPosition(b);
  return position & Node.DOCUMENT_POSITION_FOLLOWING ? -1 : 1;
});

Checking for Disconnected Nodes

When working with virtual trees or elements removed from the document, you can confirm whether two nodes share the same root:

const detachedNode = document.createElement('div');
const liveNode = document.body;

const result = liveNode.compareDocumentPosition(detachedNode);

if (result & Node.DOCUMENT_POSITION_DISCONNECTED) {
  console.log('The nodes do not share a common document tree.');
}
