Staggered Isometric Tile Mouse Picking in JavaScript

Translating a two-dimensional mouse click on a screen into the correct tile coordinates of an isometric grid is a fundamental challenge in 2D game development. When using a staggered isometric layout—where alternating rows or columns are shifted by half a tile's dimensions—standard rectangular math fails. This article explains the geometric logic behind staggered isometric projections and demonstrates how to calculate the exact tile under the mouse cursor using JavaScript through coarse grid approximation and sub-tile quadrant testing.

Understanding the Staggered Grid Layout

In a row-staggered isometric map, every diamond tile has a given tileWidth and tileHeight (typically with a 2:1 ratio, such as 64x32 pixels). Each row is drawn shifted vertically by half the tile height (tileHeight / 2). Additionally, odd-numbered rows are shifted horizontally by half the tile width (tileWidth / 2).

Because the tiles overlap along the vertical axis, a single point on the screen falls within the bounding boxes of multiple adjacent tiles. Determining which tile actually owns the mouse coordinate requires a two-step approach: coarse cell identification and fine sub-tile corner checking.

Step 1: Coarse Cell Mapping

First, treat the screen as a simple rectangular grid where each cell has a width equal to tileWidth and a height equal to tileHeight / 2.

Given the mouse coordinates (mouseX, mouseY) relative to the map origin:

const halfWidth = tileWidth / 2;
const halfHeight = tileHeight / 2;

// Calculate coarse grid row and local offset
const coarseY = Math.floor(mouseY / halfHeight);
const isOddRow = coarseY % 2 !== 0;

// Apply horizontal offset for odd rows
const offsetX = isOddRow ? mouseX - halfWidth : mouseX;
const coarseX = Math.floor(offsetX / tileWidth);

At this stage, coarseX and coarseY identify the dominant rectangular region. Next, determine the relative coordinates (relX, relY) within that specific rectangular cell:

const relX = isOddRow ? (mouseX - halfWidth) % tileWidth : mouseX % tileWidth;
const relY = mouseY % halfHeight;

Step 2: Fine-Tuning with Diamond Edge Detection

Each rectangular coarse region contains parts of four overlapping isometric tiles. The center forms the selected tile, while the four corners belong to neighboring tiles from adjacent rows.

Using the line equation for the diamond's edge, determine if the cursor sits within a corner triangle:

// Calculate normalized distance from the corners
// The slope ratio is halfHeight / halfWidth
const ratio = halfHeight / halfWidth;

let tileX = coarseX;
let tileY = coarseY;

if (relY < halfHeight - relX * ratio) {
    // Top-left corner: Belongs to previous row, shifted left if on even row
    tileY -= 1;
    if (!isOddRow) tileX -= 1;
} else if (relY < -halfHeight + relX * ratio) {
    // Top-right corner: Belongs to previous row, shifted right if on odd row
    tileY -= 1;
    if (isOddRow) tileX += 1;
}

If the click falls outside these upper-corner thresholds, the initial (coarseX, coarseY) is the selected tile.

Complete JavaScript Implementation

Below is a consolidated function that combines both steps to return the zero-based grid coordinate (x, y):

function screenToStaggeredTile(mouseX, mouseY, tileWidth, tileHeight) {
    const halfWidth = tileWidth / 2;
    const halfHeight = tileHeight / 2;

    // Coarse row selection
    const coarseY = Math.floor(mouseY / halfHeight);
    const isOdd = Math.abs(coarseY % 2) === 1;

    // Coarse column selection adjusted for staggering
    const adjustedX = isOdd ? mouseX - halfWidth : mouseX;
    let tileX = Math.floor(adjustedX / tileWidth);
    let tileY = coarseY;

    // Calculate local position within the half-height bounding box
    const relX = adjustedX - tileX * tileWidth;
    const relY = mouseY - coarseY * halfHeight;

    // Edge testing against the isometric slopes
    const slope = halfHeight / halfWidth;

    if (relY < halfHeight - relX * slope) {
        // Upper-left corner boundary
        tileY -= 1;
        if (!isOdd) tileX -= 1;
    } else if (relY < relX * slope - halfHeight) {
        // Upper-right corner boundary
        tileY -= 1;
        if (isOdd) tileX += 1;
    }

    return { x: tileX, y: tileY };
}

This mathematical approach removes the need for costly off-screen lookup textures or iterative distance checks, calculating precise mouse coordinates in constant time \(O(1)\).
