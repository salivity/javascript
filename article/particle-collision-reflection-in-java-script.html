Particle Collision Reflection in JavaScript

Particle collision reflection is a foundational mechanic in 2D and 3D game physics that determines how a moving entity rebounds after striking an obstacle. This article covers the mathematical theory of reflection using surface normals and provides a clear, practical implementation in JavaScript for calculating redirected velocity vectors during collisions.

Understanding Particle Collision Reflection

When a particle collides with a static or dynamic barrier, its velocity vector must change direction to simulate a bounce. Without physics-based reflection, particles might stick to surfaces, pass through them, or bounce in unnatural, axis-aligned directions.

In real-world physics, reflection follows the law of reflection: the angle of incidence equals the angle of reflection. In video game programming, rather than calculating angles using expensive trigonometric functions, game loops use vector mathematics based on the surface normal.

The Role of the Surface Normal

A surface normal is a unit vector (a vector with a length of 1) that points perpendicularly outward from a surface at the point of impact.

  • For a flat horizontal floor, the normal vector points straight up: (0, -1) in standard screen coordinates where the Y-axis points downward.
  • For a vertical wall on the right, the normal vector points left: (-1, 0).
  • For angled walls, the normal is calculated by taking the perpendicular vector of the surface line and normalizing it to a magnitude of 1.

The normal vector acts as the reference line across which the particle's incoming velocity vector is mirrored.

The Vector Reflection Formula

To reflect an incoming velocity vector \(\mathbf{v}\) across a normalized surface normal \(\mathbf{n}\), use the following standard vector reflection formula:

\[\mathbf{v}' = \mathbf{v} - 2(\mathbf{v} \cdot \mathbf{n})\mathbf{n}\]

Where:

  • \(\mathbf{v}\) is the original velocity vector.
  • \(\mathbf{n}\) is the unit normal vector of the collision surface.
  • \(\mathbf{v} \cdot \mathbf{n}\) represents the dot product of the velocity and the normal vector.
  • \(\mathbf{v}'\) is the resulting reflected velocity vector.

To account for energy loss during an impact, a coefficient of restitution (bounciness) \(e\) ranging from 0 (completely inelastic) to 1 (perfectly elastic) is introduced:

\[\mathbf{v}' = \mathbf{v} - (1 + e)(\mathbf{v} \cdot \mathbf{n})\mathbf{n}\]

JavaScript Implementation

Below is a pure JavaScript implementation demonstrating vector math and surface redirection for a particle colliding with an arbitrary surface.

// Basic 2D Vector operations
class Vector2D {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }

  // Calculate the dot product of two vectors
  dot(vector) {
    return this.x * vector.x + this.y * vector.y;
  }

  // Multiply vector by a scalar
  multiply(scalar) {
    return new Vector2D(this.x * scalar, this.y * scalar);
  }

  // Subtract another vector from this one
  subtract(vector) {
    return new Vector2D(this.x - vector.x, this.y - vector.y);
  }

  // Normalize vector to unit length
  normalize() {
    const magnitude = Math.hypot(this.x, this.y);
    if (magnitude === 0) return new Vector2D(0, 0);
    return new Vector2D(this.x / magnitude, this.y / magnitude);
  }
}

// Particle definition
class Particle {
  constructor(x, y, vx, vy, restitution = 0.8) {
    this.position = new Vector2D(x, y);
    this.velocity = new Vector2D(vx, vy);
    this.restitution = restitution; // Bounciness (0 = no bounce, 1 = full bounce)
  }

  // Reflects velocity based on a given surface normal
  bounce(normal) {
    // Ensure normal vector is normalized
    const unitNormal = normal.normalize();

    // Calculate dot product (v . n)
    const dotProduct = this.velocity.dot(unitNormal);

    // Only reflect if the particle is moving toward the surface
    if (dotProduct < 0) {
      const impulseMultiplier = 1 + this.restitution;
      const reflectionComponent = unitNormal.multiply(impulseMultiplier * dotProduct);
      
      // Apply the formula: v' = v - (1 + e)(v . n)n
      this.velocity = this.velocity.subtract(reflectionComponent);
    }
  }

  update(deltaTime) {
    this.position.x += this.velocity.x * deltaTime;
    this.position.y += this.velocity.y * deltaTime;
  }
}

Handling Collisions at Runtime

When integrating this into an update loop, redirection is typically handled in three steps:

  1. Detection: Check if the particle intersects with a surface segment or boundary.
  2. Resolution: Move the particle slightly outside the collision boundary to prevent it from getting stuck inside geometry.
  3. Redirection: Call the bounce method using the normal vector of the contacted surface.
// Example: Particle hitting an angled surface with normal (-0.707, -0.707)
const particle = new Particle(100, 100, 5, 5, 0.75);
const surfaceNormal = new Vector2D(-0.707, -0.707);

// Perform redirection upon impact
particle.bounce(surfaceNormal);

Checking that the dot product is negative (dotProduct < 0) guarantees that the particle is actually approaching the surface rather than already separating from it, preventing unnatural multi-collision sticking bugs.
