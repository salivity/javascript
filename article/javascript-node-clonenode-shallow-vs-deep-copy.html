JavaScript Node.cloneNode: Shallow vs Deep Copy

The Node.cloneNode() method in JavaScript creates a duplicate of a DOM node, but its behavior depends entirely on whether you perform a shallow or a deep copy. By passing a boolean argument—false for a shallow copy or true for a deep copy—you control whether the operation duplicates only the specific node and its attributes, or recursively copies the node along with all of its child elements, text content, and descendants.

The Syntax

const duplicate = originalNode.cloneNode(deep);

The deep parameter is optional in modern browsers (defaulting to false), but explicitly passing true or false is recommended for code clarity and legacy compatibility.

Shallow Copy: cloneNode(false)

A shallow copy duplicates only the targeted node and its attributes. It does not copy any child nodes, including nested HTML tags or plain text nodes.

  • What is cloned: The element tag itself and all of its HTML attributes (such as class, id, and custom data-* attributes).
  • What is excluded: Any inner text, nested tags, or descendant nodes.

For example, consider the following HTML:

<div id="card" class="container">
  <h2>Title</h2>
  <p>Some description text.</p>
</div>

If you perform a shallow copy:

const original = document.getElementById('card');
const shallow = original.cloneNode(false);

The resulting shallow node will be:

<div id="card" class="container"></div>

The inner <h2>, <p>, and all corresponding text are discarded.

Deep Copy: cloneNode(true)

A deep copy duplicates the node, its attributes, and the entire subtree of descendants beneath it.

  • What is cloned: The element, its attributes, every child element, text nodes, and comments.
  • What is excluded: Nothing within the DOM hierarchy is excluded; the complete structure is preserved.

Using the same HTML element:

const original = document.getElementById('card');
const deep = original.cloneNode(true);

The resulting deep node contains the complete hierarchy:

<div id="card" class="container">
  <h2>Title</h2>
  <p>Some description text.</p>
</div>

Important Considerations for Both Methods

Regardless of whether you use a shallow or deep copy, Node.cloneNode() has specific limitations:

  1. Event Listeners: Event listeners added using addEventListener() are not copied to the cloned nodes. Only inline event handlers (like onclick="doSomething()") written directly as HTML attributes are preserved.
  2. Duplicate IDs: If the original node or its descendants have id attributes, the cloned nodes will have identical IDs. Because duplicate IDs violate HTML specifications and break JavaScript lookups, you must update or remove the IDs before inserting the cloned nodes into the document.
  3. Form States: User input states that are not reflected in HTML attributes (such as text typed into a form input or canvas drawings) are generally not retained in the clone.
