Calculating Levenshtein Distance in JavaScript

The Levenshtein distance algorithm measures the similarity between two strings by determining the minimum number of single-character edits—insertions, deletions, or substitutions—required to transform one string into another. Using dynamic programming, this problem is solved efficiently by breaking it down into smaller subproblems and storing intermediate results in a matrix rather than recalculating them recursively. This article explains how the dynamic programming approach works mathematically and demonstrates how to implement it directly in JavaScript.

Understanding the Operations

To convert string a into string b, the algorithm considers three primary operations, each typically assigned an edit cost of 1:

  1. Insertion: Add a character to string a to match string b.
  2. Deletion: Remove a character from string a.
  3. Substitution: Replace a character in string a with the corresponding character in string b (cost is 0 if the characters are identical).

The Dynamic Programming Matrix

The dynamic programming approach uses a two-dimensional array, dp, of size (m + 1) x (n + 1), where m is the length of the source string a and n is the length of the target string b.

Each cell dp[i][j] represents the edit distance between the prefix a[0...i-1] and the prefix b[0...j-1].

Base Cases

  • dp[i][0] = i: Converting a prefix of length i to an empty string requires i deletions.
  • dp[0][j] = j: Converting an empty string to a prefix of length j requires j insertions.

Recurrence Relation

For any cell dp[i][j], if the characters match (a[i - 1] === b[j - 1]), the cost is identical to the previous prefixes: \[\text{dp}[i][j] = \text{dp}[i - 1][j - 1]\]

If the characters differ, the algorithm takes the minimum cost of the three potential operations plus one: \[\text{dp}[i][j] = 1 + \min(\text{dp}[i - 1][j], \text{dp}[i][j - 1], \text{dp}[i - 1][j - 1])\]

  • dp[i - 1][j] + 1 represents a deletion.
  • dp[i][j - 1] + 1 represents an insertion.
  • dp[i - 1][j - 1] + 1 represents a substitution.

JavaScript Implementation

Below is the standard dynamic programming implementation of the Levenshtein distance algorithm in JavaScript:

function levenshteinDistance(a, b) {
  const m = a.length;
  const n = b.length;

  // Initialize a matrix of size (m + 1) x (n + 1)
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  // Populate base cases for the first column and row
  for (let i = 0; i <= m; i++) {
    dp[i][0] = i;
  }
  for (let j = 0; j <= n; j++) {
    dp[0][j] = j;
  }

  // Compute the optimal edit distance
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (a[i - 1] === b[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      } else {
        dp[i][j] = 1 + Math.min(
          dp[i - 1][j],     // Deletion
          dp[i][j - 1],     // Insertion
          dp[i - 1][j - 1]  // Substitution
        );
      }
    }
  }

  return dp[m][n];
}

// Example usage:
console.log(levenshteinDistance("kitten", "sitting")); // Output: 3

Space-Optimized Implementation

Because calculating dp[i][j] only requires values from the current row and the previous row, the memory requirement can be reduced from \(O(m \times n)\) to \(O(n)\) space:

function levenshteinDistanceOptimized(a, b) {
  if (a.length < b.length) {
    return levenshteinDistanceOptimized(b, a);
  }

  const m = a.length;
  const n = b.length;
  let previousRow = Array.from({ length: n + 1 }, (_, index) => index);
  let currentRow = new Array(n + 1);

  for (let i = 1; i <= m; i++) {
    currentRow[0] = i;

    for (let j = 1; j <= n; j++) {
      if (a[i - 1] === b[j - 1]) {
        currentRow[j] = previousRow[j - 1];
      } else {
        currentRow[j] = 1 + Math.min(
          previousRow[j],     // Deletion
          currentRow[j - 1],  // Insertion
          previousRow[j - 1]  // Substitution
        );
      }
    }

    previousRow = [...currentRow];
  }

  return previousRow[n];
}

// Example usage:
console.log(levenshteinDistanceOptimized("flaw", "lawn")); // Output: 2

Complexity Analysis

  • Time Complexity: \(O(m \times n)\), where \(m\) and \(n\) are the lengths of the two input strings. Every state in the grid must be evaluated once.
  • Space Complexity: \(O(m \times n)\) for the full matrix approach, or \(O(\min(m, n))\) for the space-optimized version that only maintains two active rows.
