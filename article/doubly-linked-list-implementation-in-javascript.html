Doubly Linked List Implementation in JavaScript

This article provides a complete guide to efficiently implementing a doubly linked list data structure in JavaScript. You will learn the core architecture of nodes with bidirectional pointers, explore a modern ES6 class-based implementation, and review methods for constant-time additions and removals, as well as optimized indexed operations.

Understanding the Node and List Structure

A doubly linked list consists of a series of nodes where each node contains three properties: the stored data (value), a reference to the next node (next), and a reference to the previous node (prev). The list itself maintains pointers to both the head (the start) and the tail (the end), along with a length counter to enable \(O(1)\) operations at both extremities.

The Node Class

The Node class encapsulates the data and pointers:

class Node {
  constructor(value) {
    this.value = value;
    this.next = null;
    this.prev = null;
  }
}

The DoublyLinkedList Class

The primary list class initializes head, tail, and length.

class DoublyLinkedList {
  constructor() {
    this.head = null;
    this.tail = null;
    this.length = 0;
  }

  // Append a node to the end: O(1)
  push(value) {
    const newNode = new Node(value);
    if (!this.head) {
      this.head = newNode;
      this.tail = newNode;
    } else {
      this.tail.next = newNode;
      newNode.prev = this.tail;
      this.tail = newNode;
    }
    this.length++;
    return this;
  }

  // Remove a node from the end: O(1)
  pop() {
    if (!this.tail) return null;
    const removedNode = this.tail;
    if (this.length === 1) {
      this.head = null;
      this.tail = null;
    } else {
      this.tail = removedNode.prev;
      this.tail.next = null;
      removedNode.prev = null;
    }
    this.length--;
    return removedNode.value;
  }

  // Add a node to the beginning: O(1)
  unshift(value) {
    const newNode = new Node(value);
    if (!this.head) {
      this.head = newNode;
      this.tail = newNode;
    } else {
      newNode.next = this.head;
      this.head.prev = newNode;
      this.head = newNode;
    }
    this.length++;
    return this;
  }

  // Remove a node from the beginning: O(1)
  shift() {
    if (!this.head) return null;
    const removedNode = this.head;
    if (this.length === 1) {
      this.head = null;
      this.tail = null;
    } else {
      this.head = removedNode.next;
      this.head.prev = null;
      removedNode.next = null;
    }
    this.length--;
    return removedNode.value;
  }

  // Retrieve a node at a specific index: O(n) optimized to O(n/2)
  get(index) {
    if (index < 0 || index >= this.length) return null;

    let current;
    // Optimize traversal: check whether index is closer to head or tail
    if (index <= this.length / 2) {
      current = this.head;
      for (let i = 0; i < index; i++) {
        current = current.next;
      }
    } else {
      current = this.tail;
      for (let i = this.length - 1; i > index; i--) {
        current = current.prev;
      }
    }
    return current;
  }

  // Insert at a specific index: O(n)
  insert(index, value) {
    if (index < 0 || index > this.length) return false;
    if (index === 0) return !!this.unshift(value);
    if (index === this.length) return !!this.push(value);

    const newNode = new Node(value);
    const beforeNode = this.get(index - 1);
    const afterNode = beforeNode.next;

    beforeNode.next = newNode;
    newNode.prev = beforeNode;
    newNode.next = afterNode;
    afterNode.prev = newNode;

    this.length++;
    return true;
  }

  // Remove from a specific index: O(n)
  remove(index) {
    if (index < 0 || index >= this.length) return null;
    if (index === 0) return this.shift();
    if (index === this.length - 1) return this.pop();

    const removedNode = this.get(index);
    const beforeNode = removedNode.prev;
    const afterNode = removedNode.next;

    beforeNode.next = afterNode;
    afterNode.prev = beforeNode;

    removedNode.next = null;
    removedNode.prev = null;

    this.length--;
    return removedNode.value;
  }
}

Performance Optimization Highlights

  1. Tail Pointer for \(O(1)\) Removals: Unlike singly linked lists, which require traversing to the second-to-last node to remove from the end (\(O(n)\)), maintaining a tail pointer and backward prev references allows pop() to run in \(O(1)\) time.
  2. Bidirectional Search: The get(index) method divides the list traversal in half. By checking if the target index is closer to the head or the tail, operations traverse at most \(n / 2\) steps instead of \(n\) steps.
  3. Garbage Collection Cleanup: When severing nodes in removal methods (pop, shift, remove), setting dangling pointers (prev and next) to null helps prevent memory leaks by breaking object reference cycles.

Time Complexity Summary

Operation Time Complexity
Insertion at Head (unshift) \(O(1)\)
Insertion at Tail (push) \(O(1)\)
Removal from Head (shift) \(O(1)\)
Removal from Tail (pop) \(O(1)\)
Search / Access (get) \(O(n)\)
Arbitrary Insertion / Removal \(O(n)\)
