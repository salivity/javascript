How to Poll Gamepad Axes and Buttons in JavaScript

The Gamepad API provides web developers with access to connected controllers, enabling console-style input in browser games. Unlike mouse and keyboard inputs that rely primarily on asynchronous event listeners, controller states are captured by polling navigator.getGamepads() inside a continuous animation loop. This article explains how to set up the polling cycle, interpret floating-point data from analog stick axes, apply deadzones, and read analog button pressures from triggers.

The Polling Model and the Game Loop

While the browser uses events like gamepadconnected and gamepaddisconnected to signal hardware availability, reading active gameplay inputs requires explicit polling. Controller states change rapidly, and polling ensures inputs are captured in sync with rendering.

To poll input, call navigator.getGamepads() inside a requestAnimationFrame loop. Each call returns a snapshot (a GamepadList) containing Gamepad objects representing each connected device.

function gameLoop() {
  const gamepads = navigator.getGamepads();
  const gp = gamepads[0];

  if (gp) {
    handleAxes(gp.axes);
    handleButtons(gp.buttons);
  }

  requestAnimationFrame(gameLoop);
}

requestAnimationFrame(gameLoop);

Polling Analog Stick Axes

The axes property of a Gamepad object is an array of floating-point numbers ranging from -1.0 to 1.0. According to the standard gamepad mapping:

  • Axis 0: Left stick horizontal axis (left is -1.0, right is 1.0)
  • Axis 1: Left stick vertical axis (up is -1.0, down is 1.0)
  • Axis 2: Right stick horizontal axis
  • Axis 3: Right stick vertical axis

Because physical potentiometers in thumbsticks rarely sit at pure zero when released, reading raw axis data often results in unwanted movement, known as stick drift. You must apply a deadzone threshold to ignore minor resting fluctuations.

function applyDeadzone(value, threshold = 0.15) {
  return Math.abs(value) > threshold ? value : 0;
}

Reading Button Pressures and Triggers

The buttons property is an array of GamepadButton objects. Each button object exposes three key properties:

  • pressed: A boolean indicating whether the button is considered pushed past the activation threshold.
  • touched: A boolean indicating if the user's finger is resting on a capacitive button (supported by select hardware).
  • value: A floating-point number ranging from 0.0 (fully released) to 1.0 (fully depressed).

Digital buttons (such as the D-pad, face buttons, or stick clicks) switch directly between 0.0 and 1.0. However, analog triggers (like L2 and R2 on PlayStation controllers, or LT and RT on Xbox controllers, typically mapped to indices 6 and 7) provide variable pressure readings through the value property.

function handleButtons(buttons) {
  // Reading a standard digital face button (e.g., 'A' or 'Cross' at index 0)
  const jumpPressed = buttons[0].pressed;

  // Reading an analog trigger (e.g., Right Trigger / R2 at index 7)
  const acceleratorPressure = buttons[7].value;

  if (jumpPressed) {
    triggerJump();
  }

  applyAcceleration(acceleratorPressure);
}

By querying axes and buttons at the refresh rate of the browser, developers obtain precise, frame-accurate control over directional movement and variable actions like braking, acceleration, or pressure-sensitive mechanics.
