Empty Array Plus Empty Object in JavaScript

In JavaScript, evaluating the addition operator with an empty array and an empty object typically produces the string "[object Object]". This article explains the step-by-step mechanism of implicit type coercion that leads to this result, detailing how the ToPrimitive abstract operation works and why the order of operands can alter the output in certain execution contexts.

The Addition Operator and Type Coercion

The binary plus operator (+) in JavaScript performs two distinct operations: numeric addition and string concatenation. When applied to non-primitive values such as arrays and objects, the JavaScript engine must first convert both operands into primitive values using the internal ToPrimitive algorithm.

When ToPrimitive is invoked on an object or array without a specified hint, JavaScript defaults to treating it as a number hint (or string hint depending on the object), which ultimately calls the valueOf() and toString() methods in sequence.

Step-by-Step Evaluation of [] + {}

When evaluating the expression [] + {}, the engine executes the following steps:

  1. Coerce the Array ([]):

    • The engine calls [].valueOf(), which returns the array itself (a non-primitive).
    • Because the value is still an object, the engine calls [].toString().
    • Calling toString() on an empty array produces an empty string: "".

  2. Coerce the Object ({}):

    • The engine calls {}.valueOf(), which returns the object itself.
    • Because it is not a primitive, the engine calls {}.toString().
    • The default Object.prototype.toString() method returns the string "[object Object]".

  3. Concatenate the Results:

    • Because both operands are now primitives and at least one is a string, the + operator acts as string concatenation.
    • The expression becomes "" + "[object Object]".
    • The final result is "[object Object]".

The Impact of Operand Order: {} + []

If the order of the operands is reversed, the result depends on how the JavaScript parser interprets the line:

  • In an Expression Context: If evaluated within parentheses, assigned to a variable, or passed into a function (e.g., ({} + []) or console.log({} + [])), the steps are identical to [] + {}. The engine concatenates "[object Object]" and "", yielding "[object Object]".
  • At Statement Level (Console/REPL): If {} + [] is typed directly at the start of a line in many browser consoles, the JavaScript parser interprets {} not as an object literal, but as an empty code block. The parser then treats the remaining code as the unary plus operator applied to an empty array: +[]. Unary plus coerces the empty array to a number via Number(""), yielding 0.
