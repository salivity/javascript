JavaScript String repeat Errors for Invalid Counts

The JavaScript String.prototype.repeat() method constructs and returns a new string containing the specified number of concatenated copies of the string on which it was called. When an invalid count value is supplied to this method, JavaScript throws a RangeError. This article details the specific conditions that cause String.prototype.repeat() to throw errors, the types of errors produced, and how different data types are coerced prior to error validation.

The RangeError Exception

The only standard error thrown by String.prototype.repeat() due to an invalid count argument is a RangeError. Under the ECMAScript specification, the method first converts the provided count argument into an integer. Once converted, the value must be a non-negative integer and must not produce a string that exceeds the maximum string length allowed by the JavaScript engine.

A RangeError is thrown in the following three scenarios:

1. Negative Count Values

If the converted count is less than 0, JavaScript throws a RangeError.

"abc".repeat(-1);
// RangeError: Invalid count value (or "repeat count must be non-negative")

"abc".repeat(-Infinity);
// RangeError: Invalid count value

2. Infinity

If the count is positive infinity, the repetition cannot be completed, resulting in a RangeError.

"abc".repeat(Infinity);
// RangeError: Invalid count value (or "repeat count must be less than infinity")

3. Exceeding Maximum String Length

Even if the count is a positive number, a RangeError will occur if str.length * count exceeds the platform's maximum allowable string size (typically between 512 MB and 1 GB, or \(2^{28} - 1\) to \(2^{30} - 1\) characters depending on the JavaScript engine).

// Exceeding maximum buffer/string allocation
"a".repeat(2 ** 30); 
// RangeError: Invalid string length

How count Is Coerced

Before checking if the count is valid, the JavaScript engine applies the abstract operation ToIntegerOrInfinity(count). This process converts various types to integers, which may prevent an error from being thrown unexpectedly:

  • Floats and Decimals: Fractional numbers are truncated toward zero. A count of 3.9 is treated as 3. A negative float between -1 and 0 (such as -0.5) truncates to -0, which converts to +0 and succeeds without an error.
  • NaN, null, undefined, false, and "": These values all convert to 0. The method returns an empty string without throwing an error.
  • true: Converts to 1, returning the original string unchanged.
  • Numeric Strings: Strings like "3" are coerced to numbers. However, non-numeric strings like "hello" coerce to NaN, which then converts to 0.

Example Summary

Input Expression Result Status
"x".repeat(-1) RangeError Throws
"x".repeat(Infinity) RangeError Throws
"x".repeat(2 ** 31) RangeError (Invalid string length) Throws
"x".repeat(-0.9) "" (truncated to 0) Valid
"x".repeat(NaN) "" (coerced to 0) Valid
"x".repeat("invalid") "" ("invalid" becomes NaN -> 0) Valid
