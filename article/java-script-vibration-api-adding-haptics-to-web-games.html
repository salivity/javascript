JavaScript Vibration API: Adding Haptics to Web Games

Haptic feedback bridges the physical and digital worlds by using tactile sensations to communicate events to the player, significantly boosting immersion in web-based games. In JavaScript, this physical sensation is implemented through the native Vibration API, an interface that allows web applications to directly interact with a device's vibration hardware. This article explains the fundamentals of haptic feedback, explores how the navigator.vibrate() method works, and provides practical code examples for triggering single pulses, complex vibration patterns, and cancellation events in game development.

What Is Haptic Feedback?

Haptic feedback is the use of touch sensations—typically via eccentric rotating mass (ERM) motors or linear resonant actuators (LRA)—to convey information to a user. In video games, haptics enrich visual and auditory cues by simulating physical forces. When a player fires a weapon, collides with an obstacle, or suffers damage, a tactile pulse reinforces the event, making the gameplay loop feel tangible and responsive.

The JavaScript Vibration API

Modern mobile browsers expose hardware vibration functionality via the navigator.vibrate() method. Because web-based haptics depend on physical motors, this API primarily functions on mobile devices and handheld platforms; desktop systems safely ignore the commands without throwing syntax errors.

To prevent unauthorized background usage and conserve battery, modern browsers enforce two key rules:

  1. The web page must be the active, visible tab.
  2. The vibration call must stem from a user interaction (such as a tap, click, or touch event).

Before invoking the API, always check for browser support:

if ("vibrate" in navigator) {
    // Vibration API is supported
}

Triggering Single Pulses

A single tactile response is generated by passing an integer representing milliseconds to navigator.vibrate(). This is ideal for short, discrete game events like collecting a coin, pressing a UI button, or jumping.

function onCoinCollect() {
    // Vibrates for 50 milliseconds
    navigator.vibrate(50);
}

function onPlayerDamage() {
    // Vibrates for 200 milliseconds
    navigator.vibrate(200);
}

If the device successfully schedules the vibration, the method returns true. If the parameters are invalid or vibration is not permitted, it returns false.

Creating Complex Vibration Patterns

Games often require distinct sensory signatures for different mechanics. You can create complex rhythms by passing an array of integers. The values alternate between vibration durations and pause durations (in milliseconds), starting with a vibration:

// Pattern: [vibrate, pause, vibrate, pause, vibrate...]
function onCriticalExplosion() {
    // 100ms rumble, 50ms pause, 100ms rumble, 50ms pause, 300ms strong rumble
    navigator.vibrate([100, 50, 100, 50, 300]);
}

function onHeartbeat() {
    // Simulates a low-health double-thump pulse
    navigator.vibrate([80, 100, 80]);
}

By varying the duration of pulses and intervals, you can create distinct physical profiles for machine gun fire, ticking timers, or environmental hazards.

Canceling Vibrations

If an ongoing vibration or pattern needs to be interrupted immediately—such as when a player pauses the game, dies, or navigates away from an action screen—pass 0 or an empty array [] to the method:

function pauseGame() {
    // Stops any active or queued vibration immediately
    navigator.vibrate(0);
}

Best Practices for Games

  1. Avoid Overuse: Continuous buzzing numbs the player's hand, drains the device's battery, and rapidly diminishes the feedback's psychological impact. Reserve haptics for moments of high impact or clear confirmation.
  2. Provide User Controls: Always include an in-game accessibility toggle allowing players to disable vibration entirely.
  3. Layer with Audio and Visuals: Haptics work best when synchronized precisely with sound effects and screen shakes to create a unified sensory experience.
