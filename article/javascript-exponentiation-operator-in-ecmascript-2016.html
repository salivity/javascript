JavaScript Exponentiation Operator in ECMAScript 2016

ECMAScript 2016 (ES7) introduced a native exponentiation operator (**) and an exponentiation assignment operator (**=) to JavaScript, offering a cleaner, more readable alternative to Math.pow(). This article covers the syntax of these additions, how they compare to older methods, their unique associativity rules, and syntax requirements regarding unary operators.

The Exponentiation Operator (**)

Prior to ECMAScript 2016, calculating powers required the built-in Math.pow() function. The exponentiation operator (**) provides an infix notation equivalent to mathematical notation:

// Using Math.pow()
const traditional = Math.pow(2, 3); // 8

// Using the ES2016 exponentiation operator
const modern = 2 ** 3; // 8

The operator accepts both numbers and BigInt values, returning the base raised to the specified exponent:

console.log(5 ** 2);   // 25
console.log(4 ** -1);  // 0.25
console.log(2n ** 3n); // 8n

The Exponentiation Assignment Operator (**=)

Alongside the standard operator, ECMAScript 2016 added the corresponding assignment operator (**=). This provides a shorthand for calculating a power and reassigning the result to the variable:

let base = 3;
base **= 3; // Equivalent to: base = base ** 3

console.log(base); // 27

Operator Associativity

Unlike most binary arithmetic operators in JavaScript (such as +, -, *, and /), which are left-associative, the exponentiation operator is right-associative. This matches standard mathematical convention:

// Evaluated as 2 ** (3 ** 2), which is 2 ** 9
console.log(2 ** 3 ** 2); // 512

// Explicit grouping forces left-to-right evaluation:
console.log((2 ** 3) ** 2); // 64

Restrictions with Unary Operators

To prevent ambiguity regarding whether a negative sign applies to the base or the entire operation, ECMAScript 2016 forbids placing a unary operator directly before the base without parentheses:

// SyntaxError: Unary operator used immediately before exponentiation expression
// -2 ** 2;

// Correct usage:
(-2) ** 2; // 4
-(2 ** 2); // -4
