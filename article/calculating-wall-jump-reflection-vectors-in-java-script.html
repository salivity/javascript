Calculating Wall Jump Reflection Vectors in JavaScript

Implementing responsive wall jump mechanics in 2D JavaScript games requires understanding vector reflection and surface normals. This article explains the mathematics behind surface normal detection, details the vector reflection formula used to redirect a character's momentum, and provides concrete JavaScript implementations for calculating launch velocities during a wall jump.

Understanding the Wall Normal

A normal is a normalized unit vector pointing perpendicularly outward from a surface. In standard 2D platformers using Axis-Aligned Bounding Boxes (AABB), wall normals are straightforward:

  • Left-side wall (player collides moving left): Normal vector is \(\mathbf{n} = (1, 0)\)
  • Right-side wall (player collides moving right): Normal vector is \(\mathbf{n} = (-1, 0)\)

For complex or sloped geometry defined by two vertices \(A(x_1, y_1)\) and \(B(x_2, y_2)\), the edge vector is \(\mathbf{e} = (x_2 - x_1, y_2 - y_1)\). The outward perpendicular normal is derived by swapping coordinates and negating one axis, then normalizing the result:

function getNormal(x1, y1, x2, y2) {
    const dx = x2 - x1;
    const dy = y2 - y1;
    const length = Math.hypot(-dy, dx);
    return {
        x: -dy / length,
        y: dx / length
    };
}

The Mathematical Reflection Formula

In classical physics, a vector reflecting off a hard surface preserves its magnitude while reversing its component perpendicular to the surface. The mathematical formula for reflecting velocity vector \(\mathbf{v}\) across a normal vector \(\mathbf{n}\) is:

\[\mathbf{r} = \mathbf{v} - 2(\mathbf{v} \cdot \mathbf{n})\mathbf{n}\]

Where:

  • \(\mathbf{v}\) is the incoming velocity vector.
  • \(\mathbf{n}\) is the normalized surface normal vector (\(|\mathbf{n}| = 1\)).
  • \(\mathbf{v} \cdot \mathbf{n}\) is the dot product (\(v_x \cdot n_x + v_y \cdot n_y\)).
  • \(\mathbf{r}\) is the resulting reflected velocity vector.

JavaScript Implementation of Vector Reflection

The reflection formula converts directly into a JavaScript function:

function reflectVelocity(vx, vy, nx, ny) {
    // 1. Calculate the dot product
    const dotProduct = vx * nx + vy * ny;

    // 2. Compute the reflection vector: v - 2 * (v . n) * n
    const rx = vx - 2 * dotProduct * nx;
    const ry = vy - 2 * dotProduct * ny;

    return { x: rx, y: ry };
}

Adapting Pure Reflection for Platformer Wall Jumps

Pure geometric reflection is rarely used unmodified in platformer physics. A standard reflection reverses horizontal speed and maintains or amplifies downward falling speed if the player hits the wall while descending.

To create an intuitive game feel, the reflected vector is decomposed into an outward horizontal push combined with a fixed upward impulse:

class Player {
    constructor() {
        this.vx = 0;
        this.vy = 0;
        this.jumpForce = 12;
        this.pushbackSpeed = 8;
    }

    performWallJump(normalX, normalY) {
        // Project horizontal trajectory along the surface normal
        this.vx = normalX * this.pushbackSpeed;

        // Apply upward vertical impulse regardless of downward entry velocity
        this.vy = -this.jumpForce;
    }
}

If sloped walls require the jump direction to account for surface tilt, project the standard jump velocity vector onto the normal and blend it:

function calculateAngledWallJump(nx, ny, jumpSpeed) {
    // Bias normal vector slightly upward for gameplay balance
    const jumpDirX = nx;
    const jumpDirY = ny - 0.5; // Bias upward

    // Normalize the combined jump vector
    const length = Math.hypot(jumpDirX, jumpDirY);
    
    return {
        vx: (jumpDirX / length) * jumpSpeed,
        vy: (jumpDirY / length) * jumpSpeed
    };
}

Resolving Collision and Applying the Jump

During your game loop's collision phase, identify the contact point and extract the normal prior to applying the jump vector:

  1. Detect Collision: Determine if the player's bounding box intersects the wall.
  2. Determine Overlap: Calculate the penetration vector along the axis of minimum penetration.
  3. Resolve Position: Move the player out of the wall to prevent clipping.
  4. Execute Jump: When the jump input is received while in contact, apply the normal-derived velocity vector and momentarily disable horizontal player input to prevent immediate re-attachment to the wall.
