JavaScript Selection API: Inspect and Edit Text

The JavaScript Selection API allows developers to inspect, modify, and control text highlighting and caret positions initiated by user interactions. By interacting with the Selection object—typically retrieved via window.getSelection()—and its associated Range objects, scripts can determine the exact DOM nodes and character offsets an active selection spans, extract highlighted text, programmatically expand or collapse boundaries, and dynamically alter document content within selected areas.

Accessing the Selection Object

The browser exposes the active user selection through the global window object.

const selection = window.getSelection();

This returns a Selection object representing the text selected by the user or the current position of the caret if no text is actively highlighted.

Inspecting User Selections

The Selection object provides several read-only properties to inspect boundaries and direction:

  • anchorNode and anchorOffset: Identifies where the user started making the selection. The anchorNode is the DOM node containing the start point, and the anchorOffset is the zero-based character index (in text nodes) or child node index (in element nodes).
  • focusNode and focusOffset: Identifies where the user ended the selection (where the mouse button was released or cursor stopped).
  • isCollapsed: A boolean that returns true if the anchor and focus positions are identical, meaning no text is highlighted and the selection is simply an active caret.
  • rangeCount: The number of ranges currently held in the selection. Most modern desktop and mobile browsers only support single selections (rangeCount is either 0 or 1).

To extract the plain text contained within the selection:

const selectedText = selection.toString();
console.log(selectedText);

Working with the Range Object

While the Selection object tracks the user's interaction points (which can be reversed if selected from right to left or bottom to top), actual DOM manipulation occurs through Range objects. A Range is always organized in document order (from start to end).

To inspect the underlying Range:

if (selection.rangeCount > 0) {
  const range = selection.getRangeAt(0);
  console.log(range.startContainer, range.startOffset);
  console.log(range.endContainer, range.endOffset);
}

Manipulating the Selection Boundaries

The API provides direct methods to adjust or clear selection boundaries without mutating the DOM:

  • collapse(parentNode, offset): Collapses the selection to a single point at the specified node and offset.
  • collapseToStart() / collapseToEnd(): Moves the caret to the beginning or the end of the current selection.
  • selectAllChildren(parentNode): Expands the selection so that all child elements of the specified node are selected.
  • removeAllRanges(): Clears the selection entirely, deselecting any highlighted text.
  • addRange(range): Sets a programmatic Range to become the active selection in the browser.
// Deselect everything
selection.removeAllRanges();

// Select all text in a specific element
const targetElement = document.getElementById("content");
selection.selectAllChildren(targetElement);

Mutating DOM Content within Selections

To alter or replace the selected HTML or text, manipulate the associated Range object retrieved from the selection:

1. Deleting Selected Content

const range = selection.getRangeAt(0);
range.deleteContents();

2. Wrapping Selected Content in an Element

const range = selection.getRangeAt(0);
const span = document.createElement("mark");
range.surroundContents(span);

3. Inserting New Content at the Selection Point

const range = selection.getRangeAt(0);
range.deleteContents();
const newNode = document.createTextNode("Replacement text");
range.insertNode(newNode);

After modifying the DOM, the visual selection may need to be updated. You can collapse the range to the end of the newly inserted content and apply it back to the selection:

range.collapse(false);
selection.removeAllRanges();
selection.addRange(range);
