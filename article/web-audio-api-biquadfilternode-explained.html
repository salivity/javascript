Web Audio API BiquadFilterNode Explained

The BiquadFilterNode is a core audio processing interface within the Web Audio API that shapes and sculpts audio frequency spectrums in real time using JavaScript. By implementing a second-order Infinite Impulse Response (IIR) filter, it allows developers to attenuate, boost, or isolate specific frequency ranges of an audio stream. This article explains how the node mathematically alters sound spectra, details its key operational parameters, and demonstrates how to implement and modulate it within a standard Web Audio graph.

How the Biquad Filter Operates

At its technical core, the BiquadFilterNode implements a digital biquadratic filter based on the standard bilinear transform. It calculates each output audio sample as a linear combination of the current and previous input samples, as well as previous output samples. This feedback-driven difference equation allows it to efficiently manipulate amplitude and phase across the frequency spectrum using minimal computational overhead.

When audio data passes through the node, the filter applies a transfer function that alters the frequency domain:

  • Phase Shift: Modifies the temporal alignment of specific frequency bands relative to others.
  • Amplitude Attenuation or Boost: Decreases or increases the energy of designated frequency bands according to the filter's transfer curve.

Key Filter Types

The node's type property determines the shape of the frequency response curve applied to the incoming audio:

  • lowpass: Frequencies below the cutoff pass through unaltered; frequencies above the cutoff are attenuated at a rate of 12 dB/octave.
  • highpass: Frequencies above the cutoff pass through; frequencies below are attenuated at 12 dB/octave.
  • bandpass: Only frequencies within a specified range surrounding the center frequency pass through; frequencies outside this range are attenuated.
  • lowshelf: Frequencies below the cutoff receive a set boost or cut in decibels, while higher frequencies remain untouched.
  • highshelf: Frequencies above the cutoff receive a set boost or cut in decibels, while lower frequencies remain untouched.
  • peaking: Frequencies within a specific band around the center frequency are boosted or attenuated, resembling a parametric EQ band.
  • notch: Strongly attenuates frequencies inside a narrow band around the center frequency while passing all other frequencies (a band-stop filter).
  • allpass: Retains the amplitude of all frequencies while shifting the phase relationship across the spectrum.

Configurable AudioParams

The BiquadFilterNode provides four primary AudioParam attributes that govern its filtering behavior. Because these are AudioParam objects, they can be automated smoothly over time without causing audio artifacts or clicks.

  1. frequency: Measured in Hertz (Hz). Represents the cutoff frequency for shelving and pass filters, or the center frequency for peaking, notch, and bandpass filters.
  2. Q (Quality Factor): A dimensionless value indicating the sharpness of the filter curve. In bandpass and notch filters, a higher Q narrows the affected bandwidth. In lowpass and highpass filters, higher Q values create a resonant peak directly at the cutoff frequency.
  3. gain: Measured in decibels (dB). Only active on peaking, lowshelf, and highshelf filters, determining the amount of boost (positive values) or attenuation (negative values) applied.
  4. detune: Measured in cents (1/100th of a semitone). Allows fine-tuning or musical scaling of the primary frequency parameter.

Implementation in JavaScript

Integrating a BiquadFilterNode requires an active AudioContext. The node is placed in series between an audio source and an audio destination.

// Initialize the audio context
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();

// Create an audio source (e.g., an oscillator or media element)
const oscillator = audioCtx.createOscillator();
oscillator.type = 'sawtooth';
oscillator.frequency.value = 220;

// Create and configure the BiquadFilterNode
const filter = audioCtx.createBiquadFilter();
filter.type = 'lowpass';
filter.frequency.value = 800; // Cut off frequencies above 800 Hz
filter.Q.value = 5;            // Add resonance at the cutoff point

// Connect the nodes: Source -> Filter -> Destination
oscillator.connect(filter);
filter.connect(audioCtx.destination);

// Start playback
oscillator.start();

Dynamic Spectrum Modulation

Because filtering parameters are often dynamic (such as synthesizing a synthesizer sweep or simulating an acoustic environment), you can schedule parameter changes using the Web Audio API's timing methods.

const currentTime = audioCtx.currentTime;

// Smoothly sweep the cutoff frequency from 800 Hz to 5000 Hz over 2 seconds
filter.frequency.setValueAtTime(800, currentTime);
filter.frequency.exponentialRampToValueAtTime(5000, currentTime + 2);

By changing these parameters dynamically, the BiquadFilterNode continuously recalculates its coefficients, reshaping the acoustic spectrum in real-time without introducing digital clipping or buffer underruns.
