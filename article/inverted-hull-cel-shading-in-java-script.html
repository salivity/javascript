Inverted Hull Cel Shading in JavaScript

This article explores the inverted hull technique for generating toon outlines alongside cel shading in JavaScript game development. You will learn the core mechanics behind toon rendering, how the inverted hull method produces clean outlines using vertex extrusion and back-face rendering, and how to implement this approach effectively using WebGL libraries such as Three.js.

Understanding Cel Shading

Cel shading, or toon shading, is a non-photorealistic rendering (NPR) technique designed to make 3D graphics mimic the flat, hand-drawn look of comic books and traditional animation.

In standard rendering (such as Phong or PBR), the lighting across a surface is calculated as a smooth gradient based on the dot product between the surface normal and the light direction. Cel shading replaces this continuous gradient with discrete steps or bands of color. In a GLSL fragment shader, this is achieved by quantizing the light intensity value into defined thresholds:

float NdotL = max(dot(normal, lightDir), 0.0);
float lightIntensity;

if (NdotL > 0.8) {
    lightIntensity = 1.0;
} else if (NdotL > 0.4) {
    lightIntensity = 0.6;
} else {
    lightIntensity = 0.2;
}

vec3 finalColor = diffuseColor * lightIntensity;

While stepped lighting creates the characteristic flat tones of animation, cartoon art typically relies on bold black outlines to define silhouettes and feature boundaries.

The Inverted Hull Technique Explained

The inverted hull method—also known as back-face extrusion—is an object-space technique used to render real-time outlines around 3D geometry. Unlike screen-space edge detection (which operates on depth and normal buffers in a post-processing pass), the inverted hull method operates entirely within the mesh pipeline through a two-pass rendering strategy.

The Mechanics

  1. Base Pass: Render the original 3D mesh normally using your cel-shading material, writing both color and depth to the frame buffer.
  2. Hull Pass: Render a second, modified version of the same mesh with two critical changes:
    • Vertex Extrusion: In the vertex shader, push each vertex outward along its normal vector by a fixed thickness value.
    • Inverted Culling: Reverse the polygon winding or set the face culling to cull front faces instead of back faces (THREE.BackSide in Three.js).
    • Solid Color: Paint this extruded mesh with an unlit, flat outline color (typically black).

Because the back faces are scaled outward past the boundaries of the original front-facing mesh, they peek out around the edges from the camera's perspective. The original mesh (rendered in the base pass or occluding the back faces via standard depth testing) covers the interior, leaving only the outer rim visible as a continuous outline.

Implementation in JavaScript and WebGL

In JavaScript game engines such as Three.js, Babylon.js, or raw WebGL, the inverted hull can be implemented either as an additional material pass or as a duplicate mesh parented to the original.

Vertex Shader Extrusion

To keep the outline thickness consistent across different screen resolutions and camera distances, the extrusion should occur in view space or clip space rather than local object space.

// Inverted Hull Vertex Shader
uniform float outlineThickness;

void main() {
    // Transform normal to view space
    vec3 transformedNormal = normalize(normalMatrix * normal);
    
    // Transform position to view space
    vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
    
    // Extrude vertex along the normal in view space
    mvPosition.xyz += transformedNormal * outlineThickness;
    
    gl_Position = projectionMatrix * mvPosition;
}
// Inverted Hull Fragment Shader
uniform vec3 outlineColor;

void main() {
    gl_FragColor = vec4(outlineColor, 1.0);
}

Three.js Scene Setup

In Three.js, you can construct an inverted hull mesh and link it to the base mesh:

import * as THREE from 'three';

// 1. Base Mesh with Cel Shading
const baseMaterial = new THREE.ShaderMaterial({
    vertexShader: celVertexShader,
    fragmentShader: celFragmentShader,
    uniforms: { /* lighting uniforms */ }
});

const characterMesh = new THREE.Mesh(geometry, baseMaterial);
scene.add(characterMesh);

// 2. Outline Material using Inverted Hull
const outlineMaterial = new THREE.ShaderMaterial({
    vertexShader: outlineVertexShader,
    fragmentShader: outlineFragmentShader,
    uniforms: {
        outlineThickness: { value: 0.03 },
        outlineColor: { value: new THREE.Color(0x000000) }
    },
    side: THREE.BackSide // Render only back faces
});

// 3. Attach Hull Mesh
const outlineMesh = new THREE.Mesh(geometry, outlineMaterial);
characterMesh.add(outlineMesh);

Advantages and Disadvantages

Advantages

  • Performance: Inverted hulls are computationally inexpensive and run efficiently on mobile WebGL contexts because they avoid costly post-processing passes and multi-target framebuffers.
  • Selective Application: You can apply outlines strictly to chosen entities (e.g., dynamic characters) while leaving terrain or UI elements untouched.
  • Stylistic Control: Outline thickness and color can be adjusted independently per object or dynamically scaled via uniforms based on distance.

Disadvantages

  • Geometry Requirements: Meshes must be smooth and manifold. Hard surface edges with split normals will "tear" or break apart when extruded, exposing gaps in the outline. To fix this, hard-surface models often require pre-smoothed vertex normals specifically authored for the outline pass.
  • Interior Edges: The inverted hull technique only creates silhouettes. It cannot detect interior creases, such as the line defining a character's nose or fingers crossing in front of a torso. Interior lines must be drawn into the texture map or combined with screen-space depth detection.
  • Draw Call Overhead: Doubling the mesh to create the outline doubles both the vertex count and the number of draw calls for that object.
