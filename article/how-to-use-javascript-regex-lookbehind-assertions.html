How to Use JavaScript Regex Lookbehind Assertions

Lookbehind assertions in JavaScript regular expressions are zero-width assertions that verify whether a specific pattern precedes the target text without including that pattern in the matched result. Introduced in ECMAScript 2018 (ES2018), lookbehinds allow developers to match strings conditionally based on surrounding context. This article explains how positive and negative lookbehind assertions work, their syntax, and practical examples of matching text based on preceding patterns.

Understanding Lookbehind Assertions

Traditional regular expression patterns consume characters as they match them. In contrast, a lookbehind is a "zero-width assertion." It directs the regex engine to peek backward to evaluate the text immediately before the current position. If the condition is met, the engine continues evaluating the rest of the pattern from that same position, leaving the preceding characters out of the captured match.

JavaScript provides two types of lookbehind assertions:

  1. Positive Lookbehind ((?<=pattern))
  2. Negative Lookbehind ((?<!pattern))

Positive Lookbehind ((?<=pattern))

A positive lookbehind ensures that the text being matched is directly preceded by a specified subpattern.

Syntax

/(?<=prefix)target/

Example: Extracting Prices

Suppose you want to extract numeric values, but only when they are preceded by a dollar sign ($).

const text = "The book costs $45, while the pen costs €10 and the notebook is 5.";
const regex = /(?<=\$)\d+/g;

const matches = text.match(regex);
console.log(matches); // Output: ['45']

In this example:

  • (?<=\$) checks that the character directly before the number is $.
  • \d+ matches the digits.
  • The output contains only '45' because the dollar sign was verified rather than consumed.

Negative Lookbehind ((?<!pattern))

A negative lookbehind ensures that the text being matched is not preceded by a specified subpattern.

Syntax

/(?<!prefix)target/

Example: Finding Standalone Numbers

Suppose you want to find numbers that are not preceded by any currency symbol (e.g., neither $ nor €).

const text = "Items: $45, €10, 25 items total";
const regex = /(?<![\$€])\b\d+\b/g;

const matches = text.match(regex);
console.log(matches); // Output: ['25']

In this example:

  • (?<![\$€]) asserts that the digits are not preceded by $ or €.
  • \b\d+\b matches whole numbers.
  • 45 and 10 are ignored because they are preceded by currency symbols, leaving only 25.

Variable-Length Lookbehinds

Unlike some older regex implementations in other languages, JavaScript's lookbehind assertions support variable-length patterns. You can use quantifiers such as *, +, or ? inside the assertion.

const log = "ERROR [2023-10-12]: Connection failed. INFO [2023-10-12]: Success.";
const regex = /(?<=ERROR.*:\s)\w+/g;

const match = log.match(regex);
console.log(match); // Output: ['Connection']

Key Characteristics to Remember

  • Zero-Width: The matched string returned by methods like String.prototype.match() or RegExp.prototype.exec() does not include the text inside the lookbehind assertion unless capturing groups are explicitly placed inside it.
  • Direction of Evaluation: JavaScript evaluates lookbehinds by working backward from the current matching position, which can impact performance on extremely long strings with complex quantifiers.
  • Engine Support: Lookbehinds are standard in modern JavaScript environments (Node.js, Chrome, Firefox, Safari, Edge), but will throw a syntax error in legacy environments that do not support ES2018.
