JavaScript Regex Multiline m Flag and Line Anchors

In JavaScript regular expressions, the multiline flag (m) alters the behavior of the start (^) and end ($) anchor assertions. By default, these anchors treat the entire input string as a single unbroken sequence, matching only at the absolute beginning and end of the full text. When the m flag is enabled, their scope changes to recognize individual lines, allowing ^ and $ to match immediately after or before line terminator characters, respectively.

Default Anchor Behavior (Without the m Flag)

Without the m flag, anchors evaluate the entire string as a single line, regardless of whether it contains line breaks like \n or \r.

  • ^ (Start anchor): Matches only at index 0 of the input string.
  • $ (End anchor): Matches only at the final index of the input string.
const text = "apple\nbanana\ncherry";

// Without 'm', ^ matches only the very start of the entire string
console.log(/^banana/.test(text)); // false
console.log(/^apple/.test(text));  // true

// Without 'm', $ matches only the very end of the entire string
console.log(/banana$/.test(text)); // false
console.log(/cherry$/.test(text)); // true

Modified Anchor Behavior (With the m Flag)

Enabling the m flag makes anchors line-aware. The engine treats newline characters (\n, \r, \u2028, and \u2029) as boundaries.

  • ^ (Start anchor): Matches at the start of the string and immediately after any line terminator character.
  • $ (End anchor): Matches at the end of the string and immediately preceding any line terminator character.
const text = "apple\nbanana\ncherry";

// With 'm', ^ matches at the start of any new line
console.log(/^banana/m.test(text)); // true

// With 'm', $ matches at the end of any line
console.log(/banana$/m.test(text)); // true

Combining with the Global (g) Flag

To extract or replace occurrences across every line, the m flag is commonly combined with the global g flag. Without g, the regex stops after the first successful match, even if subsequent lines also match the criteria.

const list = "item 1\nitem 2\nitem 3";

// Match the word at the start of every line
const result = list.match(/^item/gm);
console.log(result); // ['item', 'item', 'item']

What the m Flag Does Not Change

The m flag solely affects the ^ and $ anchors. It does not alter how the dot (.) character class behaves. By default, . matches any character except line breaks; making the dot match line breaks requires the separate s (dotAll) flag.
