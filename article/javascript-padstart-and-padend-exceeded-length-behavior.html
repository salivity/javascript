JavaScript padStart and padEnd Exceeded Length Behavior

The JavaScript String.prototype.padStart() and String.prototype.padEnd() methods pad a string to a desired target length using an optional fill string. When length constraints are exceeded—whether the original string is already longer than the target length, the filler string is longer than the remaining space, or the target length exceeds engine memory limits—JavaScript handles these cases predictably by preserving original text, truncating fillers, or throwing specific errors.

1. Target Length Is Smaller Than Current String Length

If the targetLength argument passed to padStart() or padEnd() is less than or equal to the current string's length, the method ignores the padding process entirely. The original string is returned as-is without any modification or truncation.

const str = "JavaScript";

console.log(str.padStart(5, "*")); // Output: "JavaScript"
console.log(str.padEnd(5, "*"));   // Output: "JavaScript"

The methods will never shorten an existing string to fit within a smaller targetLength.

2. Pad String Exceeds Needed Padding Space

When targetLength is greater than the string's length, the space to be filled equals targetLength - str.length. If the provided padString contains more characters than this required space, the padString is truncated from the right to fill the exact remainder.

Behavior in padStart

The filler string is clipped to fit the missing length on the left:

const str = "5";

// Needed space is 3 characters (4 - 1). 
// "ABCD" is truncated to "ABC".
console.log(str.padStart(4, "ABCD")); // Output: "ABC5"

Behavior in padEnd

The filler string is similarly clipped to fit the missing length on the right:

const str = "5";

// Needed space is 3 characters (4 - 1). 
// "ABCD" is truncated to "ABC".
console.log(str.padEnd(4, "ABCD")); // Output: "5ABC"

If the padString needs to repeat to fulfill the length, it repeats fully until the final repetition, which is then truncated to match the exact targetLength.

const str = "Item";

// Needed space is 7 characters (11 - 4).
// "123" repeats twice ("123123") + 1 character ("1") to reach 7 characters.
console.log(str.padEnd(11, "123")); // Output: "Item1231231"

3. Target Length Exceeds Maximum String Capacity

If the targetLength parameter is set to a value that exceeds the JavaScript engine's maximum allowed string length limit (typically \(2^{28} - 16\) characters in V8/Chrome or up to \(2^{53} - 1\) defined by the ECMAScript specification), or if it is set to Infinity, JavaScript throws a RangeError.

const str = "overflow";

// Exceeding maximum allowable length throws an error
try {
  str.padStart(2 ** 31 - 1, "0");
} catch (error) {
  console.error(error.name); // Output: "RangeError"
}

Negative values or NaN supplied to targetLength are treated as 0, causing the original string to be returned without modification.
