Graph Adjacency List Using JavaScript Map and Set

Representing graphs with an adjacency list in JavaScript is most effectively achieved using built-in Map and Set objects. This approach pairs each vertex as a key in a Map with a Set containing its neighboring vertices. This article explains how to build a flexible graph structure using these primitives, highlights why Map and Set outperform traditional arrays and plain objects, and provides a clean, reusable implementation for directed and undirected graphs.

Why Use Map and Set?

Traditional JavaScript adjacency lists rely on plain objects ({}) to store vertices and arrays ([]) to store neighbors. While functional, this pattern has limitations:

  • Key Flexibility: A Map allows vertices to be of any data type (primitives, objects, or custom classes), whereas plain object keys are coerced to strings or symbols.
  • Unique Connections: A Set automatically prevents duplicate edges between the same two nodes without requiring manual deduplication checks.
  • Performance: Checking if an edge exists between two nodes using Set.prototype.has() runs in \(O(1)\) average time, compared to \(O(V)\) for searching an array with indexOf() or includes(). Deleting an edge with Set.prototype.delete() is also an \(O(1)\) operation.

Graph Class Implementation

Here is a full implementation of a graph using Map and Set:

class Graph {
  constructor() {
    this.adjacencyList = new Map();
  }

  // Add a new vertex to the graph
  addVertex(vertex) {
    if (!this.adjacencyList.has(vertex)) {
      this.adjacencyList.set(vertex, new Set());
    }
  }

  // Add an edge between source and destination
  addEdge(source, destination, isDirected = false) {
    // Ensure both vertices exist
    if (!this.adjacencyList.has(source)) {
      this.addVertex(source);
    }
    if (!this.adjacencyList.has(destination)) {
      this.addVertex(destination);
    }

    // Add destination to source's neighbor set
    this.adjacencyList.get(source).add(destination);

    // If undirected, add source to destination's neighbor set
    if (!isDirected) {
      this.adjacencyList.get(destination).add(source);
    }
  }

  // Check if an edge exists
  hasEdge(source, destination) {
    if (!this.adjacencyList.has(source)) return false;
    return this.adjacencyList.get(source).has(destination);
  }

  // Remove an edge between two vertices
  removeEdge(source, destination, isDirected = false) {
    if (this.adjacencyList.has(source)) {
      this.adjacencyList.get(source).delete(destination);
    }
    if (!isDirected && this.adjacencyList.has(destination)) {
      this.adjacencyList.get(destination).delete(source);
    }
  }

  // Remove a vertex and all associated edges
  removeVertex(vertex) {
    if (!this.adjacencyList.has(vertex)) return;

    // Remove the vertex from all neighbors' adjacency sets
    for (const [, neighbors] of this.adjacencyList) {
      neighbors.delete(vertex);
    }

    // Delete the vertex entry from the Map
    this.adjacencyList.delete(vertex);
  }

  // Retrieve neighbors of a vertex
  getNeighbors(vertex) {
    return this.adjacencyList.get(vertex) || new Set();
  }
}

Practical Usage Example

const graph = new Graph();

// Adding edges automatically registers missing vertices
graph.addEdge("A", "B");
graph.addEdge("A", "C");
graph.addEdge("B", "D");

// Querying connections
console.log(graph.hasEdge("A", "B")); // true
console.log(graph.hasEdge("B", "C")); // false

// Listing neighbors for node "A"
console.log([...graph.getNeighbors("A")]); // ['B', 'C']

// Removing an edge
graph.removeEdge("A", "C");
console.log(graph.hasEdge("A", "C")); // false

// Removing a vertex
graph.removeVertex("B");
console.log(graph.hasEdge("A", "B")); // false

Time and Space Complexity

  • Space Complexity: \(O(V + E)\), where \(V\) is the number of vertices and \(E\) is the number of edges. Each vertex occupies one entry in the Map, and each edge occupies an entry in a Set.
  • Add Vertex: \(O(1)\)
  • Add Edge: \(O(1)\) average time
  • Remove Edge: \(O(1)\) average time
  • Check Edge (hasEdge): \(O(1)\) average time
  • Remove Vertex: \(O(V + E)\), because the graph must iterate over every neighbor collection to remove incident edges.
