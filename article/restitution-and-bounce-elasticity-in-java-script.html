Restitution and Bounce Elasticity in JavaScript

The coefficient of restitution is a fundamental physics parameter that dictates how much kinetic energy remains after two objects collide, directly controlling the "bounciness" or elasticity in game simulations. In JavaScript game programming, this value—typically represented as a scalar between 0 and 1—determines whether an object rebounds with full force, loses momentum over successive impacts, or stops dead upon contact. This article explains how the restitution coefficient functions, how it governs elastic and inelastic collisions, and how to implement it within a 2D JavaScript physics loop.

What is the Coefficient of Restitution?

The coefficient of restitution (often denoted as e) is the ratio of relative velocity between two objects after a collision to their relative velocity before the collision. Mathematically, it is defined as:

\[e = \frac{v_{2}' - v_{1}'}{v_{1} - v_{2}}\]

Where \(v\) represents pre-collision velocities and \(v'\) represents post-collision velocities along the collision normal.

  • \(e = 1\) (Perfectly Elastic): The object conserves all kinetic energy. A ball dropped with \(e = 1\) will bounce back to the exact height from which it was released.
  • \(0 < e < 1\) (Inelastic): Kinetic energy is partially dissipated (converted to heat, sound, or deformation). This reflects real-world physics, causing each successive bounce to diminish.
  • \(e = 0\) (Perfectly Inelastic): All relative velocity along the collision axis is lost upon impact. The object stops bouncing instantly and sticks to or slides along the surface.

Boundary Collisions (Object vs. Environment)

The simplest application of restitution occurs when an object collides with a static boundary, such as a floor or a canvas edge. Because the boundary has infinite mass and zero velocity, you apply the coefficient directly to invert and scale the moving object's velocity along the axis of collision:

// Update ball position
ball.y += ball.vy;
ball.vy += gravity;

// Boundary check against canvas floor
if (ball.y + ball.radius > canvas.height) {
  // Prevent the ball from sinking into the floor
  ball.y = canvas.height - ball.radius;

  // Invert and scale velocity by the restitution coefficient
  ball.vy = -ball.vy * ball.restitution;

  // Settle threshold to prevent endless micro-bouncing (jitter)
  if (Math.abs(ball.vy) < 0.5) {
    ball.vy = 0;
  }
}

In this implementation, setting ball.restitution = 0.8 means the ball retains 80% of its speed after each floor strike.

Resolving Collisions Between Two Moving Objects

When two dynamic bodies collide, both objects possess individual restitution values. In physics engines, these values are commonly combined using one of three methods:

  • Minimum: Math.min(objA.restitution, objB.restitution) (conservative approach)
  • Average: (objA.restitution + objB.restitution) / 2
  • Multiplication: objA.restitution * objB.restitution

Once the effective restitution coefficient (\(e\)) is determined, the collision response is calculated along the collision normal vector:

function resolveCollision(bodyA, bodyB) {
  // 1. Calculate normal vector from bodyA to bodyB
  const nx = bodyB.x - bodyA.x;
  const ny = bodyB.y - bodyA.y;
  const distance = Math.hypot(nx, ny);

  if (distance === 0) return; // Prevent division by zero

  const normalX = nx / distance;
  const normalY = ny / distance;

  // 2. Relative velocity
  const relVx = bodyB.vx - bodyA.vx;
  const relVy = bodyB.vy - bodyA.vy;

  // 3. Velocity along the normal
  const velAlongNormal = relVx * normalX + relVy * normalY;

  // Do not resolve if objects are already separating
  if (velAlongNormal > 0) return;

  // 4. Calculate effective restitution
  const e = Math.min(bodyA.restitution, bodyB.restitution);

  // 5. Calculate impulse scalar
  const invMassA = 1 / bodyA.mass;
  const invMassB = 1 / bodyB.mass;
  const impulseMagnitude = -(1 + e) * velAlongNormal / (invMassA + invMassB);

  // 6. Apply impulse along normal
  bodyA.vx -= impulseMagnitude * invMassA * normalX;
  bodyA.vy -= impulseMagnitude * invMassA * normalY;
  bodyB.vx += impulseMagnitude * invMassB * normalX;
  bodyB.vy += impulseMagnitude * invMassB * normalY;
}

In the formula above, the term -(1 + e) * velAlongNormal determines the strength of the impulse. If \(e = 0\), the collision will produce just enough force to eliminate the relative closing speed, halting bounce separation. If \(e = 1\), it reflects the relative velocity entirely, producing a high-energy rebound.
