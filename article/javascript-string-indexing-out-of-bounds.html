JavaScript String Indexing Out of Bounds

When accessing out-of-bounds character indices in JavaScript, the returned value depends entirely on the method used. Accessing an index that does not exist using bracket notation (str[index]) or the modern str.at() method returns undefined, whereas using the traditional str.charAt() method returns an empty string (""). JavaScript does not throw an IndexOutOfBoundsException or any runtime error when reading beyond the valid range of a string.

Bracket Notation ([])

Bracket notation treats a string similarly to an array-like object. When you attempt to access an index that is either negative or greater than or equal to str.length, JavaScript attempts to read a non-existent property on the string object.

const text = "hello";

console.log(text[10]); // Output: undefined
console.log(text[-1]); // Output: undefined

Because property lookups on missing keys default to undefined, this operation evaluates safely without terminating code execution.

The charAt() Method

The String.prototype.charAt() method is an older, dedicated string method that converts the passed index to an integer. If the specified index falls outside the range between 0 and str.length - 1, it returns an empty string.

const text = "hello";

console.log(text.charAt(10)); // Output: ""
console.log(text.charAt(-1)); // Output: ""

This behavior can cause subtle bugs if a program relies on truthiness checks, as an empty string ("") and undefined are both falsy, but their types (string vs. undefined) differ.

The at() Method

Introduced in ECMAScript 2022, String.prototype.at() allows both positive and negative integer indexing. Negative integers count backward from the end of the string. However, if the index still lies outside the range (i.e., less than -str.length or greater than or equal to str.length), at() returns undefined.

const text = "hello";

console.log(text.at(10));  // Output: undefined
console.log(text.at(-1));  // Output: "o" (valid negative index)
console.log(text.at(-10)); // Output: undefined (out of bounds)

Key Differences and Best Practices

  • Return Types: Bracket notation and at() return undefined when out of bounds, while charAt() returns "".
  • Negative Indices: Only at() supports negative indexing to access characters from the end. Bracket notation interprets negative values as literal string keys (e.g., text["-1"]), which do not exist and resolve to undefined.
  • Safety: None of these approaches throw an error on read operations, but attempting to perform property lookups or call string methods on an out-of-bounds result from bracket notation or at() will result in a TypeError: Cannot read properties of undefined.
