Slope Angles Using Surface Normals in JavaScript

Calculating slope angles using surface normals is a fundamental technique in 2D platformer game development for handling irregular terrain, slopes, and player physics. In JavaScript games, this method involves deriving a perpendicular vector—known as the surface normal—from a terrain segment and using trigonometry to extract its angle relative to the world coordinate system. By obtaining this angle, developers can dynamically adjust player movement speed, determine whether a surface is too steep to walk on, and properly align character sprites or velocity vectors to smooth out traversal across non-flat surfaces.

Understanding the Surface Normal

A surface normal is a unit vector pointing directly outward, perpendicular to a surface. In a 2D Cartesian coordinate system where the Y-axis points downward (common in HTML5 Canvas and WebGL game engines), a flat floor has an upward-pointing normal of (0, -1).

When a player steps onto a sloped line segment defined by two points, \(A(x_1, y_1)\) and \(B(x_2, y_2)\), the direction vector (tangent) of the surface is:

\[\Delta x = x_2 - x_1\] \[\Delta y = y_2 - y_1\]

To find the perpendicular normal pointing outward (typically to the "left" of the traversal direction), rotate the direction vector by 90 degrees and normalize it:

function getSurfaceNormal(p1, p2) {
  const dx = p2.x - p1.x;
  const dy = p2.y - p1.y;
  const length = Math.hypot(dx, dy);

  if (length === 0) return { x: 0, y: -1 };

  // 90-degree counter-clockwise rotation normalized
  return {
    x: dy / length,
    y: -dx / length
  };
}

Calculating the Slope Angle

There are two primary methods to derive a slope angle from a normal vector: using the arctangent function or using the vector dot product.

1. Using Math.atan2

The Math.atan2(y, x) function converts coordinates directly into radians relative to the positive X-axis. To calculate the tilt angle of the slope itself relative to flat ground:

function getSlopeAngle(normal) {
  // Returns angle in radians relative to flat ground (normal: {x: 0, y: -1})
  return Math.atan2(normal.x, -normal.y);
}

function toDegrees(radians) {
  return radians * (180 / Math.PI);
}

If the normal is (0, -1), Math.atan2(0, 1) yields 0 radians (\(0^\circ\)). If the normal tilts to the right (0.707, -0.707), it yields approximately \(0.785\) radians (\(45^\circ\)).

2. Using the Dot Product

If you only need the absolute steepness (incline magnitude) regardless of left-or-right direction, use the dot product of the normal and the world "up" vector (0, -1):

\[\vec{n} \cdot \vec{up} = (n_x \cdot 0) + (n_y \cdot -1) = -n_y\]

Because both vectors are normalized, the angle \(\theta\) is:

\[\theta = \arccos(-n_y)\]

function getSteepnessAngle(normal) {
  // Clamp value between -1 and 1 to prevent floating-point errors
  const dot = Math.max(-1, Math.min(1, -normal.y));
  return Math.acos(dot); // Returns angle in radians from 0 (flat) to PI (upside down)
}

Platformer Gameplay Applications

Steepness and Sliding

A game character typically has a maximum climbable angle (e.g., \(45^\circ\) or \(\approx 0.785\) radians). If the calculated angle exceeds this threshold, the player state switches from "grounded" to "sliding":

const MAX_SLOPE_ANGLE = Math.PI / 4; // 45 degrees

const slopeIncline = getSteepnessAngle(surfaceNormal);

if (slopeIncline > MAX_SLOPE_ANGLE) {
  player.isGrounded = false;
  player.isSliding = true;
  // Apply downward acceleration along the slope
  player.vx += surfaceNormal.x * slideAcceleration;
}

Velocity Projection

To prevent a character from launching off upward slopes or jittering when running down them, project the player's horizontal movement vector along the slope's tangent. The tangent can be constructed directly from the normal:

function projectVelocityOnSlope(velocity, normal) {
  // Tangent perpendicular to the normal
  const tangent = { x: -normal.y, y: normal.x };
  
  // Dot product of velocity and tangent
  const speedAlongSlope = (velocity.x * tangent.x) + (velocity.y * tangent.y);

  return {
    x: tangent.x * speedAlongSlope,
    y: tangent.y * speedAlongSlope
  };
}

This normal-based calculation guarantees smooth physics updates, precise collision responses, and predictable player movement across varied geometric terrain.
