JavaScript String replaceAll Explained

The String.prototype.replaceAll() method in JavaScript provides a native, straightforward way to replace all occurrences of a specified substring or regular expression pattern within a string without altering the original string. This article covers how replaceAll() works, its syntax, how it handles both string and RegExp inputs, and how to use replacement strings and replacer functions effectively.

Syntax and Basic Mechanics

The syntax for replaceAll() is:

string.replaceAll(pattern, replacement)

The method returns a brand-new string with all matches replaced. Strings in JavaScript are immutable, so the original string remains untouched.

Replacing Substrings

Prior to ES2021, the standard replace() method only replaced the first occurrence when given a string search pattern. To replace all instances, developers had to use regular expressions with the global flag (/g) or workarounds like .split().join().

replaceAll() simplifies this by replacing every exact instance of a string pattern:

const sentence = "The quick brown fox jumps over the lazy dog. The fox is fast.";
const updated = sentence.replaceAll("fox", "cat");

console.log(updated);
// Output: "The quick brown cat jumps over the lazy dog. The cat is fast."

Using Regular Expressions with replaceAll

You can pass a regular expression as the pattern argument, but it must have the global flag (g) enabled. If the regular expression lacks the g flag, JavaScript throws a TypeError.

const text = "apple 1, apple 2, apple 3";

// Valid: RegExp contains the 'g' flag
const result = text.replaceAll(/apple/g, "orange");
console.log(result); // "orange 1, orange 2, orange 3"

// Throws TypeError: String.prototype.replaceAll called with a non-global RegExp argument
const errorExample = text.replaceAll(/apple/, "orange");

This enforcement prevents accidental infinite loops and distinguishes the intentional use of replaceAll from standard replace.

Replacement Patterns and Substitution Strings

When the replacement argument is a string, you can use special replacement patterns to inject portions of the match:

  • $$: Inserts a literal dollar sign ($).
  • $&: Inserts the matched substring.
  • `$``: Inserts the portion of the string that precedes the matched substring.
  • $': Inserts the portion of the string that follows the matched substring.
  • $n: Inserts the n-th parenthesized capture group (1-indexed) if using a RegExp.

Example using $&:

const quote = "Item: pen, Item: book";
const result = quote.replaceAll("Item", "$& (sold)");

console.log(result);
// Output: "Item (sold): pen, Item (sold): book"

Dynamic Replacements with a Function

Instead of a static string, the replacement parameter can be a callback function. This function executes once for every match found, allowing for dynamic evaluation:

const prices = "Prices: 10, 25, 40";
const withTax = prices.replaceAll(/\d+/g, (match) => {
  const taxed = Number(match) * 1.1;
  return taxed.toFixed(2);
});

console.log(withTax);
// Output: "Prices: 11.00, 27.50, 44.00"

The replacer function receives the following arguments:

  1. match: The matched substring.
  2. p1, p2, ...: Capture groups (if the pattern is a RegExp with capture groups).
  3. offset: The zero-based index of the matched substring within the whole string.
  4. string: The original string being processed.

Summary

String.prototype.replaceAll() simplifies global search-and-replace operations in JavaScript. It removes the necessity of escaping special characters for simple string-based global replacements and ensures type safety by enforcing the global flag on regular expressions.
