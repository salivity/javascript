How to Use JavaScript Intl.DisplayNames API

The Intl.DisplayNames API is a built-in JavaScript object that provides consistent, localized names for internationalization codes, such as countries, languages, currencies, and scripts. This article explains how the API works, why it eliminates the need for massive third-party translation dictionaries, and how to use it to translate ISO region and language codes into any target language directly in the browser or Node.js.

What is the Intl.DisplayNames API?

The Intl.DisplayNames object is a native part of the ECMAScript Internationalization API (ECMA-402). Traditionally, translating a country code like "FR" into "France" (English) or "Francia" (Spanish) required developers to import large JSON mapping files or external libraries into their bundles.

Intl.DisplayNames solves this by leveraging the Unicode Common Locale Data Repository (CLDR) already embedded within modern JavaScript engines. It allows you to dynamically translate standard identifiers into human-readable strings based on a specified target locale.

Basic Syntax

To use the API, you initialize an instance using the constructor, passing the target output locale and an options object, then call the .of() method with the code you want to translate:

const displayNames = new Intl.DisplayNames(locales, options);
const translatedName = displayNames.of(code);
  • locales: A string or array of BCP 47 language tags (e.g., 'en', 'es', 'de') indicating the output language.
  • options: An object that must contain the type property. Valid types include 'region', 'language', 'currency', and 'script'.

Translating Country Codes (Regions)

To translate ISO 3166-1 alpha-2 country codes into localized names, set the type option to 'region'.

// Display country names in English
const regionNamesEnglish = new Intl.DisplayNames(['en'], { type: 'region' });
console.log(regionNamesEnglish.of('US')); // "United States"
console.log(regionNamesEnglish.of('JP')); // "Japan"
console.log(regionNamesEnglish.of('DE')); // "Germany"

// Display the same country names in Spanish
const regionNamesSpanish = new Intl.DisplayNames(['es'], { type: 'region' });
console.log(regionNamesSpanish.of('US')); // "Estados Unidos"
console.log(regionNamesSpanish.of('JP')); // "Japón"
console.log(regionNamesSpanish.of('DE')); // "Alemania"

Translating Language Codes

To convert ISO 639 language tags into full display names, set the type option to 'language'.

// Display language names in French
const langNamesFrench = new Intl.DisplayNames(['fr'], { type: 'language' });
console.log(langNamesFrench.of('en')); // "anglais"
console.log(langNamesFrench.of('zh')); // "chinois"
console.log(langNamesFrench.of('es')); // "espagnol"

// Display language names in their native locales or another target
const langNamesGerman = new Intl.DisplayNames(['de'], { type: 'language' });
console.log(langNamesGerman.of('en')); // "Englisch"
console.log(langNamesGerman.of('ja')); // "Japanisch"

The API also supports regional sub-tags:

const langNamesEnglish = new Intl.DisplayNames(['en'], { type: 'language' });
console.log(langNamesEnglish.of('en-US')); // "American English"
console.log(langNamesEnglish.of('en-GB')); // "British English"
console.log(langNamesEnglish.of('pt-BR')); // "Brazilian Portuguese"

Additional Options: Style and Fallback

You can customize the output using optional configuration parameters:

  • style: Determines the length of the result. Options are 'long' (default), 'short', or 'narrow'.
  • fallback: Dictates behavior when a translation is unavailable. Options are 'code' (default, which returns the input code) or 'none' (which returns undefined).
const shortNames = new Intl.DisplayNames(['en'], { 
  type: 'region', 
  style: 'short' 
});

console.log(shortNames.of('US')); // "US"

By relying on Intl.DisplayNames, applications reduce JavaScript bundle sizes, gain out-of-the-box support for hundreds of locales, and ensure that localized strings stay updated automatically with platform updates.
