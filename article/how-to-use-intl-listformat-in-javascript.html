How to Use Intl.ListFormat in JavaScript

The Intl.ListFormat object in JavaScript provides a language-sensitive way to join arrays of strings into natural-language lists. Instead of manually writing error-prone string manipulation functions to handle commas and conjunctions, Intl.ListFormat automatically applies locale-specific grammatical rules, conjunctions, and punctuation marks like the Oxford comma.

Basic Syntax

To use Intl.ListFormat, create an instance by passing a locale identifier and an optional configuration object, then invoke the .format() method on your array.

const items = ['Apples', 'Bananas', 'Oranges'];

const formatter = new Intl.ListFormat('en', { style: 'long', type: 'conjunction' });
console.log(formatter.format(items));
// Output: "Apples, Bananas, and Oranges"

Configuration Options

The constructor accepts two main options to tailor the output: type and style.

1. type

The type property defines the syntactic role of the list:

  • conjunction (default): Joins items with "and" or its localized equivalent to describe a collection.
  • disjunction: Joins items with "or" or its localized equivalent to describe alternatives.
  • unit: Formats lists of values with units without using conjunctions.
const options = ['Red', 'Green', 'Blue'];

const disjunction = new Intl.ListFormat('en', { type: 'disjunction' });
console.log(disjunction.format(options));
// Output: "Red, Green, or Blue"

2. style

The style property determines the length and visual weight of the output:

  • long (default): Spells out conjunctions and separators fully (e.g., "A, B, and C").
  • short: Uses shorter separators or abbreviations where appropriate.
  • narrow: Condenses elements as tightly as the locale allows, often omitting standard conjunctions entirely.
const vehicles = ['Cars', 'Motorcycles', 'Bicycles'];

const narrow = new Intl.ListFormat('en', { style: 'narrow', type: 'conjunction' });
console.log(narrow.format(vehicles));
// Output: "Cars, Motorcycles, Bicycles"

Localization Handling

The primary advantage of Intl.ListFormat is its adherence to regional grammar rules. Different languages place conjunctions differently or modify the conjunction depending on the phonetic context of the surrounding words.

const fruits = ['manzanas', 'plátanos', 'naranjas'];

// Spanish conjunction: "y"
const esConjunction = new Intl.ListFormat('es', { type: 'conjunction' });
console.log(esConjunction.format(fruits));
// Output: "manzanas, plátanos y naranjas"

// German disjunction: "oder"
const deDisjunction = new Intl.ListFormat('de', { type: 'disjunction' });
console.log(deDisjunction.format(['Katzen', 'Hunde']));
// Output: "Katzen oder Hunde"

Granular Output with formatToParts()

If you need to render the output inside UI components—such as React elements or HTML nodes where individual list items require custom CSS styling or hyperlinking—use formatToParts(). This method returns an array of objects describing each token (element vs. literal separator).

const users = ['Alice', 'Bob', 'Charlie'];
const formatter = new Intl.ListFormat('en', { style: 'long', type: 'conjunction' });

console.log(formatter.formatToParts(users));
/*
Output:
[
  { type: 'element', value: 'Alice' },
  { type: 'literal', value: ', ' },
  { type: 'element', value: 'Bob' },
  { type: 'literal', value: ', and ' },
  { type: 'element', value: 'Charlie' }
]
*/

By relying on Intl.ListFormat, JavaScript applications can effortlessly produce grammatically accurate, localized sentences across all modern browsers and Node.js environments without third-party dependencies.
