JavaScript Range API: Extract and Clone DOM Nodes

The JavaScript Range API provides developers with a standard way to select, read, clone, and manipulate arbitrary fragments of a document tree, even when the selection spans across multiple HTML nodes. This article explains the fundamentals of the Range object and demonstrates how to utilize its core methods, specifically extractContents() and cloneContents(), to handle DOM fragments cleanly and efficiently.

What is the Range API?

A Range object represents a continuous fragment of a document. Unlike typical DOM manipulation methods that require selecting entire elements, a Range can start and end anywhere—including within the middle of text nodes.

You can create an empty Range using the document.createRange() method, or retrieve an existing user selection using window.getSelection().getRangeAt(index).

A range is defined by two boundary points:

  • Start Boundary: Specified by a node (startContainer) and an offset (startOffset).
  • End Boundary: Specified by a node (endContainer) and an offset (endOffset).

Setting Up a Range

To target specific content, you set the boundaries manually using methods like setStart and setEnd:

const range = document.createRange();
const startNode = document.getElementById('paragraph-one').firstChild;
const endNode = document.getElementById('paragraph-two').firstChild;

// Select from the 5th character of paragraph-one to the 10th of paragraph-two
range.setStart(startNode, 5);
range.setEnd(endNode, 10);

You can also select entire elements or their contents:

  • range.selectNode(element): Selects the element and all of its child nodes.
  • range.selectNodeContents(element): Selects only the child nodes inside the specified element.

Cloning Content with cloneContents()

The cloneContents() method duplicates the contents defined by the Range without altering the source document.

How It Works:

  1. It traverses all nodes that fall within the range boundaries.
  2. If a node is partially included, the method duplicates only the included portion.
  3. It packages the cloned nodes into a DocumentFragment and returns it.
const range = document.createRange();
const sourceElement = document.getElementById('source');
range.selectNodeContents(sourceElement);

// Clone the content
const clonedFragment = range.cloneContents();

// Append the cloned fragment elsewhere in the DOM
document.getElementById('destination').appendChild(clonedFragment);

Because it returns a DocumentFragment, the original DOM remains completely untouched, making it ideal for previews, undo buffers, or duplicating user-selected text and markup.

Extracting Content with extractContents()

The extractContents() method removes the nodes defined within the Range from the live DOM tree and places them into a DocumentFragment.

How It Works:

  1. It identifies all nodes and partial text within the Range.
  2. It detaches these items from the original document. If a partially selected node (such as a paragraph tag) spans across the boundary, the browser splits the node, leaving the unselected portion in the original document while moving the selected portion into the fragment.
  3. The resulting DocumentFragment is returned, ready to be inserted elsewhere.
const range = document.createRange();
const contentToMove = document.getElementById('movable-text');
range.selectNodeContents(contentToMove);

// Extract the content from the live DOM
const extractedFragment = range.extractContents();

// The original '#movable-text' is now empty
// Move the extracted fragment to another container
document.getElementById('new-location').appendChild(extractedFragment);

Key Differences Between Cloning and Extracting

Method Effect on Original DOM Return Type Typical Use Case
cloneContents() None (non-destructive) DocumentFragment Duplicating content, generating previews
extractContents() Removes nodes (destructive) DocumentFragment Moving elements, custom cut-and-paste
deleteContents() Removes nodes (destructive) void Deleting selected ranges without saving

Both methods preserve valid HTML structure by automatically closing and reopening tags that are only partially bounded by the range. This structural integrity makes the Range API significantly safer for text and node manipulation than modifying innerHTML strings directly.
