Tracking Player Coordinates on a Minimap in JavaScript

In JavaScript game programming, a mini-map radar tracks player and entity coordinates by converting large-scale world-space units into smaller, proportional UI-space pixels in real time. This process involves calculating scale factors between the game world and the radar interface, applying coordinate transformations, and rendering the results onto an HTML5 Canvas or DOM element during every cycle of the game loop. By synchronizing positional data with rendering routines, developers create responsive, accurate navigation displays for both static and rotating radar interfaces.

Understanding World Space vs. Radar Space

Video games operate within a coordinate system known as "world space," where an environment might measure thousands of pixels or units across (for example, a 5,000 × 5,000 unit area). A mini-map radar operates in a much smaller "radar space," typically confined to a specific UI container (such as 200 × 200 pixels).

Tracking coordinates requires translating an object’s position from world space to radar space. This is governed by a scaling ratio determined by the relative sizes of both spaces:

const scaleX = radarWidth / worldWidth;
const scaleY = radarHeight / worldHeight;

Static Full-Map Tracking

In a static mini-map, the entire game map is displayed within the radar boundaries, and the player icon moves across it.

To determine the player's position on the radar:

  1. Retrieve the player's world coordinates: (player.x, player.y).

  2. Multiply those coordinates by the scale factor:

    const radarPlayerX = player.x * scaleX;
const radarPlayerY = player.y * scaleY;

  3. Draw the indicator (often a small circle or arrow) at (radarPlayerX, radarPlayerY) on the radar surface.

Centered Dynamic Radar Tracking

Many games use a dynamic, rotating radar where the player remains pinned to the absolute center of the display, and surrounding entities or landmarks move relative to the player.

In this model, the radar center coordinates are:

const centerX = radarWidth / 2;
const centerY = radarHeight / 2;

To plot an external entity or landmark relative to the player:

  1. Calculate the distance vector between the target and the player:

    const deltaX = target.x - player.x;
const deltaY = target.y - player.y;

  2. Apply the radar scale factor:

    let blipX = centerX + (deltaX * scaleX);
let blipY = centerY + (deltaY * scaleY);

If the radar rotates based on the player’s viewing angle (heading), apply a 2D rotation matrix using the player's angle in radians:

const cosTheta = Math.cos(-player.angle);
const sinTheta = Math.sin(-player.angle);

const rotatedX = deltaX * cosTheta - deltaY * sinTheta;
const rotatedY = deltaX * sinTheta + deltaY * cosTheta;

const blipX = centerX + (rotatedX * scaleX);
const blipY = centerY + (rotatedY * scaleY);

Edge Clamping and Clipping

Circular radars require an additional step to ensure blips outside the radar's detection range do not draw outside the boundary:

  1. Calculate the Euclidean distance of the entity from the center:

    const distance = Math.hypot(blipX - centerX, blipY - centerY);
const maxRadius = radarWidth / 2;

  2. If distance > maxRadius, clamp the blip coordinates along the perimeter using trigonometry:

    if (distance > maxRadius) {
    const angle = Math.atan2(blipY - centerY, blipX - centerX);
    blipX = centerX + maxRadius * Math.cos(angle);
    blipY = centerY + maxRadius * Math.sin(angle);
}

  3. Alternatively, discard targets beyond maxRadius entirely if the radar only tracks localized threats.

Real-Time Rendering Loop

To maintain accurate tracking, this math must execute inside the main animation loop (requestAnimationFrame).

function renderRadar(ctx, player, targets) {
    // Clear radar background
    ctx.clearRect(0, 0, radarWidth, radarHeight);

    // Draw player at the center
    ctx.fillStyle = "blue";
    ctx.beginPath();
    ctx.arc(radarWidth / 2, radarHeight / 2, 4, 0, Math.PI * 2);
    ctx.fill();

    // Draw other entities
    ctx.fillStyle = "red";
    targets.forEach(target => {
        const deltaX = (target.x - player.x) * scaleX;
        const deltaY = (target.y - player.y) * scaleY;
        
        const blipX = (radarWidth / 2) + deltaX;
        const blipY = (radarHeight / 2) + deltaY;

        // Verify bounds before drawing
        if (Math.hypot(deltaX, deltaY) <= radarWidth / 2) {
            ctx.beginPath();
            ctx.arc(blipX, blipY, 3, 0, Math.PI * 2);
            ctx.fill();
        }
    });
}

Through consistent scale mapping, relative vector arithmetic, and frame-by-frame canvas updates, JavaScript mini-maps continuously mirror real-time game coordinates into a compact UI element.
