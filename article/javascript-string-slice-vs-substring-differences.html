JavaScript String slice vs substring Differences

Both String.prototype.slice and String.prototype.substring are built-in JavaScript methods used to extract a section of a string and return it as a new string without modifying the original. While they share similar syntax and behave identically when passed positive, ascending indices, they handle negative numbers, swapped arguments, and out-of-range values in fundamentally different ways.

Syntax and Basic Usage

Both methods accept two parameters:

  • start: The zero-based index at which to begin extraction.
  • end (optional): The zero-based index before which to end extraction (the character at this index is excluded).
const text = "JavaScript";

// Both return "Java"
console.log(text.slice(0, 4));
console.log(text.substring(0, 4));

Key Difference 1: Handling Negative Arguments

The most significant difference between the two methods is how they interpret negative numbers.

  • slice: Treats negative indices as offsets from the end of the string. A value of -1 refers to the last character, -2 to the second-to-last, and so forth.
  • substring: Treats any negative argument (or NaN) as 0.
const text = "JavaScript";

// slice counts from the end:
console.log(text.slice(-6));     // "Script"
console.log(text.slice(0, -6));    // "Java"

// substring converts negative numbers to 0:
console.log(text.substring(-6));   // "JavaScript" (treated as substring(0))
console.log(text.substring(0, -6)); // "" (treated as substring(0, 0))

Key Difference 2: Handling Inverted Indices (start > end)

When the first index is greater than the second index, the two methods respond with different logic:

  • slice: Returns an empty string ("") because extraction begins at a point ahead of the end point.
  • substring: Automatically swaps the two arguments so that the smaller number becomes the start index and the larger number becomes the end index.
const text = "JavaScript";

// start (4) is greater than end (0)
console.log(text.slice(4, 0));     // ""
console.log(text.substring(4, 0)); // "Java" (swapped to substring(0, 4))

Summary Comparison Table

Feature slice(start, end) substring(start, end)
Negative indices Counts backwards from the end of the string Treated as 0
start > end Returns an empty string "" Swaps arguments: (end, start)
NaN arguments Treated as 0 Treated as 0
Array equivalent Yes (Array.prototype.slice) No equivalent array method

Which Method Should You Use?

In modern JavaScript development, String.prototype.slice is generally preferred. Its ability to accept negative indices allows for more concise code when working relative to the end of a string, and its behavior is consistent with Array.prototype.slice. Use substring primarily when you specifically need the automatic argument-swapping behavior.
