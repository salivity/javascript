Currency and Unit Formatting with Intl.NumberFormat

The Intl.NumberFormat object in JavaScript provides a native, high-performance way to format numbers according to specific cultural and linguistic conventions. This guide explores how to leverage the API to format localized currencies and measurement units, configure display options such as symbols and compact notation, and ensure consistent internationalization across modern browsers without relying on external libraries.

Understanding the Basics

The Intl.NumberFormat constructor accepts two primary arguments: a locales tag (such as 'en-US', 'de-DE', or 'ja-JP') and an options object configuring the output style.

const formatter = new Intl.NumberFormat(locales, options);
formatter.format(number);

You can also call the convenience method Number.prototype.toLocaleString(), but creating an instance of Intl.NumberFormat is significantly faster when formatting large lists of numbers because it caches the locale resolution.

Localized Currency Formatting

To format currencies, set the style option to 'currency' and supply an ISO 4217 currency code to the currency property.

const amount = 123456.78;

// US Dollar formatting
const usdFormatter = new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD',
});
console.log(usdFormatter.format(amount)); 
// Output: "$123,456.78"

// Euro formatting with German locale
const eurFormatter = new Intl.NumberFormat('de-DE', {
  style: 'currency',
  currency: 'EUR',
});
console.log(eurFormatter.format(amount)); 
// Output: "123.456,78 €"

The API automatically handles proper placement of currency symbols, standard digit grouping, and decimal separators appropriate for each locale.

Customizing Currency Display

The currencyDisplay property controls how the currency identifier appears:

  • 'symbol' (default): Displays localized symbols like $ or €.
  • 'narrowSymbol': Uses shorter symbols if available (e.g., $ instead of US$).
  • 'code': Uses the ISO code (e.g., USD, EUR).
  • 'name': Spells out the currency name (e.g., US dollars).
const amount = 50;

console.log(new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'CAD',
  currencyDisplay: 'narrowSymbol'
}).format(amount)); 
// Output: "$50.00"

console.log(new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'CAD',
  currencyDisplay: 'name'
}).format(amount)); 
// Output: "50.00 Canadian dollars"

Localized Unit Formatting

By setting the style property to 'unit', you can format physical measurements such as speed, length, volume, and temperature. The unit property accepts identifiers standardized in the Unicode CLDR (Common Locale Data Repository).

const distance = 42.5;

const kmFormatter = new Intl.NumberFormat('en-US', {
  style: 'unit',
  unit: 'kilometer',
});
console.log(kmFormatter.format(distance)); 
// Output: "42.5 km"

const kmGermanFormatter = new Intl.NumberFormat('de-DE', {
  style: 'unit',
  unit: 'kilometer',
});
console.log(kmGermanFormatter.format(distance)); 
// Output: "42,5 km"

Compound units can be specified by combining base units with -per-:

const speedFormatter = new Intl.NumberFormat('en-US', {
  style: 'unit',
  unit: 'mile-per-hour',
});
console.log(speedFormatter.format(65)); 
// Output: "65 mph"

Controlling Unit Verbosity

The unitDisplay option adjusts the representation between abbreviated and verbose forms:

  • 'short' (default): Uses standard abbreviations (e.g., 16 fl oz).
  • 'narrow': Uses compact abbreviations, often without spaces (e.g., 16floz).
  • 'long': Uses fully written names adjusted for pluralization (e.g., 16 fluid ounces).
const volume = 1;

console.log(new Intl.NumberFormat('en-US', {
  style: 'unit',
  unit: 'liter',
  unitDisplay: 'long',
}).format(volume)); 
// Output: "1 liter"

console.log(new Intl.NumberFormat('en-US', {
  style: 'unit',
  unit: 'liter',
  unitDisplay: 'long',
}).format(5)); 
// Output: "5 liters"

Precision and Notation Controls

Both currency and unit modes support general number formatting controls:

  • minimumFractionDigits and maximumFractionDigits: Controls decimal precision.
  • notation: Accepts 'standard', 'scientific', 'engineering', or 'compact'.
const followers = 1250000;

const compactFormatter = new Intl.NumberFormat('en-US', {
  notation: 'compact',
  compactDisplay: 'short',
});
console.log(compactFormatter.format(followers)); 
// Output: "1.3M"

const compactCurrency = new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD',
  notation: 'compact',
});
console.log(compactCurrency.format(followers)); 
// Output: "$1.3M"

By relying on Intl.NumberFormat, applications eliminate the need for fragile regex operations and heavy localization libraries, providing native, culturally accurate output across all target locales.
