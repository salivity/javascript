Pipe vs Compose in JavaScript

In functional JavaScript programming, both pipe and compose are utility functions designed to combine multiple smaller functions into a single pipeline where the output of one function becomes the input of the next. The fundamental difference between them is the direction of execution: compose runs functions from right to left (bottom to top), whereas pipe runs functions from left to right (top to bottom). This guide explains how both utilities operate, compares their implementations, and clarifies when to use each.

Direction of Execution

The distinction between pipe and compose comes down to how arguments are processed:

  • compose (Right-to-Left): Follows the standard mathematical notation of function composition \((f \circ g)(x) = f(g(x))\). The function listed farthest to the right executes first, passing its result to the function on its left.
  • pipe (Left-to-Right): Mimics standard reading order and Unix terminal piping (data | step1 | step2). The function listed farthest to the left executes first, passing its result to the function on its right.

Code Demonstration

Consider two simple transformation functions:

const double = (x) => x * 2;
const addTen = (x) => x + 10;

Using Compose

// compose(f, g)(x) => f(g(x))
const addTenThenDouble = compose(double, addTen);

addTenThenDouble(5); 
// 1. addTen(5) executes first => 15
// 2. double(15) executes second => 30
// Result: 30

Using Pipe

// pipe(f, g)(x) => g(f(x))
const addTenThenDouble = pipe(addTen, double);

addTenThenDouble(5); 
// 1. addTen(5) executes first => 15
// 2. double(15) executes second => 30
// Result: 30

Underlying Implementation

In JavaScript, both functions can be constructed using array reduction methods. pipe relies on reduce, whereas compose relies on reduceRight.

// Pipe: Left-to-right execution
const pipe = (...fns) => (initialValue) =>
  fns.reduce((acc, fn) => fn(acc), initialValue);

// Compose: Right-to-left execution
const compose = (...fns) => (initialValue) =>
  fns.reduceRight((acc, fn) => fn(acc), initialValue);

Because of their inverse nature, pipe can also be implemented by reversing the functions and running compose:

const pipe = (...fns) => compose(...fns.reverse());

Naming in Popular JavaScript Libraries

Different functional libraries use slightly different naming conventions for these two operations:

  • Ramda: Provides R.pipe and R.compose.
  • Lodash / Lodash/fp: Uses flow for pipe (left-to-right) and flowRight for compose (right-to-left).
  • Redux: Exports a native compose function, commonly used to apply multiple store enhancers and middleware from right to left.

Choosing Between Pipe and Compose

The choice between pipe and compose does not affect performance or functional capability; it primarily affects readability:

  • Use pipe when prioritizing linear readability. Most developers naturally read code from top to bottom and left to right. Tracing transformations in the exact sequence they happen reduces cognitive load.
  • Use compose when adhering strictly to mathematical conventions or integrating with tools that default to right-to-left composition, such as Redux middleware enhancers.
