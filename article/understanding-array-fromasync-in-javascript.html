Understanding Array.fromAsync in JavaScript

Array.fromAsync is a built-in JavaScript method that simplifies creating arrays from asynchronous iterables, readable streams, and collections containing promises. This article covers what Array.fromAsync is, its syntax, how it processes asynchronous data sequentially, and practical code examples demonstrating its use alongside async generators and mapping functions.

What Is Array.fromAsync?

Array.fromAsync is a static method on the Array constructor. It acts as the asynchronous counterpart to Array.from(). While Array.from() converts synchronous iterables (like Set, Map, or standard arrays) and array-like objects into new array instances, Array.fromAsync resolves and collects values from asynchronous iterables—objects implementing Symbol.asyncIterator—as well as synchronous iterables containing promises.

The method returns a promise that resolves to a new, shallow-copied Array instance containing all the resolved values.

Syntax

Array.fromAsync(asyncIterable, mapFn, thisArg)
  • asyncIterable: An async iterable, sync iterable, or array-like object to convert to an array.
  • mapFn (optional): A mapping function to call on every element. This function can be synchronous or asynchronous (returning a promise).
  • thisArg (optional): Value to use as this when executing mapFn.

Constructing Arrays from Async Iterables

When passed an async iterable, Array.fromAsync iterates through the items sequentially using a for await...of loop internally. It awaits each promise yielded by the iterator before moving to the next item, ensuring the values are placed in the resulting array in the order they resolve.

Example: Consuming an Async Generator

Async generator functions yield promises over time. Array.fromAsync collects these yields directly into a single array:

async function* fetchSequence() {
  yield 1;
  await new Promise((resolve) => setTimeout(resolve, 100));
  yield 2;
  yield 3;
}

async function run() {
  const result = await Array.fromAsync(fetchSequence());
  console.log(result); // [1, 2, 3]
}

run();

Handling Iterables with Promises

Array.fromAsync can also process synchronous iterables containing promises. Unlike Array.from(), which would leave the promises unresolved in the array, Array.fromAsync awaits each promise before finalizing the array.

const promises = [
  Promise.resolve("A"),
  Promise.resolve("B"),
  Promise.resolve("C")
];

async function resolveArray() {
  const result = await Array.fromAsync(promises);
  console.log(result); // ['A', 'B', 'C']
}

resolveArray();

Using the Mapping Function

The optional mapFn parameter allows transforming elements during the collection process. If mapFn returns a promise, Array.fromAsync awaits its resolution before storing the element.

async function* numbers() {
  yield 1;
  yield 2;
  yield 3;
}

async function doubleNumbers() {
  const doubled = await Array.fromAsync(numbers(), async (n) => {
    return n * 2;
  });
  console.log(doubled); // [2, 4, 6]
}

doubleNumbers();

Array.fromAsync vs. Promise.all

While Promise.all(syncArray.map(...)) evaluates operations concurrently, Array.fromAsync iterates sequentially. This sequential processing is essential for streams and asynchronous iterators where each step depends on the completion of the previous one or where concurrency needs to be restricted.
