How JavaScript Handles Division by Zero

In JavaScript, dividing a numeric value by zero does not throw a runtime error or halt execution. Instead, the language follows the IEEE 754 standard for floating-point arithmetic, returning the special values Infinity, -Infinity, or NaN. This article explains how JavaScript processes division by zero depending on whether the numerator and denominator are positive, negative, or zero.

Dividing a Positive Number by Zero

When you divide any positive numeric value greater than zero by positive zero (0 or +0), JavaScript returns positive Infinity.

console.log(10 / 0);   // Infinity
console.log(0.5 / 0);  // Infinity

However, JavaScript distinguishes between positive zero (+0) and negative zero (-0). Dividing a positive number by negative zero yields -Infinity:

console.log(10 / -0);  // -Infinity

Dividing a Negative Number by Zero

When you divide any negative numeric value less than zero by positive zero, the result is -Infinity.

console.log(-10 / 0);   // -Infinity
console.log(-0.5 / 0);  // -Infinity

Following normal rules of arithmetic signs, dividing a negative number by negative zero results in positive Infinity:

console.log(-10 / -0);  // Infinity

Dividing Zero by Zero

Dividing zero by zero does not yield infinity because the mathematical result is indeterminate. In this case, JavaScript evaluates the expression as NaN (Not a Number).

console.log(0 / 0);    // NaN
console.log(-0 / 0);   // NaN
console.log(0 / -0);   // NaN

Checking for Division by Zero Results

Because JavaScript does not raise an exception during division by zero, code that relies on numeric calculations should validate results using built-in methods:

  • Number.isFinite(value): Returns false if the value is Infinity, -Infinity, or NaN, making it ideal for verifying safe numeric results.
  • Number.isNaN(value): Determines whether the value is specifically NaN.
function safeDivide(a, b) {
  const result = a / b;
  if (!Number.isFinite(result)) {
    return null; // Handle division by zero or invalid input
  }
  return result;
}

console.log(safeDivide(10, 2)); // 5
console.log(safeDivide(10, 0)); // null
console.log(safeDivide(0, 0));  // null
