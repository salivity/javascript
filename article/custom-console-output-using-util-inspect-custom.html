Custom Console Output Using util.inspect.custom

Node.js provides the util.inspect.custom symbol to give developers explicit control over how JavaScript objects are rendered during logging and inspection. When an object defines a method keyed by this well-known symbol, methods like console.log() and util.inspect() delegate their formatting to that function instead of recursively enumerating the object's raw properties. This mechanism allows developers to hide sensitive data, summarize complex internal states, and format output cleanly without mutating standard methods like toString() or toJSON().

How It Works

When console.log() or util.inspect() encounters an object, Node.js checks whether that object has a property matching the symbol util.inspect.custom (accessible via Symbol.for('nodejs.util.inspect.custom') or the util.inspect.custom property from the node:util module).

If this method exists, Node.js executes it and uses its return value as the formatted output for the console. The method can return any value, such as a string, a formatted object, or an array.

Basic Implementation

To implement custom inspection, assign a function to the [util.inspect.custom] computed property key on an object or class prototype:

const util = require('node:util');

class SecureSession {
  constructor(sessionId, secretToken, userId) {
    this.sessionId = sessionId;
    this.secretToken = secretToken;
    this.userId = userId;
  }

  [util.inspect.custom]() {
    return `SecureSession { id: '${this.sessionId}', user: ${this.userId}, token: '[REDACTED]' }`;
  }
}

const session = new SecureSession('abc-123', 'super-secret-key', 42);
console.log(session);
// Output: SecureSession { id: 'abc-123', user: 42, token: '[REDACTED]' }

Method Arguments

The custom inspection method receives three arguments provided by Node.js during execution:

  1. depth (number): The remaining recursion depth allowed for formatting. It decreases by one at each level of nested inspection.
  2. options (object): The configuration options passed to util.inspect(), including properties like colors, showHidden, and compact.
  3. inspect (function): A reference to the active util.inspect function. This allows you to delegate formatting for child properties while preserving current configuration options and styling.
const util = require('node:util');

class TreeNode {
  constructor(value, children = []) {
    this.value = value;
    this.children = children;
  }

  [util.inspect.custom](depth, options, inspect) {
    if (depth < 0) {
      return options.stylize('[TreeNode]', 'special');
    }

    const nextOptions = Object.assign({}, options, {
      depth: options.depth === null ? null : options.depth - 1,
    });

    return `TreeNode(${this.value}) -> ${inspect(this.children, nextOptions)}`;
  }
}

Primary Use Cases

  • Hiding Sensitive Information: Prevents secrets, passwords, and private tokens from leaking into production logs.
  • Cleaning Up Verbose Objects: Simplifies representations of complex instances like DOM wrappers, database connections, streams, or large data structures.
  • Separation of Concerns: Keeps console debugging formatting separate from application logic, leaving toString() for string coercion and toJSON() for serializing JSON data over network boundaries.
