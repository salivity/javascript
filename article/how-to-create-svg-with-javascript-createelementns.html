How to Create SVG with JavaScript createElementNS

Creating Scalable Vector Graphics (SVG) dynamically with JavaScript requires interacting with XML namespaces rather than standard HTML elements. This article explains why the standard document.createElement method fails for SVG, details the syntax and necessity of the document.createElementNS method, and provides a clear, step-by-step guide to generating and appending functional SVG shapes to the Document Object Model (DOM).

Why document.createElement Fails for SVG

When you call document.createElement('svg'), the browser creates an element inside the HTML namespace (HTMLElement). Because SVG shapes rely on the XML-based SVG specification, the browser will not recognize them as renderable graphics, resulting in an HTMLUnknownElement that remains invisible on the page.

To render SVG properly, you must explicitly declare the SVG namespace so the browser instantiates an SVGElement.

The createElementNS Method Syntax

The document.createElementNS method accepts two arguments:

document.createElementNS(namespaceURI, qualifiedName);
  • namespaceURI: A string specifying the namespace URI associated with the element. For standard SVG elements, this is always "http://www.w3.org/2000/svg".
  • qualifiedName: A string specifying the type of element to be created, such as 'svg', 'circle', 'rect', or 'path'.

Step-by-Step Implementation

1. Define the Namespace

Store the SVG namespace URI in a constant to keep your code clean and prevent typos:

const SVG_NS = "http://www.w3.org/2000/svg";

2. Create the Root SVG Container

Create the top-level <svg> element and assign its visual dimensions and viewBox using standard setAttribute calls:

const svg = document.createElementNS(SVG_NS, "svg");
svg.setAttribute("width", "300");
svg.setAttribute("height", "200");
svg.setAttribute("viewBox", "0 0 300 200");

3. Create and Configure Child Shapes

Every child element within the SVG canvas must also be instantiated using document.createElementNS with the same SVG namespace URI:

const circle = document.createElementNS(SVG_NS, "circle");
circle.setAttribute("cx", "150");
circle.setAttribute("cy", "100");
circle.setAttribute("r", "50");
circle.setAttribute("fill", "#007acc");

4. Append to the DOM

Once attributes are assigned, append the shape to the root SVG element, then append the SVG element to a container in your HTML document:

svg.appendChild(circle);
document.getElementById("canvas-container").appendChild(svg);

Complete Working Example

const SVG_NS = "http://www.w3.org/2000/svg";

// Create root SVG
const svgContainer = document.createElementNS(SVG_NS, "svg");
svgContainer.setAttribute("width", "400");
svgContainer.setAttribute("height", "200");

// Create a rectangle
const rect = document.createElementNS(SVG_NS, "rect");
rect.setAttribute("x", "20");
rect.setAttribute("y", "20");
rect.setAttribute("width", "120");
rect.setAttribute("height", "80");
rect.setAttribute("fill", "#4CAF50");

// Create a circle
const circle = document.createElementNS(SVG_NS, "circle");
circle.setAttribute("cx", "250");
circle.setAttribute("cy", "60");
circle.setAttribute("r", "40");
circle.setAttribute("fill", "#FF5722");

// Assemble and insert into DOM
svgContainer.appendChild(rect);
svgContainer.appendChild(circle);
document.body.appendChild(svgContainer);

By ensuring that both the parent <svg> and its nested child nodes are instantiated via document.createElementNS with "http://www.w3.org/2000/svg", the browser will parse, style, and render vector graphics dynamically without rendering issues.
