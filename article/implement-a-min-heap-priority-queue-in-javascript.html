Implement a Min-Heap Priority Queue in JavaScript

This article demonstrates how to implement an efficient Min-Heap priority queue using a standard JavaScript array. A Min-Heap is a complete binary tree where the value of each parent node is less than or equal to the values of its children, ensuring that the smallest element is always at the root. By mapping tree levels directly to array indices, you can build a high-performance priority queue that executes insertions and extractions in logarithmic time (\(O(\log n)\)) and element lookups in constant time (\(O(1)\)) without external dependencies.

Array Representation of a Binary Heap

A binary heap can be stored contiguously in an array without using explicit pointer nodes. Given a node at index i:

  • Left Child: 2 * i + 1
  • Right Child: 2 * i + 2
  • Parent: Math.floor((i - 1) / 2)

The root element is always at index 0.

Core Operations

A Min-Heap relies on two fundamental rebalancing procedures:

  1. Bubble-Up (Sift-Up): Used after appending an element to the end of the array. The element compares itself to its parent and swaps positions if it is smaller, repeating until the heap property is restored.
  2. Bubble-Down (Sift-Down): Used after removing the root element. The root is replaced with the last element in the array, which then swaps positions with its smallest child until both children are larger or equal to it.

JavaScript Min-Heap Implementation

Here is the complete implementation of the MinHeap class:

class MinHeap {
  constructor() {
    this.heap = [];
  }

  // Helper methods to calculate indices
  getParentIndex(i) {
    return Math.floor((i - 1) / 2);
  }

  getLeftChildIndex(i) {
    return 2 * i + 1;
  }

  getRightChildIndex(i) {
    return 2 * i + 2;
  }

  // Swap two elements in the array
  swap(i, j) {
    [this.heap[i], this.heap[j]] = [this.heap[j], this.heap[i]];
  }

  // Look at the minimum element without removing it
  peek() {
    return this.heap.length === 0 ? null : this.heap[0];
  }

  // Return the number of elements in the heap
  size() {
    return this.heap.length;
  }

  // Insert a new value into the heap
  push(val) {
    this.heap.push(val);
    this.bubbleUp(this.heap.length - 1);
  }

  // Reorder heap upward after an insertion
  bubbleUp(index) {
    while (index > 0) {
      const parentIndex = this.getParentIndex(index);
      if (this.heap[index] < this.heap[parentIndex]) {
        this.swap(index, parentIndex);
        index = parentIndex;
      } else {
        break;
      }
    }
  }

  // Remove and return the minimum value
  pop() {
    if (this.heap.length === 0) return null;
    if (this.heap.length === 1) return this.heap.pop();

    const min = this.heap[0];
    this.heap[0] = this.heap.pop();
    this.bubbleDown(0);
    return min;
  }

  // Reorder heap downward after an extraction
  bubbleDown(index) {
    const length = this.heap.length;

    while (true) {
      let smallest = index;
      const left = this.getLeftChildIndex(index);
      const right = this.getRightChildIndex(index);

      if (left < length && this.heap[left] < this.heap[smallest]) {
        smallest = left;
      }

      if (right < length && this.heap[right] < this.heap[smallest]) {
        smallest = right;
      }

      if (smallest !== index) {
        this.swap(index, smallest);
        index = smallest;
      } else {
        break;
      }
    }
  }
}

Example Usage

const pq = new MinHeap();

pq.push(10);
pq.push(4);
pq.push(15);
pq.push(1);

console.log(pq.peek()); // Output: 1

console.log(pq.pop());  // Output: 1
console.log(pq.pop());  // Output: 4
console.log(pq.pop());  // Output: 10
console.log(pq.pop());  // Output: 15
console.log(pq.pop());  // Output: null

Time and Space Complexity

  • peek(): \(O(1)\) time complexity because the minimum value is always at index 0.
  • push(val): \(O(\log n)\) time complexity because bubbleUp traverses at most the height of the tree.
  • pop(): \(O(\log n)\) time complexity because bubbleDown traverses at most the height of the tree.
  • Space Complexity: \(O(n)\) space complexity to store \(n\) elements contiguously in a standard JavaScript array.
