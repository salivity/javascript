JavaScript String isWellFormed and Lone Surrogates

This article provides an overview of JavaScript's String.prototype.isWellFormed() method, introduced in ECMAScript 2024. It explains what lone surrogate pairs are, why ill-formed UTF-16 strings cause bugs in modern web applications, and how isWellFormed() offers an efficient, native way to validate strings before passing them to APIs that require valid Unicode.

Understanding UTF-16 and Lone Surrogates

JavaScript strings are indexed as sequences of 16-bit code units (UTF-16). Characters in the Unicode Basic Multilingual Plane (BMP) fit into a single 16-bit code unit (ranging from 0x0000 to 0xFFFF).

Characters outside the BMP—such as emojis, historic scripts, or mathematical symbols—require two 16-bit code units called a surrogate pair:

  • High surrogate (leading): values from 0xD800 to 0xDBFF
  • Low surrogate (trailing): values from 0xDC00 to 0xDFFF

A properly formed surrogate pair consists of a high surrogate immediately followed by a low surrogate.

A lone surrogate occurs when:

  1. A high surrogate is not immediately followed by a low surrogate.
  2. A low surrogate is not immediately preceded by a high surrogate.

Strings containing lone surrogates are considered "ill-formed." They can cause critical failures when passed to web APIs that require strictly valid Unicode, such as encodeURI(), crypto.subtle.digest(), or when interacting with databases via WebAssembly.

What is String.prototype.isWellFormed()?

String.prototype.isWellFormed() is a native JavaScript method that returns a boolean indicating whether a string is well-formed UTF-16. It takes no arguments and evaluates the calling string:

  • Returns true if the string contains no lone surrogates.
  • Returns false if the string contains at least one lone surrogate.

How It Detects Lone Surrogates

Under the hood, the JavaScript engine iterates through the code units of the string:

  1. It inspects each 16-bit code unit sequentially.
  2. If it encounters a leading surrogate (0xD800–0xDBFF), it checks whether the next unit is a valid trailing surrogate (0xDC00–0xDFFF). If the next unit is missing or outside the trailing range, it flags a lone surrogate.
  3. If it encounters a trailing surrogate (0xDC00–0xDFFF) without a preceding leading surrogate, it flags a lone surrogate.
  4. If any lone surrogate is found, iteration terminates and the method immediately returns false. If the entire string passes validation, it returns true.

Code Examples

// Standard strings and properly paired emojis
const normalText = "Hello, world!";
const emoji = "😀"; // Encoded as high surrogate \uD83D and low surrogate \uDE00

console.log(normalText.isWellFormed()); // true
console.log(emoji.isWellFormed());      // true

// Ill-formed strings with lone surrogates
const loneLeading = "Hello \uD83D";     // High surrogate missing trailing counterpart
const loneTrailing = "World \uDE00";    // Low surrogate missing leading counterpart

console.log(loneLeading.isWellFormed());  // false
console.log(loneTrailing.isWellFormed()); // false

Why Use isWellFormed()?

Before the introduction of this method, validating strings for lone surrogates required either complex regular expressions or wrapping calls to encodeURI() inside a try...catch block:

// Legacy workaround
function checkWellFormed(str) {
  try {
    encodeURI(str);
    return true;
  } catch (error) {
    return false;
  }
}

The legacy approach has notable downsides:

  • Performance overhead: encodeURI() encodes the entire string into percent-encoded bytes and allocating new memory, rather than merely inspecting code units.
  • Error handling cost: Throwing and catching a URIError introduces execution overhead.

String.prototype.isWellFormed() executes directly in the engine without memory allocation or exception handling, making it the most performant way to validate user-generated input, file streams, or network payloads.

If an ill-formed string is detected, JavaScript also provides a companion method, String.prototype.toWellFormed(), which returns a sanitized copy of the string where any lone surrogates are replaced by the Unicode replacement character (``, \uFFFD).
