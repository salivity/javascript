Node.js os Module Hardware and Network Details

The built-in node:os module in Node.js provides developers with direct access to operating system-level information, enabling JavaScript applications to query underlying hardware specifications and network configurations. This article breaks down the exact hardware and network metrics exposed by the module, covering CPU specifications, memory capacity, system architecture, host information, and network interfaces.

Hardware Details Exposed by node:os

The node:os module provides several methods to inspect the machine's physical and virtual computing resources:

  • CPU Architecture and Cores (os.cpus(), os.arch()):

    • os.cpus() returns an array of objects detailing each logical CPU core. Each object contains the processor model name (e.g., Intel or AMD string), clock speed in MHz, and a breakdown of execution times spent in user, nice, sys, idle, and irq modes.
    • os.arch() returns the CPU architecture for which the Node.js binary was compiled, such as 'x64', 'arm64', or 'ia32'.
    • os.machine() returns the machine architecture as reported by the OS (e.g., 'x86_64', 'aarch64').

  • System Memory (os.totalmem(), os.freemem()):

    • os.totalmem() exposes the total physical system memory in bytes.
    • os.freemem() displays the amount of available, unallocated system memory in bytes.

  • Processing Load (os.loadavg()):

    • Returns an array containing the 1, 5, and 15-minute system load averages. On Windows systems, this metric typically returns [0, 0, 0] because load averages are a UNIX-specific concept.

  • System Uptime (os.uptime()):

    • Exposes the total system uptime in seconds, indicating how long the underlying operating system has been running since its last reboot.

Network Details Exposed by node:os

The module exposes detailed network configurations to allow applications to identify active connections and local addresses:

  • Network Interfaces (os.networkInterfaces()): This method returns an object containing lists of assigned network interfaces (e.g., eth0, wlan0, lo). For every detected interface, an array of network details is exposed:

    • address: The assigned IPv4 or IPv6 address.
    • netmask: The subnet mask associated with the IP address.
    • family: The address family, indicating 'IPv4' or 'IPv6'.
    • mac: The hardware Media Access Control (MAC) address assigned to the physical or virtual adapter.
    • internal: A boolean value indicating whether the interface is a loopback address (true) or externally accessible (false).
    • cidr: The Classless Inter-Domain Routing (CIDR) notation representing the IP address and its subnet prefix.
    • scopeid: An integer representing the numeric IPv6 scope ID (only present on IPv6 interfaces).

  • System Hostname (os.hostname()):

    • Exposes the current host system's network-assigned name as defined in the operating system.

Operating System Identity

Along with hardware and network details, node:os exposes operational metadata that links the hardware to the software environment:

  • os.platform() returns the operating system name (e.g., 'linux', 'darwin', 'win32').
  • os.release() returns the operating system release version or kernel version.
  • os.type() identifies the OS type according to POSIX conventions (e.g., 'Linux', 'Darwin', 'Windows_NT').
  • os.homedir() and os.tmpdir() expose file system paths specific to the host environment for user files and temporary storage.
