KeyframeEffect Keyframes in Web Animations API

The Web Animations API (WAAPI) provides native JavaScript control over CSS animations using the KeyframeEffect interface. This article explains how KeyframeEffect structures animation keyframes in JavaScript, detailing the two primary formats—array-of-objects and property-indexed object-of-arrays—along with property-specific options like offsets, easing, and composite modes.

The KeyframeEffect Constructor

The KeyframeEffect constructor binds an element to its keyframe definitions and timing properties. Its basic syntax is:

const effect = new KeyframeEffect(targetElement, keyframes, timingOptions);

The keyframes parameter can be provided in two distinct structures depending on how values are organized.

1. Array of Keyframe Objects

The most common structure is an array of objects, where each object represents a single frame in the animation timeline. In this format, each object defines the CSS properties and values for that specific point in time.

const keyframes = [
  { transform: 'translateY(0px)', opacity: 1 },
  { transform: 'translateY(-20px)', opacity: 0.5 },
  { transform: 'translateY(0px)', opacity: 1 }
];

Keyframe Object Properties

In addition to standard CSS properties (written in camelCase or as quoted 'kebab-case'), each keyframe object can accept metadata:

  • offset: A number between 0.0 and 1.0 representing the animation step (equivalent to CSS percentages like 0%, 50%, 100%). If omitted, the browser spaces keyframes evenly.
  • easing: A timing function (e.g., 'ease-in', 'linear', 'cubic-bezier(0.4, 0, 0.2, 1)') applied from this keyframe to the next.
  • composite: Defines how property values are combined with the element's existing styles ('replace', 'add', or 'accumulate').
const keyframes = [
  { opacity: 0, offset: 0, easing: 'ease-in' },
  { opacity: 0.8, offset: 0.7 },
  { opacity: 1, offset: 1 }
];

2. Object of Arrays (Property-Indexed Keyframes)

Alternatively, KeyframeEffect accepts a single object where each key represents a CSS property mapped to an array of values. The browser distributes these values chronologically across the animation.

const keyframes = {
  transform: ['scale(1)', 'scale(1.2)', 'scale(1)'],
  backgroundColor: ['#ff0000', '#00ff00', '#0000ff']
};

Specifying Metadata in Property-Indexed Format

When using an object of arrays, offsets and easing functions are defined as array properties alongside the CSS values:

const keyframes = {
  opacity: [0, 0.5, 1],
  offset: [0, 0.3, 1],
  easing: ['ease-in', 'ease-out'] // Defines easing between steps
};

If the arrays for different CSS properties have varying lengths, each property is distributed independently across the timeline from 0% to 100%.

Implicit Keyframes

WAAPI automatically infers missing start or end points:

  • Missing offset: 0: The browser uses the element's computed style at the moment the animation starts as the starting point.
  • Missing offset: 1: The browser uses the element's computed style as the final destination.
// Animates from the element's current opacity to 0
const keyframes = [
  { opacity: 0 }
];

Integration with Animation

Once defined, a KeyframeEffect is attached to an Animation instance and controlled via JavaScript playback controls:

const target = document.getElementById('box');

const effect = new KeyframeEffect(
  target,
  [
    { transform: 'translateX(0px)', opacity: 1 },
    { transform: 'translateX(100px)', opacity: 0 }
  ],
  {
    duration: 1000,
    iterations: Infinity,
    direction: 'alternate'
  }
);

const animation = new Animation(effect, document.timeline);
animation.play();
