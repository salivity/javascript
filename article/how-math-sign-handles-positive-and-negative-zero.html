How Math.sign Handles Positive and Negative Zero

JavaScript's Math.sign() function determines the sign of a number, indicating whether it is positive, negative, or zero. While many developers expect it to return only 1, -1, or 0, the ECMAScript specification preserves the sign bit of signed zeros defined by the IEEE 754 floating-point standard. Consequently, Math.sign() evaluates positive zero (+0) and negative zero (-0) differently, returning 0 and -0 respectively.

The Return Values of Math.sign()

The Math.sign() method converts its argument to a number and returns one of five distinct values:

  • 1: For positive numbers greater than zero.
  • -1: For negative numbers less than zero.
  • 0: For positive zero (0 or +0).
  • -0: For negative zero (-0).
  • NaN: When the argument is not a number or cannot be converted to one.

Evaluating +0 vs. -0

When evaluating positive zero, Math.sign() maintains the positive sign:

Math.sign(0);   // Returns 0 (or +0)
Math.sign(+0);  // Returns 0 (or +0)

When evaluating negative zero, Math.sign() retains the negative sign:

Math.sign(-0);  // Returns -0

Why JavaScript Differentiates Signed Zeros

JavaScript numbers are 64-bit double-precision floating-point values. Under this system, the very first bit represents the sign: 0 for positive and 1 for negative. Because the remaining bits for zero are all zeros, the number system supports two representations: +0 and -0.

To maintain mathematical consistency in edge cases (such as dividing by zero to reach Infinity or -Infinity), Math.sign() is designed not to discard this sign bit.

How to Detect the Negative Zero Return

Standard equality checks in JavaScript do not distinguish between +0 and -0:

Math.sign(0) === Math.sign(-0); // true

To confirm whether Math.sign() returned positive or negative zero, you can use one of two methods:

1. Using Object.is()

Object.is() checks for same-value equality and treats +0 and -0 as distinct values:

const resultPositive = Math.sign(+0);
const resultNegative = Math.sign(-0);

Object.is(resultPositive, 0);   // true
Object.is(resultNegative, -0);  // true
Object.is(resultNegative, 0);   // false

2. Using Division by Zero

Dividing by positive zero results in Infinity, while dividing by negative zero results in -Infinity:

1 / Math.sign(+0); //  Infinity
1 / Math.sign(-0); // -Infinity

Normalizing to an Unsigned Zero

If your application requires 0 regardless of whether the input is +0 or -0, you can normalize the output by adding 0:

function getNormalizedSign(x) {
  const s = Math.sign(x);
  return s === 0 ? 0 : s;
}

Object.is(getNormalizedSign(-0), 0); // true
