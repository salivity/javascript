Sliding Achievement Popups in JavaScript Games

In JavaScript game development, sliding achievement popups are typically created using either an overlaid HTML/CSS Document Object Model (DOM) layer or by directly rendering and interpolating coordinates within an HTML5 Canvas loop. This article explains the two primary implementation methods—CSS-driven transitions and canvas-based linear interpolation—along with the logic required to queue, display, and dismiss multiple notifications seamlessly.

Method 1: The DOM and CSS Overlay Approach

The most common and performant way to implement sliding popups is using an HTML overlay on top of the game screen. By decoupling the UI from the game's render loop, the browser's graphics engine can handle hardware-accelerated animations smoothly.

  1. Initial Setup: Create a container element placed outside the visible viewport using absolute or fixed positioning:

    .achievement-popup {
  position: fixed;
  top: 20px;
  right: -300px; /* Hidden off-screen */
  width: 250px;
  transition: transform 0.5s cubic-bezier(0.175, 0.885, 0.32, 1.275);
}
.achievement-popup.show {
  transform: translateX(-320px); /* Slides into view */
}

  2. JavaScript Trigger: When the game registers an unlock condition, JavaScript adds the active class, waits for a designated display duration, and removes the class:

    function triggerAchievement(title, description) {
  const popup = document.getElementById('achievement-popup');
  popup.querySelector('.title').textContent = title;
  popup.querySelector('.desc').textContent = description;

  popup.classList.add('show');

  setTimeout(() => {
    popup.classList.remove('show');
  }, 4000);
}

Method 2: Direct HTML5 Canvas Rendering

If a game is built entirely within an HTML5 Canvas without DOM elements, the sliding motion must be calculated manually within the game's update loop using linear interpolation (lerp) or easing algorithms.

  1. State Management: Define an achievement object with current positions, target positions, and a timer:

    const notification = {
  x: canvas.width,       // Start off-screen to the right
  targetX: canvas.width - 260, // Visible position
  y: 20,
  width: 240,
  height: 60,
  state: 'sliding_in',  // sliding_in, holding, sliding_out, idle
  timer: 0
};

  2. Update Loop: In the game's main update() loop, interpolate the x position toward the target using a factor (such as 0.1) to create an ease-out effect:

    function updateNotification(dt) {
  if (notification.state === 'sliding_in') {
    notification.x += (notification.targetX - notification.x) * 0.1;
    if (Math.abs(notification.x - notification.targetX) < 1) {
      notification.x = notification.targetX;
      notification.state = 'holding';
      notification.timer = 3.0; // Hold for 3 seconds
    }
  } else if (notification.state === 'holding') {
    notification.timer -= dt;
    if (notification.timer <= 0) {
      notification.state = 'sliding_out';
      notification.targetX = canvas.width; // Target back off-screen
    }
  } else if (notification.state === 'sliding_out') {
    notification.x += (notification.targetX - notification.x) * 0.1;
    if (notification.x >= canvas.width - 1) {
      notification.state = 'idle';
    }
  }
}

  3. Draw Loop: In the draw() function, draw the notification rectangle and text at notification.x and notification.y whenever the state is not idle.

Handling Multiple Notifications: The Queue

If a player unlocks multiple achievements simultaneously, sliding them all in at once can obscure the screen. A queue array (const queue = []) solves this issue. Whenever an achievement triggers, push its metadata into the queue. A queue-monitoring function checks if the animation is currently idle; if so, it shifts the next item from the array and initiates the slide-in sequence. Once the slide-out finishes, the system calls the queue processor again until the array is empty.
