Raycast Obstacle Avoidance in JavaScript Games

This article explains how obstacle avoidance steering behaviors work in JavaScript game development, focusing on the mechanics of using raycasts to guide autonomous agents around walls. You will learn the core differences between local steering and global pathfinding, the mathematics behind ray-wall intersection tests, and practical code patterns to cast "whiskers" and calculate corrective steering forces in real time.

Understanding Obstacle Avoidance Steering

In game development, obstacle avoidance is a reactive steering behavior popularized by Craig Reynolds. Unlike global pathfinding algorithms like A* that calculate an entire route across a pre-baked navigation mesh, steering behaviors operate locally on a frame-by-frame basis.

An autonomous agent—such as an enemy, NPC, or vehicle—navigates its environment by combining multiple movement vectors:

  1. Desired Velocity: The direction and speed the agent wants to go (e.g., seeking a player or wandering).
  2. Steering Force: The corrective force applied to the current velocity to produce smooth, natural-looking turns.
  3. Avoidance Force: A temporary, high-priority steering force applied only when an impending collision is detected.

The fundamental formula governing steering is:

\[\text{Steering Force} = \text{Desired Velocity} - \text{Current Velocity}\]

When an obstacle threatens the agent's path, the desired velocity is dynamically redirected away from the obstruction.

How Raycasts Detect Obstacles

A raycast is a mathematical query that projects an imaginary line segment (a ray) from an origin point along a directional vector to determine if, where, and when it intersects with geometry in the game world.

In 2D JavaScript games, walls are typically defined as line segments between two points, \(A(x_1, y_1)\) and \(B(x_2, y_2)\). To detect whether an agent will hit a wall, you test whether the agent’s cast ray intersects with any nearby wall segment.

The Whisker Configuration

Casting a single forward ray is rarely enough. A single ray can pass through narrow openings but cause the agent's bounding body to clip into edges, or it can fail to detect obstacles when approaching at an angle.

The standard approach uses a multi-ray "whisker" array:

  • Center Ray: Projects directly forward along the agent's velocity vector to detect head-on collisions. This is usually the longest ray.
  • Left Whisker: Projects forward-left at an angle (typically \(15^\circ\) to \(30^\circ\)).
  • Right Whisker: Projects forward-right at an angle.

If the left whisker hits a wall, the agent steers right. If the right whisker hits, it steers left. If the center ray hits, the agent steers away from the surface normal of the impacted wall.

Mathematical Implementation in JavaScript

1. Line-Line Intersection Test

To determine if a ray cast from \((x_1, y_1)\) to \((x_2, y_2)\) intersects a wall segment from \((x_3, y_3)\) to \((x_4, y_4)\), use a 2D cross-product determinant check:

function getIntersection(x1, y1, x2, y2, x3, y4, x4) {
  const den = (x1 - x2) * (y3 - y4) - (y1 - y2) * (x3 - x4);
  if (den === 0) return null; // Lines are parallel

  const t = ((x1 - x3) * (y3 - y4) - (y1 - y3) * (x3 - x4)) / den;
  const u = -((x1 - x2) * (y1 - y3) - (y1 - y2) * (x1 - x3)) / den;

  // An intersection occurs if both t and u are within the range [0, 1]
  if (t >= 0 && t <= 1 && u >= 0 && u <= 1) {
    return {
      x: x1 + t * (x2 - x1),
      y: y1 + t * (y2 - y1),
      distance: t // Normalized distance along the ray
    };
  }

  return null;
}

2. Generating Whiskers and Calculating Avoidance

The agent generates rays based on its current heading and velocity, tests each against active obstacles, and applies a lateral repulsion vector proportional to how close the collision is:

class Agent {
  constructor(x, y) {
    this.position = { x, y };
    this.velocity = { x: 2, y: 0 };
    this.maxSpeed = 3;
    this.maxForce = 0.2;
    this.rayLength = 60;
  }

  getWhiskers() {
    const heading = Math.atan2(this.velocity.y, this.velocity.x);
    const angles = [0, -0.4, 0.4]; // Center, Left (~23°), Right (~23°)
    const lengths = [this.rayLength, this.rayLength * 0.7, this.rayLength * 0.7];

    return angles.map((angleOffset, index) => {
      const angle = heading + angleOffset;
      const len = lengths[index];
      return {
        origin: { ...this.position },
        target: {
          x: this.position.x + Math.cos(angle) * len,
          y: this.position.y + Math.sin(angle) * len
        },
        side: angleOffset // Negative = left, positive = right
      };
    });
  }

  avoidWalls(walls) {
    const whiskers = this.getWhiskers();
    let steerForce = { x: 0, y: 0 };

    for (const whisker of whiskers) {
      let closestHit = null;

      for (const wall of walls) {
        const hit = getIntersection(
          whisker.origin.x, whisker.origin.y,
          whisker.target.x, whisker.target.y,
          wall.p1.x, wall.p1.y,
          wall.p2.x, wall.p2.y
        );

        if (hit && (!closestHit || hit.distance < closestHit.distance)) {
          closestHit = hit;
        }
      }

      if (closestHit) {
        // Calculate lateral push: perpendicular to current travel direction
        const heading = Math.atan2(this.velocity.y, this.velocity.x);
        
        // If center ray hits, steer away from wall; otherwise steer opposite the whisker side
        const turnDirection = whisker.side === 0 ? 1 : (whisker.side > 0 ? -1 : 1);
        const avoidAngle = heading + (Math.PI / 2) * turnDirection;

        // Force magnitude increases the closer the intersection is (1 - distance)
        const strength = (1 - closestHit.distance) * this.maxSpeed;

        steerForce.x += Math.cos(avoidAngle) * strength;
        steerForce.y += Math.sin(avoidAngle) * strength;
      }
    }

    // Clamp steering force
    const magnitude = Math.hypot(steerForce.x, steerForce.y);
    if (magnitude > this.maxForce) {
      steerForce.x = (steerForce.x / magnitude) * this.maxForce;
      steerForce.y = (steerForce.y / magnitude) * this.maxForce;
    }

    return steerForce;
  }

  update(walls) {
    const avoidance = this.avoidWalls(walls);

    // Apply steering force to velocity
    this.velocity.x += avoidance.x;
    this.velocity.y += avoidance.y;

    // Maintain max speed limit
    const speed = Math.hypot(this.velocity.x, this.velocity.y);
    if (speed > this.maxSpeed) {
      this.velocity.x = (this.velocity.x / speed) * this.maxSpeed;
      this.velocity.y = (this.velocity.y / speed) * this.maxSpeed;
    }

    // Update position
    this.position.x += this.velocity.x;
    this.position.y += this.velocity.y;
  }
}

Best Practices for Stable Agent Guidance

  • Dynamic Ray Length: Scale ray lengths relative to current velocity. Faster agents need to look further ahead to start braking or turning early enough to avoid high-speed penetration.
  • Spatial Partitioning: Avoid checking every whisker against every wall segment in large maps. Group static walls into a grid, quadtree, or spatial hash to limit intersection tests strictly to nearby geometry.
  • Surface Normals for Center Impacts: When the center ray detects a direct head-on collision, calculate the hit surface normal rather than choosing an arbitrary turning side. Steer along the reflection vector of that normal to prevent oscillations.
