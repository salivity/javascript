How to Highlight UI Elements in JavaScript Games

Tutorial overlay systems in JavaScript game programming guide new players through onboarding by dimming the game screen and spotlighting specific user interface elements. This effect is achieved through dynamic coordinate calculation, visual masking, CSS stacking adjustments, or canvas-level clipping. By isolating target UI components visually and restricting player input, developers ensure that users focus on essential mechanics, inventory slots, or ability buttons before moving forward.

Calculating Target Coordinates

Before highlighting an element, the tutorial system must determine its exact screen position and dimensions.

For DOM-based game interfaces, JavaScript retrieves the target's bounding box using element.getBoundingClientRect(). This method provides the top, left, width, and height properties relative to the viewport.

In canvas-based frameworks such as Phaser or PixiJS, coordinates are obtained from the scene graph. Developers query the UI node's world transform or call methods like getBounds() to retrieve screen-space coordinates, accounting for camera offsets, scaling, and parent container transformations.

Visual Masking via Canvas Clipping

In pure canvas or WebGL games, a dedicated tutorial layer renders a semi-transparent dark rectangle covering the entire viewport. To create the cutout effect:

  1. Composite Operations: The system draws the darkened overlay across the screen. It then sets the canvas context's globalCompositeOperation to 'destination-out' and draws a rectangle or circle matching the target element's coordinates. This clears the pixels within the shape, revealing the game UI beneath.
  2. Path Clipping: Alternatively, the overlay uses ctx.beginPath(), traces the full screen boundary, and then traces the target bounding box in reverse direction (using the even-odd fill rule). When ctx.fill() executes, the dark overlay covers everything except the specified cutout area.

SVG Masks and CSS Cutouts for Hybrid Games

When games utilize an HTML5 DOM UI layered over a WebGL canvas, SVG masks provide a scalable way to spotlight elements.

An SVG overlay spanning the entire viewport contains a <mask> element. Inside the mask, a white rectangle covers the screen (making everything opaque), and a black shape is positioned over the target element (making that region transparent). The main dark layer references this mask using the CSS mask property:

.tutorial-overlay {
  position: fixed;
  inset: 0;
  background: rgba(0, 0, 0, 0.75);
  mask: url(#tutorial-mask);
}

Whenever the tutorial advances to a new UI component, JavaScript updates the coordinates and dimensions of the black shape within the SVG mask.

The Z-Index Elevation Technique

A simpler DOM approach avoids clipping entirely by elevating the target element's stacking context:

  1. A full-screen overlay div with a semi-transparent dark background is inserted into the DOM with a set z-index (e.g., 1000).
  2. The target UI element's CSS is dynamically updated to position: relative (or absolute) and given a higher z-index (e.g., 1001).
  3. Optional box-shadows, such as box-shadow: 0 0 15px #ffd700, are applied to the target to draw player attention.
  4. When the step completes, the target's original styles are restored, and the overlay moves to the next element.

Input Gating and Event Forwarding

Visual highlighting is only half of an onboarding overlay; the system must also control user input.

To prevent players from clicking non-highlighted elements, the overlay consumes pointer events by default. For the highlighted area, systems either allow events to pass through using the CSS property pointer-events: none on the transparent cutout zone, or attach dedicated event listeners directly to the target UI element. Once the expected action (such as a click, drag, or keypress) is detected, the tutorial manager unbinds the listeners, cleans up the overlay, and transitions to the subsequent step.
