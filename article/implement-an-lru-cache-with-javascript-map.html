Implement an LRU Cache with JavaScript Map

A Least Recently Used (LRU) cache is a data structure that organizes items in order of use, discarding the least recently accessed item when the cache reaches its defined capacity. In JavaScript, an LRU cache can be implemented cleanly and efficiently using the built-in Map object because Map maintains the insertion order of its keys. This guide explains how the Map ordering mechanics work and provides a direct, production-ready implementation of an LRU cache with constant \(O(1)\) time complexity for both read and write operations.

Why JavaScript Map Works for LRU Caches

In standard JavaScript objects, property order is not strictly predictable. In contrast, ECMAScript guarantees that a Map iterates elements in the exact order they were inserted.

This property enables a straightforward LRU strategy:

  1. Reading an item: If an item is accessed via get, it is deleted from the Map and re-inserted immediately. This moves it to the "newest" position (the end of the iteration sequence).
  2. Adding an item: When an item is added via set, if it already exists, it is deleted and re-added to refresh its position. If the cache exceeds its maximum capacity, the oldest item—the very first key in the iteration sequence—is removed using this.cache.keys().next().value.

Both operations execute in \(O(1)\) average time complexity.

The LRU Cache Implementation

Below is the complete ES6 implementation of an LRU cache using a JavaScript Map:

class LRUCache {
  constructor(capacity) {
    if (capacity <= 0) {
      throw new Error("Capacity must be greater than 0");
    }
    this.capacity = capacity;
    this.cache = new Map();
  }

  get(key) {
    if (!this.cache.has(key)) {
      return undefined;
    }

    // Refresh the key by removing and re-inserting it
    const value = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, value);

    return value;
  }

  put(key, value) {
    // If the key exists, delete it first to reset its position
    if (this.cache.has(key)) {
      this.cache.delete(key);
    } 
    // If the cache is full, evict the least recently used (first) item
    else if (this.cache.size >= this.capacity) {
      const oldestKey = this.cache.keys().next().value;
      this.cache.delete(oldestKey);
    }

    this.cache.set(key, value);
  }

  has(key) {
    return this.cache.has(key);
  }

  get size() {
    return this.cache.size;
  }

  clear() {
    this.cache.clear();
  }
}

How the Methods Work

1. The get(key) Method

  • Checks if the key exists using this.cache.has(key). If not, it returns undefined.
  • If the key exists, it captures the current value, deletes the key from the Map, and immediately sets it again.
  • By re-setting the key, it moves to the back of the Map's internal entry list, marking it as the most recently used.

2. The put(key, value) Method

  • Checks if the key is already present. If so, it removes the existing entry so the new value can be appended at the end.
  • If the key is new and the size matches capacity, it triggers eviction. The expression this.cache.keys().next().value retrieves the key from the first element yielded by the keys iterator, which is always the oldest item.
  • Finally, it stores the key-value pair, ensuring it occupies the most recently used position.

Usage Example

const cache = new LRUCache(3);

cache.put("a", 1); // Cache: {a: 1}
cache.put("b", 2); // Cache: {a: 1, b: 2}
cache.put("c", 3); // Cache: {a: 1, b: 2, c: 3}

cache.get("a");    // Returns 1; Cache: {b: 2, c: 3, a: 1} ("a" refreshed)

cache.put("d", 4); // Evicts "b" (oldest); Cache: {c: 3, a: 1, d: 4}

console.log(cache.get("b")); // Returns undefined (evicted)
console.log(cache.get("c")); // Returns 3; Cache: {a: 1, d: 4, c: 3}

By leveraging Map's built-in iteration ordering, this pattern avoids the overhead of manually managing a doubly linked list while delivering optimal performance.
