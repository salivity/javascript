Union-Find with Path Compression in JavaScript

This article provides a concise guide and practical implementation of the Disjoint-Set (Union-Find) data structure in JavaScript, focusing on the path compression optimization. You will learn the core mechanics of the structure, how path compression flattens tree hierarchies to achieve near-constant time complexity, and how to combine it with union by rank for optimal performance.

Understanding Union-Find and Path Compression

The Disjoint-Set data structure tracks elements partitioned into disjoint (non-overlapping) subsets. It supports two primary operations:

  • find(i): Determines which subset an element i belongs to by returning the representative (root) of that set.
  • union(i, j): Merges the subsets containing elements i and j into a single subset.

Without optimizations, trees can degenerate into linked lists, resulting in \(O(n)\) time complexity per operation.

Path compression optimizes the find operation. When traversing up the tree to locate the root, the algorithm updates each visited node to point directly to the root. Subsequent lookups for any of those nodes resolve in \(O(1)\) time. When paired with union by rank (attaching the shallower tree beneath the root of the deeper tree), operations execute in amortized \(O(\alpha(n))\) time, where \(\alpha\) is the extremely slow-growing Inverse Ackermann function.

JavaScript Implementation

Below is a complete implementation using an ES6 class:

class UnionFind {
  /**
   * Initializes the Disjoint Set with `size` elements (0 to size - 1).
   * @param {number} size
   */
  constructor(size) {
    // Each element initially points to itself as its own parent
    this.parent = new Int32Array(size);
    // Rank tracks the approximate depth of the trees
    this.rank = new Uint8Array(size);

    for (let i = 0; i < size; i++) {
      this.parent[i] = i;
      this.rank[i] = 0;
    }
  }

  /**
   * Finds the representative root of element `i` with path compression.
   * @param {number} i
   * @returns {number}
   */
  find(i) {
    if (this.parent[i] !== i) {
      // Path compression: set parent directly to the root
      this.parent[i] = this.find(this.parent[i]);
    }
    return this.parent[i];
  }

  /**
   * Unites the sets containing elements `i` and `j` using union by rank.
   * @param {number} i
   * @param {number} j
   * @returns {boolean} True if merged, false if already in the same set.
   */
  union(i, j) {
    const rootI = this.find(i);
    const rootJ = this.find(j);

    if (rootI === rootJ) {
      return false; // Already in the same set
    }

    // Attach smaller rank tree under the root of the higher rank tree
    if (this.rank[rootI] < this.rank[rootJ]) {
      this.parent[rootI] = rootJ;
    } else if (this.rank[rootI] > this.rank[rootJ]) {
      this.parent[rootJ] = rootI;
    } else {
      this.parent[rootJ] = rootI;
      this.rank[rootI]++;
    }

    return true;
  }

  /**
   * Checks whether elements `i` and `j` belong to the same set.
   * @param {number} i
   * @param {number} j
   * @returns {boolean}
   */
  connected(i, j) {
    return this.find(i) === this.find(j);
  }
}

Usage Example

// Initialize 5 distinct elements (0 through 4)
const uf = new UnionFind(5);

// Connect nodes
uf.union(0, 1);
uf.union(1, 2);
uf.union(3, 4);

// Check connectivity
console.log(uf.connected(0, 2)); // true (0, 1, 2 are in the same set)
console.log(uf.connected(0, 3)); // false (3 is in a different set)

// Merge the two components
uf.union(2, 4);
console.log(uf.connected(0, 3)); // true

Complexity Analysis

  • Time Complexity:
    • Find: \(O(\alpha(n))\) amortized time.
    • Union: \(O(\alpha(n))\) amortized time.
    • For all practical values of \(n\) (even up to \(10^{80}\)), \(\alpha(n) \le 4\), making operations effectively \(O(1)\).
  • Space Complexity: \(O(n)\) to store the parent and rank typed arrays. Using typed arrays (Int32Array and Uint8Array) minimizes memory overhead and provides cache-friendly contiguous memory allocation in the V8 engine.
